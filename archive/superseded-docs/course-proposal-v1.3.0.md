# 新开课立项说明草案

## 课程名称

智能科研方法

英文名称：AI for Research: Methods and Practice

## 开课背景

大模型和智能代理（Agentic AI）正在改变科研中的文献检索、论文阅读、代码生成、实验迭代、结果分析和论文写作方式。AutoResearch（自主研究）正在形成重要研究范式，Karpathy AutoResearch、Sakana AI Scientist 等高关注度项目展示了"修改→评估→保留/丢弃→重复"的自主实验循环；Sakana AI Scientist 已有 AI 生成论文被 ICLR 2025 Workshop 接收。国际一流高校（UC Berkeley、MIT、Johns Hopkins、Cornell、UNL）已开设 Agentic AI 相关课程，但普遍侧重技术/应用导向，缺乏系统的科研方法论框架。

对 CS/AI 研究生而言，关键能力不只是会使用工具，而是能够判断哪些科研环节适合 AI 增强，哪些环节必须保留人工判断，并能在可复现、可审查、符合科研伦理和学术规范的前提下提升科研效率。

本课程面向研究生早期科研训练，回应培养方案中对独立科研能力、交叉实践能力和原创性成果意识的要求。课程以通用科研工作流为主线（70-80%），附带 ML 实验自动化实践（20-30%），帮助学生完成从研究问题到实验原型的小型科研闭环。

## 课程目标

课程目标包括：

1. 建立 AI 辅助科研的整体流程观，而非停留在单点工具使用。
2. 训练学生从文献中识别真实研究空白，并形成可验证研究问题。
3. 训练可复现实验设计、实验记录、结果分析和失败复盘能力。
4. 引入 ML 实验自动化，使学生理解自动化实验循环的收益和边界。
5. 训练学生理解 Agent/Skill 背后的任务契约、Context、Memory、工具与权限、状态、执行循环、评估和人工审核机制。
6. 引导每位学生为自己的真实科研动作设计、实现并评价一个可审计的 Agent Workflow。
7. 强化 AI 使用透明性、人工核验、引用规范、科研伦理和学术诚信意识。

## 申请表建议填报口径

- 学分与学时：2 学分，32 学时。
- 课程性质：专业选修课。
- 课程层次：硕士生、博士生。
- 授课语言：中文，配套英文文献与英文资料；如平台支持，也可填中英文双语。
- 主要上课方式：讲授、研讨、上机实践、项目指导。
- 成绩记录方式：百分制。
- 主要考试类型：课程项目 / 大作业。
- 开课单位：计算机学院。
- 所属一级学科：计算机科学与技术。

## 课程特色

- 以八阶段研究链路组织内容：问题定义、第一性原理、机制假设、外部输入摄取、证据整理、研究判断、原型验证、回写与表达
- 以个人项目贯穿全课：不设置每周独立作业，第 6、9、13、16 课四次研究门材料持续服务最终研究计划、工作流和原型
- OpenCode 从第 1 课起作为主要课堂工作平台，但不绑定单一模型后端，也不把平台操作作为评分目标
- 不把课程讲成 Skills 安装和调用教程；通过案例拆解任务契约、上下文、工具权限、状态、评价、人工审核和失败恢复，引导学生构建自己的科研工作流
- 引入结构化研究方法论（研究门、证据分级、工件状态追踪），让学生掌握有门的科研工作流，而非松散的"做了什么就写什么"模式
- 兼顾通用科研能力（70-80%）与 ML 实验自动化实践（20-30%），课次表明确标注类型
- 引入 AutoResearch 元模式（修改→评估→保留/丢弃→重复）作为实验自动化的核心方法论，并通过 AI Scientist v1/v2 对比展示"模板驱动 vs 自由探索"两种策略
- 将 Research Agent 作为可审计研究助理讲授，要求学生完成“工作流说明 + 可运行或可演示原型 + 一次评价与迭代记录”
- 在第 8 课安排个人研究方案分享与设计诊所，固定同伴组提供形成性反馈但不共同提交项目
- 将 AI 使用记录作为正式考核材料，避免不可追溯的工具依赖
- 将科研伦理与合规说明作为正式项目材料，覆盖数据隐私、知情同意、版权许可、署名贡献、潜在误用和 AI 使用披露
- 强调失败实验、误差分析和威胁有效性，而不是只追求成功 demo
- 证据分级与多源核验要求：学生区分证据角色，说明关键结论的证据来源、支持强度和缺失风险
- 研究工件有标准格式和轻量状态追踪，确保结论可追溯到证据和决策
- 融入科研诚信、负责任 AI、开源合规、数据安全和科技创新责任等课程思政元素
- 与国际同类课程（Berkeley、MIT、JHU、Cornell、UNL）形成差异化定位：国外课程多侧重 Agentic AI 技术、架构、工作流和项目实践，本课程侧重用 AI 支撑可审查、可追溯、负责任的科研链路

## 教学内容概述

课程共 32 学时，建议 16 周完成。内容分为五个模块：

| 模块 | 学时 | 对应研究链路阶段 | 内容 |
| --- | --- | --- | --- |
| 科研工作流、平台与规范 | 4 | 全链路概览 | AI for Research、OpenCode 个人项目工作区、八阶段研究链路、研究工件、Agent 权限、科研伦理 |
| 文献到问题 | 8 | 阶段 1-5 | 检索与证据角色判断、精读、证据地图、研究空白、问题定义、第一性原理、问题门 |
| 假设、分享与可复现基线 | 6 | 阶段 3+6 | 机制假设、研究判断、个人方案分享、实验设计、baseline、实验规格、判断门 |
| 受限 Agent 与自主工作流验证 | 8 | 阶段 7 | Agent 辅助编码、实验自动化、AutoResearch 循环、Agent/Skill 逻辑、自主工作流设计与评价、失败分析、验证门 |
| 表达与评审 | 6 | 阶段 8 + 全链路门检查 | 证据回写、论文式表达、同行评审、论证门预检、个人展示和最终提交 |

## 考核方式

课程采用过程性评价和项目评价结合：

- 文献与问题定位：25%（含证据角色判断、证据地图、非例和可证伪命题、第一性原理推导）
- 实验设计与可复现性：30%（含实验规格、研究判断记录、结果可追溯性）
- 原型与 Agent Workflow 实践：25%（含个人工作流逻辑、原型、权限边界、评价与迭代记录、失败分析）
- 表达、伦理与复盘：20%（含结论可追溯性、门条件满足）

最终产出为问题定义、研究计划、证据地图、实验规格、个人 Agent Workflow、评价报告、可运行原型、实验记录、科研伦理与合规说明、AI 使用记录和论文式短文。

## 与现有培养目标的关系

本课程支持研究生在以下方面形成能力：

- 独立从事科学研究的基本流程能力
- 面向前沿问题的文献判断和问题定义能力
- 将 AI 工具纳入科研实践的工程能力
- 设计、实现和评价可审计 Research Agent 工作流的基础能力，包括任务契约、上下文组织、工具接入、权限控制、自动优化约束和评估
- 可复现、可审查、可表达的研究产出能力
- 对科研伦理、学术诚信、工具边界和研究责任的自觉意识

该定位与计算机科学与技术博士培养方案中“独立从事科学研究工作的能力”“加强学科交叉和实践教学”“在学科前沿领域开展研究”等要求直接对应。

## 开课条件

建议授课前准备：

- 一个可课堂演示的小型 ML 或 LLM 相关实验案例
- 可供全课使用的 OpenCode 环境、开源或国内可用模型后端，以及课前安装和故障替代方案
- 若干正反面 AI 辅助科研案例
- 八阶段研究链路教学图示和工件-门关系概览
- 早期研究脚手架模板（问题定义、AI 使用记录、伦理检查和轻量工件追踪）
- 实验追踪、配置管理和结果汇总的最小模板
- Agent Workflow 说明与评价模板（任务契约、context、memory、skill、MCP、evals、权限、预算、失败恢复和人工审核）
- 证据地图模板和证据充分性检查表
- 研究判断记录模板和实验规格模板
- 期末项目完整模板（含工件状态追踪表）

学生需具备：

- Python 基础
- 机器学习基础
- Git 基本操作
- 命令行环境使用能力
- 基本英文论文阅读能力

## 预期效果

课程结束后，每位学生应至少完成一个可继续发展的研究雏形和一个服务本人科研动作的可审计 Agent Workflow。该成果可以用于后续开题准备、论文 idea 打磨、实验 baseline 建设、组会汇报或个人科研工作流迭代。
