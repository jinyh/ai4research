# 第 12 讲 · 自主性与实质工作流设计

这个任务需要 Agent 自主选择吗？

## 带什么来

L11 可恢复动作与 trace。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-12/judgment-task.md)，先写判断和依据。
2. 与同伴比较；核验后说明维持或改变判断的理由。
3. 在个人副本接入 L10 校验，或增加分组盲化/任务状态持久化等一个实质环节。对真实输入走通输入→处理→人工检查→评价 trace；输出标明 accepted/rejected 与理由，正常项守恒。
4. 同一输入运行 baseline 与改动版；检查拒绝记录仍在账本中，gold 不参与执行端选择。只换提示词措辞、改标题或画流程图不能替代实际实现。

## 做到哪里

本人可运行工作流、实质 diff、任务契约与端到端 trace。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

课外总投入最多 **60 分钟**：指定阅读 15 分钟，准备 10 分钟，项目补全 35 分钟。阅读范围：van der Aalst 工作流模式中的 sequence、exclusive choice 与 iteration 定义/示例；对照本人控制流。

项目补全：仅修未走通的一个环节并补运行说明；不要求接入 MCP 或付费模型。

L13 按冻结协议评价 baseline 和改动版。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
