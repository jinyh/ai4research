# 第 10 讲 · 受限 Agent 执行

审查一次实际代码修改，判断它是修复根因、绕过失败，还是污染实验。

## 带什么来

第 9 讲实验规格、baseline 和复现记录。

## 课堂怎么做

1. 选一个受限步骤，写五字段任务契约与权限边界。
2. 执行任务或读取预置 diff，逐行核对实际变化。
3. 用测试与原始记录验证修改，不只看 Agent 的完成报告。
4. 作出处理决定，保留失败或越权记录并更新 AI 使用记录。

## 做到哪里

任务契约、审查过的 diff 与测试记录、一项处理决定，以及一条失败或越权记录。

## 完成样例

依次打开[任务](../lessons/lesson-10/assets/agent-task-example/task-01.md)、[实际 diff](../lessons/lesson-10/assets/agent-task-example/generate.diff)、[测试输出](../lessons/lesson-10/assets/agent-task-example/test-output.txt)和[失败记录](../lessons/lesson-10/assets/agent-task-example/failure-log.md)。环境故障时使用这组工件完成同样的审查。

课后整理受限步骤；第 11 讲将同一任务放入有预算和停止条件的循环。
