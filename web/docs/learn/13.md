# 第 13 讲 · 工作流评价

用对照与失败证据，判断工作流是否改善了目标科研动作。

## 带什么来

第 12 讲工作流、已有运行结果、baseline 与冻结的评价协议。

## 课堂怎么做

1. 在同一口径下整理一张结果对照表。
2. 写清一项失败或局限，标明它影响什么判断。
3. 将一条研究判断修订为“支持／反驳／仍不能判断”，附上理由与记录位置。

## 做到哪里

一张对照表、一项失败或局限，以及一条修订后的研究判断。

## 完成样例

对照[评价报告模板](../lessons/lesson-13/evaluation-report-template.md)与[虚构填写样例](../lessons/lesson-13/evaluation-report-example.md)。样例数值与运行 ID 均为课程构造，不能作为你的实验结果。

课后补全人工审核、证据充分性、有效性威胁和伦理更新，按[验证门条件](../project.md#checkpoint-3)提交。第 14 讲将其中一个结果写成论证。
