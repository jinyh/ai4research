# 第 13 讲 · 均值、分母与评价结论

总均值较好是否足以采用改动？

## 带什么来

L12 工作流版本、baseline 与冻结协议。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-13/judgment-task.md)，先写判断和依据。
2. 先独立记录，再由教师校准或开放讨论；从逐条记录复核汇总结论。
3. 在同一输入上比较 baseline 与实质修改版，分别报告正确处理、误拒、失败和成本；实际执行证据与构造输出分开。给出结论强度与一项采用/修订/停止决定。
4. 从汇总回到每条记录；核对分母守恒、评价器只读、开发材料与最终证据身份；无改善亦可达标。

## 做到哪里

验证门：本人实际比较、评价报告和后续决定。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

本课为研究门课，课外总投入最多 **60 分钟**：整理 15 分钟，修订与提交 45 分钟；不叠加新必读。15 分钟整理；45 分钟修订验证门材料并提交，缺口优先收窄结论。

L14 直接用此证据写论证段与短报告。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
