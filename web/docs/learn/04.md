# 第 4 讲 · 精读与主张核验

围绕论文的一条主张，完成一张可回查的阅读卡。

## 带什么来

第 3 讲候选表中的一篇核心论文、正式原文和拟用主张。

## 课堂怎么做

1. 用 AI 建立阅读地图，先标为未核验。
2. 回到至少两个原文位置，检查主张、证据与实验设置或论证前提。
3. 找出 AI 的错读、遗漏或已检查风险，写出核验依据。
4. 由你定稿阅读卡，区分作者主张、原文证据与自己的判断。

## 做到哪里

一张完整阅读卡、一条偏差审计和一条 AI 使用记录。未发现明显错误时记录检查过的风险，不编造偏差。

## 完成样例

[Keshav 阅读卡](../lessons/lesson-04/reading-card-demo.md)与[MI 阅读卡](../lessons/lesson-04/mi-reading-card-demo.md)展示原文位置和适用边界。

课后沿用流程累计完成 3 张精读卡；第 5 讲从中选取可比较的证据，第 6 课统一检查。
