# 第 8 讲 · 中期诊所

让同伴质询你的方案，并当场完成一项修改。

## 带什么来

第 7 讲的假设、映射草图与风险记录。陈述按五段组织：问题（含可证伪命题）、关键证据、机制假设、最小验证、最大风险。

## 课堂怎么做

1. 在固定同伴组陈述方案，主动指出尚不能判断的部分。
2. 向同伴提出一项最强处、一项最大风险和一条可执行建议。
3. 收到至少两位同伴的反馈，对至少两条写明处理决定、理由和影响文件。
4. 落实一项修改，保留修改位置和待补证据。

## 做到哪里

一次陈述、同伴反馈、处理记录和一项实际修订，统一写入 `peer-review.md` 或研究判断记录的同伴反馈段。

## 完成样例

虚构案例中的反馈：“baseline 没说模型和温度是否一致。”作者采纳，在实验规格的对照段补齐固定条件；理由是保证公平比较。[查看完整反馈样例](../lessons/lesson-08/handout.md)。

按事实选择采纳、澄清、补证、暂缓或保留异议，不必凑齐类型。课后补尚未处理完的事项；本课不正式提交，记录进入第 9 课判断门。
