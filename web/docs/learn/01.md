# 第 1 讲 · AI 辅助科研导论

围绕一个当前不确定的问题，完成一次“AI 建议 → 人工判断 → 有限写回 → 检查记录”的交互。

## 带什么来

一个研究兴趣、可使用的公开材料，以及[早期研究脚手架](../course/starter-template.md)。课前按[Pi Agent 准备](../course/pi-setup.md)确认环境；课程模型资源见[沐曦算力申请与接入](../course/metax-compute.md#pi)。

## 课堂怎么做

1. 跟随同一阅读卡案例，理解八阶段怎样衔接；再写下自己的问题与不确定性。
2. 请 AI 只读材料、提出建议；由你选择一处值得修改的内容。
3. 明确只修改 `problem-definition.md` 的“当前问题”段，确认后按已验证的配置写回；未配置写入限制时由人应用建议。
4. 核对实际 diff 与修改范围，再人工补修改记录和第一条 AI 使用记录。

## 做到哪里

本次完成阶段 1 的问题修订，下一步定义“限定条件遗漏”并准备比较材料；效果仍待实验验证。

留下问题、不确定性、链路位置、一次经审查的修改和使用记录。八阶段草图只填当前相关位置；其余随项目推进补全。

## 完成样例

打开[两轮提示词、预期 diff 与日志空表](../lessons/lesson-01/classroom-pack.md)。样例为课堂构造，预期 diff 不冒充实际执行；你的记录应能看出建议、人工取舍、实际修改与待核验项。模型不可用时按材料包完成纸面审查，标明未执行。

课后沿用这个项目，为第 2 讲补充材料与权限边界；本课不正式提交。
