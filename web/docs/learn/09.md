# 第 9 讲 · 公平 baseline 与实际复现

“降低遗漏”这项比较公平吗？

## 带什么来

L8 已修订的协议；CPU 运行起点。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-09/judgment-task.md)，先写判断和依据。
2. 与同伴比较；核验后说明维持或改变判断的理由。
3. 复制个人微型项目起点，实际执行 baseline.py 并评价；保存本人 trace 与输入、实现散列。为记录校验问题冻结比较协议，同伴依说明复现关键步骤。阅读卡回放另作方法示范。
4. 核对 inputs、implementation、reference 与运行目录；基线和后续修改共用输入及评价。回放只证明回放过程；构造开发用例上的改进不能外推为模型改善。

## 做到哪里

判断门：baseline 运行、七字段规格、复现说明及两条判断。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

本课为研究门课，课外总投入最多 **60 分钟**：整理 15 分钟，修订与提交 45 分钟；不叠加新必读。15 分钟整理；45 分钟修订并提交判断门，主要运行在课堂完成。

L10 在这个工作区完成受限补丁，输入与评价协议保持冻结。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
