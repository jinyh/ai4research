# 第 7 讲 · 假设与区分实验

找出一种观察，使主假设与替代解释得到不同判断。

## 带什么来

第 6 讲选定的问题、证据与待验证前提。

## 课堂怎么做

1. 为主假设写出可能的中间过程。
2. 选择一个有依据的替代解释，明确两者的区分观察。
3. 绘制“假设—指标—实验—可能结论”映射草图。
4. 写一条研究判断和一条 AI 使用记录。

## 做到哪里

一个 H1、一个可区分替代假设、一条判断和一张映射草图。完整实验规格集中在第 9 讲完成。

## 完成样例

阅读卡案例分开三个问题：Q1 问遗漏是否减少；H1 猜测生成时显式列出条件，使输出保留更多条件；A2 则问评价者看到字段提示是否改变了评分。仅有两组遗漏率，不能区分 H1 与 A2。

可追加隐藏条件标签、统一呈现后的盲评，检查差异是否仍在；机制判断还需生成过程或对照证据。其他错误检查整体质量，材料分层检查适用范围。[查看假设与结果映射](../lessons/lesson-07/handout.md)。

课后整理陈述与最大风险，带到第 8 讲诊所接受质询。
