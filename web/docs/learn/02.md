# 第 2 讲 · 科研伦理与 Agent 边界

为上一讲的科研动作补上材料、权限和人工审核边界。

## 带什么来

个人项目与第一条 AI 使用记录。使用自己的公开材料，或打开[风险与权限材料包](../lessons/lesson-02/classroom-pack.md)中的虚构课堂项目。

## 课堂怎么做

1. 填一张五字段风险卡：对象、动作、风险、控制、责任人。
2. 在权限矩阵填写当前任务的一行，写清可读、可写、确认点和禁止项。
3. 检查一次操作是否符合这些边界，并更新 AI 使用记录。

## 做到哪里

风险卡、权限矩阵一行、使用记录，以及一次边界审查。材料包同时提供空表和完成样例；无模型时也可据预置记录完成审查。

课后补全项目伦理说明和工件追踪，为第 3 讲准备公开问题、关键词与来源边界。本课不正式提交。
