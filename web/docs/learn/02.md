# 第 2 讲 · 权限声明与运行行为

这份 trace 足以证明边界有效吗？应在哪个动作前停止？

## 带什么来

L1 的问题、实际建议、读写记录、diff 或保留理由，以及下一项动作；无需实验结果。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-02/judgment-task.md)，先写判断和依据。
2. 先个人记录判断和依据，再看教师校准或参加开放讨论；面对新证据时说明维持、修订或暂缓判断的理由。
3. 给本人一个动作列必要上下文、已授权读写、输出与停止条件；让 AI 在授权内完成该动作，保存实际输入输出。更新既有权限行、风险卡和日志。
4. 对一个超出当前授权的模拟请求，在执行前由人拒绝并记录拦截位置，不实际读取被拒文件。默认形成的是人工控制证据；仅在已验证工具限制的环境追加工具层检查，现有 access-check 不是前提。

## 做到哪里

权限行、风险卡、一次允许/拒绝检查及日志。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

课外总投入最多 **60 分钟**：指定阅读 15 分钟，准备 10 分钟，项目补全 35 分钟。阅读范围：中科院诚信提醒中涉及 AI 生成内容核实与责任的条款；对照本课权限声明，不扩展为整份规范背诵。

项目补全：补齐边界验证记录；准备公开研究问题和检索关键词。

L3 只在已声明的公开来源和网络范围内检索。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
