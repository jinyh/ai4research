# 第 6 讲 · 问题定义

从候选题中选择一个能在课程周期内检验的问题。

## 带什么来

候选题池、证据地图、精读卡，以及已经发生的失败或放弃记录。

## 课堂怎么做

1. 比较问题的重要性、证据基础与可行性，记录取舍理由。
2. 写清问题范围、非例和一个可证伪命题。
3. 从基本约束推出一个待验证前提，标记一个替代解释。
4. 对照问题门完整条件，标注已满足与待补缺口。

## 做到哪里

把选定问题、命题、前提和替代解释写回 `problem-definition.md` 及相关记录。新颖性用于诊断，不作为额外硬门。

## 完成样例

阅读卡案例先问：“在限定材料与任务中，阅读卡是否比自由摘要少遗漏原文条件？”比较结果可以检验这条命题；生成步骤为什么有效，需要另列机制假设。对照[贯穿案例](../course/reading-card-case.md)写出范围、非例与推翻条件。[MI 问题定义示例](../lessons/lesson-06/mi-problem-definition-demo.md)供课后迁移练习。

课后只补自查缺口，并按[问题门条件](../project.md#checkpoint-1)提交当前项目版本。第 7 讲继续拆解机制假设。
