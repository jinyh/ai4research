# 第 3 讲 · 检索漏检与误纳诊断

查询的改动解决了哪种漏检，又引入什么误纳？

## 带什么来

L2 的来源范围；独立种子 Keshav 2007。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-03/judgment-task.md)，先写判断和依据。
2. 与同伴比较；核验后说明维持或改变判断的理由。
3. 先修复保存结果，再在本地索引或可用学术库执行自己的修订查询，记录字段/语义/结果。对两条真实线索做身份与一条拟用主张审计；两条均核验通过也合格。同题允许独立定位与判断。
4. 同伴按查询逐字重放一个命中和一个漏检；候选条目有原文位置与纳入理由。离线用 S1/S2 存档审计，网络故障条目保持 pending。

## 做到哪里

notes/literature-search.md：一条可重放查询、两条据实审计、一条候选的角色与决定。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

课外总投入最多 **60 分钟**：指定阅读 15 分钟，准备 10 分钟，项目补全 35 分钟。阅读范围：Booth Chapter 3 中 Finding and Evaluating Sources 的检索与来源评价段落；只记录一次查询修订依据。

项目补全：按相同筛选条件从公开起始池扩展候选，保留排除理由；给 L4 选一条拟用主张。

L4 精读其中一条关键主张；候选起始池可继续扩展。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
