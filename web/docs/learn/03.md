# 第 3 讲 · 多路文献发现与检索决策

哪条检索路线适合当前问题，结果怎样改变下一步？

## 带什么来

L2 的来源范围；独立种子 Keshav 2007。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-03/judgment-task.md)，先写个人判断和检索目标。
2. 先个人记录判断和依据，再看教师校准或参加开放讨论；面对新证据时说明维持、修订或暂缓判断的理由。
3. 围绕研究问题选择词法、语义、引文网络或 Agent 多源检索路线，记录实际来源、查询/提示、筛选条件和结果；依据漏检、误纳、重复或偏题调整路线。OpenAlex 只是可替换的一个来源。对真实候选做身份与拟用主张审计。
4. 个人重放一次命中和一次漏检，检查候选条目的原文位置与纳入理由；离线可用 S1/S2 存档，网络故障按 pending 记录。

## 做到哪里

notes/literature-search.md：多路检索决策记录、来源审计、候选角色与筛选决定。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

课外总投入最多 **60 分钟**：指定阅读 15 分钟，准备 10 分钟，项目补全 35 分钟。阅读范围：Booth Chapter 3 中 Finding and Evaluating Sources 的检索与来源评价段落；只记录一次查询修订依据。

项目补全：按相同筛选条件从公开起始池扩展候选，保留排除理由；给 L4 选一条拟用主张。

L4 精读其中一条关键主张；候选起始池可继续扩展。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
