# 第 3 讲 · 检索与来源核验

让一条拟用主张从检索线索走到可检查的原文。

## 带什么来

研究问题、关键词和允许访问的来源范围；记录写入 `notes/literature-search.md`。

## 课堂怎么做

1. 构造并执行一条检索式，记录数据库、日期、命中数和筛选条件。
2. 对两条线索做来源审计，区分身份核验、主张核验与纳入决定。
3. 将至少一条主张回到原文，写入候选表，注明证据角色、状态与理由。
4. 保留未核验或排除记录，并写一条 AI 使用记录。

## 做到哪里

一条检索记录、两条审计、至少一条已核验或带完整限定的候选记录，以及使用记录。未完成核验的条目保持 `pending`。

## 完成样例

[真实 Keshav 2007 来源核验记录](../lessons/lesson-03/source-audit-demo.md)展示从书目信息到正式原文的检查过程。断网时使用该记录练习审计，自有候选保持待核验。

课后继续扩展同一候选表，供第 4 讲精读；第 6 课问题门统一检查累计材料。
