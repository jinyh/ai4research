# 第 3 讲 · 多路文献发现与检索决策

哪条路线能补上当前问题的缺口？返回结果怎样改变下一步？

## 带什么来

L2 的公开问题、工具与来源权限。共同问题围绕 GPT-2 small IOI 干预与跨模板迁移，给定种子 [2211.00593](https://arxiv.org/abs/2211.00593)。

## 课堂怎么做

1. 打开[个人判断任务](../lessons/lesson-03/judgment-task.md)与[真实运行记录](../lessons/lesson-03/ioi-retrieval-record.md)，先看输入 A，形成初判。
2. 比较词法、语义与引文路线，查看 Agent 的实际调整及访问失败恢复，决定是否更新判断。
3. 用本人问题执行两条互补路线，按结果调整一次，核验两条真实来源的身份与拟用主张。
4. 反查一项纳入决定，再回答改模型情境下哪些证据角色需要重判。

## 做到哪里

`notes/literature-search.md`：实际请求与返回、路线比较与调整、两条审计、至少一条已核验候选与本人决定、停止理由与 AI 使用记录。无新增、有依据地保留或仍不能判断均可成立。断网用历史记录完成诊断，明确本人实际执行缺项后补核。

## 课外与下课去向

课外总量最多 **60 分钟**：阅读 15、准备 10、补全 35，含安装排障。指定阅读 IOI 摘要与 §2，只记一项检索缺口。第 4 课深读一条会改变设计或解释的主张。本课无独立正式提交，第 6 课汇总问题门材料。
