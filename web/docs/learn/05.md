# 第 5 讲 · 证据地图

判断两张阅读卡是否真正可比，并把判断写成一段短综述。

## 带什么来

同一子问题下的两张已核验阅读卡；带限定的来源须保留限定。

## 课堂怎么做

1. 对齐任务、设置与指标，判断证据支持、冲突或暂不可比较。
2. 将同一组记录整理为窄矩阵和证据地图，复用主张、原文位置与边界。
3. 写四句短综述：共同问题、支持证据、冲突或限制、下一步。
4. 记录一个候选问题与生成路径，并更新 AI 使用记录。

## 做到哪里

一个子问题、两条地图主格、一次可比性判断、窄矩阵与四句综述。发现空白时先记类型、状态和下一步窄检索。

## 完成样例

[MI 证据地图](../lessons/lesson-05/mi-evidence-map-demo.md)展示如何组织支持、冲突和缺口，而非逐篇堆摘要。
