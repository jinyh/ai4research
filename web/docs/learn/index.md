# 16 讲课程

先看本课任务，再按需要进入方法讲解、完成样例和阅读材料。课堂产出持续写回个人项目。

| 课次与主题 | 本课主要产出 |
| --- | --- |
| [01 · AI 辅助科研导论](01.md) | 一个问题，一次经人工审查的 AI 交互 |

| [03 · 检索与来源核验](03.md) | 检索记录、来源审计与候选文献 |

| [06 · 问题定义](06.md) | 收敛问题；课后提交**问题门**材料 |
| [07 · 假设与区分实验](07.md) | 主假设、替代解释与判断记录 |

| [09 · MI 共同实验与双基线](09.md) | 实际运行与复现记录；课后提交**判断门**材料 |

| [15 · 独立评审与作者回应](15.md) | 匿名稿评审、意见处理与提交预检 |

## 判断任务与课外预算

每课由学生形成并记录个人判断；AI 可参与研究行动，教师校准、来源核验和开放讨论帮助检验判断。课外总投入每课最多 60 分钟，包含阅读、准备、安装排障、项目推进和提交。研究门课不叠加新必读。
