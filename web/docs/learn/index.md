# 16 讲课程

先看本课任务，再按需要进入方法讲解、完成样例和阅读材料。课堂产出持续写回个人项目。

| 课次与主题 | 本课主要产出 |
| --- | --- |
| [01 · AI 辅助科研导论](01.md) | 一个问题，一次经人工审查的 AI 交互 |
| [02 · 科研伦理与 Agent 边界](02.md) | 风险卡、权限一行、使用记录 |
| [03 · 检索与来源核验](03.md) | 检索记录、来源审计与候选文献 |
| [04 · 精读与主张核验](04.md) | 一张完整阅读卡与偏差审计 |
| [05 · 证据地图](05.md) | 可比较的证据记录与短综述 |
| [06 · 问题定义](06.md) | 收敛问题；课后提交**问题门**材料 |
| [07 · 假设与区分实验](07.md) | 主假设、替代解释与判断记录 |
| [08 · 中期诊所](08.md) | **学生主导**：质询、反馈与当场修改 |
| [09 · Baseline 与复现](09.md) | 可复现记录；课后提交**判断门**材料 |
| [10 · 受限 Agent 执行](10.md) | 任务契约、diff 与验证记录 |
| [11 · 自动化循环](11.md) | 受控循环说明与三类运行记录 |
| [12 · 个人工作流](12.md) | 同一任务的工作流原型与 trace |
| [13 · 工作流评价](13.md) | 对照与失败分析；课后提交**验证门**材料 |
| [14 · 结果写成论证](14.md) | 一段有证据、有边界的论证 |
| [15 · 同行评审与修改](15.md) | 真实评审、现场修改与提交预检 |
| [16 · 最终展示](16.md) | **学生主导**：展示与**论证门**；详细讲义待复核 |
