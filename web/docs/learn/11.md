# 第 11 讲 · 自动化循环

让上一讲的受限任务重复执行，同时保留停止、回退与失败证据。

## 带什么来

任务契约、验证方法、diff 与运行记录。

## 课堂怎么做

1. 固定指标、预算、停止条件与回退位置。
2. 检查一次正常运行、一次无改善或结果不支持、一次受控技术失败。
3. 对照配置和日志，判断应继续、保留修改还是回退。
4. 保存三类 trace，记录决定依据。

## 做到哪里

一份循环说明与三类运行记录，可使用小子集或课次预置日志。无改善与技术故障应分别处理。

## 完成样例

[讲义的循环案例与日志审计](../lessons/lesson-11/handout.md)展示为何不能在结果不理想后改换指标，再宣布成功。

课后把受限执行整理成可重复调用的队列与恢复逻辑；第 12 讲继续设计同一工作流。本课不正式提交。
