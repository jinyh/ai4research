# 第 14 讲 · 结果写成论证

把自己的一项关键结果写成有来源、有边界的段落。

## 带什么来

第 13 讲评价报告、对应实验或运行 ID、原始结果与研究判断。

## 课堂怎么做

1. 选一项结果，写清主张、证据、推理和边界。
2. 回查数字、引用和上游判断，删去结果不能支持的外推。
3. 补一条结论追踪记录，以及 AI 使用披露摘要。

## 做到哪里

一个完整论证段、一条追踪记录和披露摘要。完整短文在课后扩展。

## 完成样例

以下为贯穿案例的**教学构造数据**，由 3 份文本的参考标注逐项合并；每个条件分母均为 8：

| 条件 | 限定条件遗漏率 |
| --- | ---: |
| 阅读卡 | 3/8 = 0.375 |
| 自由摘要 | 4/8 = 0.500 |

可写：“本构造包中总遗漏率方向与 Q1 一致，但 T03 上阅读卡更差；H1 生成机制与 A2 测量解释仍未区分，其他质量尚未评价，不能外推至所有材料。”没有随机重复，不画误差线或作显著性判断。[反查材料与计算](../materials/reading-card.md) · [查看完整推导](../lessons/lesson-14/handout.md)。

课后将段落扩展为 `report.md` 初版，补齐引用与披露，供第 15 讲评审；本课不正式提交。
