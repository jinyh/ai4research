# 第 16 讲 · 结论到决定的反向抽查

展示结论能一路反查到什么，哪处断点会改变决定？

## 带什么来

L15 修订版、实际运行与反馈处理。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-16/judgment-task.md)，先写判断和依据。
2. 与同伴比较；核验后说明维持或改变判断的理由。
3. 全员闪电展示；固定 3–4 人组轮流反查。直接打开现有材料，说明一个关键取舍、失败或未决问题，并完成最终提交与复盘。
4. 每位学生留一条由真实同伴完成的反查记录；教师另记抽查对象与范围。断网使用本地工件，机器故障展示保存 trace 并约定实际运行复核。

## 做到哪里

论证门与最终个人项目：报告、工作流、原始证据与复盘。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

本课为研究门课，课外总投入最多 **60 分钟**：整理 15 分钟，修订与提交 45 分钟；不叠加新必读。15 分钟整理；45 分钟修订和最终提交；已有材料直接打包。

课程收束；仅修明确反馈缺口，不新增研究任务。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
