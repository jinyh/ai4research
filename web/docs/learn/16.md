# 第 16 讲 · 个人展示与迁移检验

结论能反查到什么证据，换了条件后自己的判断是否仍成立？

## 带什么来

L15 修订版、实际运行与反馈处理。

## 课堂怎么做

1. 打开[共同诊断任务与原始输入](../lessons/lesson-16/judgment-task.md)，先写判断和依据。
2. 先个人记录判断和依据，再看教师校准或参加开放讨论；面对新证据时说明维持、修订或暂缓判断的理由。
3. 全员个人短展示，说明一个关键取舍、失败或未决问题；结合新条件完成证据反查和迁移判断。
4. 每人提交个人书面证据检查与新条件判断；教师记录抽查对象与范围。

## 做到哪里

论证门与最终个人项目：报告、工作流、原始证据、个人解释与迁移判断。达标看独立判断、证据定位、相称验证与实际回写；无改善或仍不能判断也可达标。

## 课外与下课去向

本课为研究门课，课外总投入最多 **60 分钟**：整理 15 分钟，修订与提交 45 分钟；不叠加新必读。15 分钟整理；45 分钟修订和最终提交；已有材料直接打包。

课程收束；仅修明确反馈缺口，不新增研究任务。 安装与排障包含在预算内；超时切换备用。既有示例仅供参考，不替代本人执行与决定。
