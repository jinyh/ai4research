# 第 16 讲 · 最终展示

展示自己的研究判断、证据和工作流，完成论证门与课程复盘。

## 带什么来

经过第 15 讲修改的个人项目、报告、证据与工作流运行记录。

## 展示什么

1. 全员闪电报告：研究问题、关键结果、结论边界。
2. 固定同伴组演示：对应证据、实验 ID 与个人工作流 trace。
3. 接受教师抽查，说明结果如何复现、引用如何核验、判断如何形成。
4. 复盘 AI 的实际帮助、误导与人工核验。

## 提交到哪里

论证门与最终个人项目合并提交当前版本；入口与截止时间见教师通知。展示核验已有材料，不另做一套项目。

[查看完整论证门条件](../project.md#checkpoint-4) · [检查最终项目模板](../course/project-template.md) · [回到第 15 讲修改](15.md)

准备时可对照第 13 讲的[虚构评价样例](../lessons/lesson-13/evaluation-report-example.md)检查结果追踪方式，展示必须使用自己的真实记录。
