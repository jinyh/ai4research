# 智能科研方法

上海交通大学研究生课程 · AI for Research: Methods and Practice

面向已经在使用 AI 的研究生，学习组织 AI 深度参与问题、假设、实验、分析、评审与工作流改进；学生独立判断依据、适用条件和结论，并对研究选择负责。课程既讨论 AI 怎样改变研究方法，也检验这些改变何时成立。

**2 学分 · 32 学时 · 16 讲 · 一个个人项目 · 四次正式提交**

## 这门课怎样推进

<div class="milestones" markdown="1">

| 课次 | 在同一个项目上继续做什么 |
| --- | --- |
| [01–06](learn/01.md) | 建立工作区，检索和精读文献，形成问题与证据地图 |
| [07–09](learn/07.md) | 提出假设，在中期诊所接受质询，完善实验规格 |
| [10–13](learn/10.md) | 执行、约束并评价自己的科研工作流 |
| [14–16](learn/14.md) | 写出论证，同行评审、修改并展示项目 |

</div>

个人项目与评分由学生本人承担。第 8 讲个人方案分享并接受公开质询；第 15 讲独立评审与作者回应；第 16 讲个人展示与新条件迁移检验。讨论和自愿协作保留，不要求固定配对、固定小组或相互签认。

## 判断任务与课外预算

每课先形成个人判断，再结合 AI 参与、教师校准、证据核验或开放讨论迁移到本人项目。课外总投入每课最多 60 分钟，包含阅读、准备、安装排障、项目推进和提交。研究门课不叠加新必读。
