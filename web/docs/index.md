# 智能科研方法

> 上海交通大学研究生课程　·　AI for Research: Methods and Practice　·　2 学分 · 32 学时 · 专业选修课

## 课程定位

生成式人工智能正在降低许多科研动作的成本：扩展关键词、理解陌生概念、定位代码错误、生成实验脚本、整理结果、修改文字。成本降低并不意味着研究质量自动提高——未经核验的引用、含数据泄漏的代码、不公平的对照、丢失的失败记录和缺乏边界的结论，也可能更快地扩散。

本课程因此不把“会不会用某个 AI 工具”作为核心问题，而提出一个更严格的问题：

> 当 AI 参与科研之后，我们如何保证问题仍由研究者定义，证据仍可核验，实验仍可复现，结论仍有边界，责任仍由人承担？

## 教学结构

课程按八阶段研究链路组织，OpenCode 作为主要课堂工作平台贯穿全程；每位学生从第 1 课起维护一个个人项目，持续回写同一研究问题。详见 [课程大纲](course/syllabus.md)。

## 考核方式

课程不设每周作业分，核心是学生是否形成可验证、可复现、可追溯、有门的科研闭环，并能为自己的科研动作设计、实现和评价一个可审计的 Agent Workflow。正式提交只有四次，对应四个研究门。详见 [考核方式](course/assessment.md) 与 [项目与研究门](course/assignments.md)。
