# 模板与资源

从本课任务进入相应材料；所有记录持续写回同一个个人项目。

## 开始与迁移

- [沐曦算力：申请与使用](course/metax-compute.md)：领取算力券、连接模型、按需运行 GPU 实验与保存结果。
- [Pi Agent 课前准备](course/pi-setup.md)：环境确认、权限边界和备用路径。
- [早期研究脚手架](course/starter-template.md)：第 1–8 课维护问题、证据和 AI 使用记录；允许有预算的早期审计与试跑。
- [完整项目模板](course/project-template.md)：第 9 课按内容成熟度迁移；分文件与合并主文档按相同内容验收，保留阶段版本。
- [伦理与合规说明模板](course/ethics-and-compliance-template.md)：从第 2 课开始更新。

每课先独立判断共同材料，再核验并迁移到本人项目。课外总投入每课最多 60 分钟，包含阅读、准备、安装排障、项目推进和提交。研究门课不叠加新必读。
