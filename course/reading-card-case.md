# 阅读卡贯穿案例：命题、材料与评价

本文件统一 L06–L16 的阅读卡示例。课程结构、评分和四个研究门沿用原权威文件；本案例的样本量、模式和指标不成为全班硬门。

## 1. 四层判断

| 标识 | 具体含义 | 怎样判断 |
| --- | --- | --- |
| Q1 结果命题 | 在明确的材料与任务范围内，阅读卡输出的限定条件遗漏率低于自由摘要 | 对回同一源文本的人工基准，比较两种输出；写明样本与不确定性 |
| H1 机制候选 | 显式列出限定条件的生成步骤促使输出保留更多限定条件 | 需要能区分生成步骤作用的过程记录或对照；仅有两组遗漏率不能确认机制 |
| A2 测量解释 | 评价者看到字段提示，造成评分差异 | 检查评价呈现与盲评记录；不把生成提示与评价提示混为一谈 |
| A1 质量代价 | 限定遗漏下降，同时其他错误增加或总错误未改善 | 分项错误及总量；可能与 Q1 同时成立，不自动反驳 Q1 |
| A3 适用范围 | 效果随输入材料结构变化 | 分层观察；某类材料有效不能推广为全部材料，也未必推翻该范围内的 H1 |
| J1 采用决定 | 根据质量、成本、范围与资源约束继续、修改或暂缓工作流 | 写清证据和取舍；成本不可接受影响采用决定，不自动推翻 Q1 |

L07 课堂完整演示 Q1、H1 与 A2 的区分，A1/A3 用于质量和范围追问。学生自己的项目只需一个有依据的主机制与一个可区分替代，不强制使用这些编号。

## 2. 当前课堂小包

材料入口：[可复演工作流](../lessons/lesson-11/assets/reading-card-workflow/README.md)。

- 3 份源文本 T01–T03，分别含 3、3、2 项限定条件；T03 的条件在图表文字描述中。
- 两种输出条件 card/free，每份源文本每条件一份预制输出，共 6 份。
- 源文本、输出与参考标注全部为教师构造素材；程序回放这些素材，没有调用模型或运行真实科研实验。
- 参考标注逐项连到源文本和输出；程序检查记录完整性、引用片段和汇总一致性，语义是否被保留仍由人核验。
- 汇总采用逐项合并口径：每个条件分母为 8。阅读卡遗漏 3/8=0.375，自由摘要遗漏 4/8=0.500，差为 -0.125（阅读卡减自由摘要）。
- T01 改善，T02 无改善，T03 阅读卡更差。原样本的三项全部保留。
- 不画误差条，不作显著性或总体机制判断。原有 20×2×3=120 是扩展规格示意，退出当前主演；学生根据自己主张设计重复计划。

## 3. 跨课使用

| 课次 | 本次动作 |
| --- | --- |
| L06–L08 | 只使用问题、假设、观察卡和方案；不预设真实结果会改善 |
| L09 | 从一项原文条件对回输出与参考标注，解释指标；已有四条布尔记录小包另作复算校准 |
| L10 | 已有 normalize_record 缺字段修复作工程校准，明确它不是遗漏率评价器 |
| L11 | 回放六项队列，保留受控技术失败与恢复后的新 run ID；正常/无改善/负例均可查 |
| L12 | 指认输入、持久状态、执行、独立评价和人工审核；演示工具访问接口拒绝读取 gold |
| L13 | 从人工逐项标注复算对照，保留 T03，形成一条有限判断 |
| L14–L16 | 由同一汇总写段落、评审、修改和证据反查 |

## 4. 可以形成的判断

“在这套课堂构造材料中，阅读卡输出遗漏 3/8，自由摘要遗漏 4/8；总体方向与 Q1 一致，T03 上阅读卡更差。H1 与 A2 尚无区分证据，整体质量代价 A1 未评价；现有材料只训练方法，不能作为阅读卡科研效果的证据。”

负例先作为观察保留。“图表条件提取不足”是待核查的原因候选；检查解析记录或追加对照后再改变原因判断。下一版可以修解析、改字段或明确范围，但必须保留本版总体与分项结果，另记版本和评价计划。

## 5. 证据用语

来源核验（是否正确转述）、证据作用（支持哪条主张）、结论方向（支持/反驳/仍不能判断）和工件成熟度分别记录。`verified` 不表示原研究已获独立证实，`stable` 不表示取得引用资格。有限结果、负结果和未决项均可按实际依据写入报告。
