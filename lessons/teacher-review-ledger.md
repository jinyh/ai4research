# 全课程教师复核台账

## 一、权限边界与使用方式

本台账是 16 课教师复核的唯一入口。AI 以资深教授角色先做事实准确性、跨文档一致性、课堂可执行性、前后课接口、重复与 PPT 映射审查，并直接修复不需要教学判断的客观问题。以下事项不由 AI 代签：

- 教学取舍、课堂负荷与活动时长；
- 学校规范的课程化解释、真实或未发表材料的授权边界；
- 班级人数、分组、提交平台和实际授课条件；
- 是否用真实数据替换虚构教学数值；
- 讲义、教案和正式发布物的最终教师通过。

教师只需处理本文标为 `T-*` 的决定。技术检查通过不等于教师内容通过；未显式确认的项目保持待定。

## 二、固定复核顺序与依赖

固定顺序如下，后续不再从 L1 重排：

1. **L2**：先锁定伦理、权限、披露和工件状态边界。
2. **L4-L6**：复核“精读 → 证据地图 → 问题门”完整上游链。
3. **L7-L9**：复核“机制假设 → 方案分享 → 判断门”；其中 `T-L08-01` 必须先于 L7-L9 最终定稿。
4. **L10-L13**：复核“受限执行 → 循环 → 工作流设计 → 验证门”。
5. **L14-L16**：复核“论文式回写 → 同行评审 → 论证门”；其中 `T-C03` 是三课共用前置决定。
6. **L1/L3 回归检查**：两课已被教师重点阅读，只检查前后接口和后续改版造成的回归，不重复从头审。

课程 2.0 当前只完成 L3 与 L4-L6。L7-L16、L1-L2 的现行材料可以先做教师判断，但其最终发布确认应在相应 2.0 批次落地后再做一次差异复核。

## 六、PPT 教师现场复核

AI 已完成结构、内容提取、来源 notes、布局与 LibreOffice 重开检查。教师无需再审 XML，但仍需在实际 Microsoft PowerPoint、授课电脑和教室投影环境完成一次现场检查：

1. 每课至少打开封面、最密集的方法/清单页、学生实践停留页、知识点总结和退出卡。
2. 检查中文字体替换、16:9 比例、动画/切换、后排字号和链接可点击性。
3. 优先检查 L1 34 页节奏、L2 风险/权限表、L4-L6 MI 证据页、L8 分享计时、L9 P15/P17-P19/P21、L12 八要素页、L13-L16 门条件与虚构数值页。
4. 现场问题只记录现象与页码；AI 可据记录修版并重走受影响的映射与三重检查。

## 七、教师确认记录

教师可直接回复 ID 与决定，例如：

```text
T-L08-01：改为“可证伪命题及其机制假设”
T-C03：保留虚构数值
T-L15-01：只做一轮，第二轮课后
```

AI 收到后负责同步权威源、受影响课次、模板与 PPT，并保留门控记录。没有回复的 ID 不视为默认通过。
