### 历史·二、关键页契约

#### P01｜受限执行把 Agent 帮忙变成可追溯记录
- **页面任务与主结论**：Agent 修改代码、运行测试和归因错误时，研究者必须预先写明审核、权限与记录。
- **主视觉锚点及来源**：`Agent 修改 → 人工审核 → 可追溯记录 → 可安全重复` 单线；课程方法示意。
- **与相邻页的叙事关系**：封面提出张力；P02 回扣第 9 课已有输入与本课产出。
- **最小成立内容**：课名、核心问题、阶段七定位和指向第 11 课的路径。

#### P03｜模糊 prompt 的风险是无法追溯
- **页面任务与主结论**：让学生看见“跑通 / 结果 / 有问题 / 改一下”四个语义坑位如何导致任务边界消失。
- **主视觉锚点及来源**：一条模糊 prompt 分裂为四个不可独立核验的解释；讲义 §二·1。
- **与相邻页的叙事关系**：P02 给任务入口；本页显示缺口；P04 用五字段契约关闭缺口。
- **最小成立内容**：模糊 prompt、四个自行解释、“出错后无法追溯”。

#### P04｜任务契约五字段
- **页面任务与主结论**：任务契约是可被独立检查者复核的工件，不是加长的 prompt。
- **主视觉锚点及来源**：Context / Permission / Non-goal / 人工审核点 / 失败恢复五段契约；讲义 §二·2 教学案例。
- **与相邻页的叙事关系**：解决 P03 的模糊性；P05 对照契约与模糊 prompt 的可追溯差异。
- **最小成立内容**：五字段名称、贯穿案例边界、工件写入位置。

#### P06｜权限分层与人工审核点
- **页面任务与主结论**：权限必须落到任务级具体路径和命令，审核点是“停下来等确认”。
- **主视觉锚点及来源**：只读 / 可写 / 可执行 / 需确认 / 禁止五层，与四个人工审核点共同构成边界；讲义 §三。
- **与相邻页的叙事关系**：P05 说明契约为何可追溯；本页落实执行边界；P07 解释循环错误与失败恢复。
- **最小成立内容**：五层权限、四个审核点、一条“预先写明停下来”的判断。

#### P07｜ReAct 错误传播与失败恢复
- **页面任务与主结论**：契约和日志不消除错误，而是让 reasoning–action–observation 中的错误可定位、可停止。
- **主视觉锚点及来源**：三环循环与五种失败恢复动作；Yao et al., ICLR 2023 与讲义 §三·4。
- **与相邻页的叙事关系**：P06 定义权限与审核；本页定义失败时如何停；P08 转向候选实现的人工核验。
- **最小成立内容**：三环错误传播、超时 / 解析 / 工具 / 越权 / 测试失败五类恢复、不重试到成功。

#### P08｜diff 审查把候选实现变成可验证实现
- **页面任务与主结论**：Agent 产生的代码只是候选，必须经过 diff、测试与研究判断三层核验。
- **主视觉锚点及来源**：六项 diff 审查表为主工件；讲义 §四·1 与 §四·3。
- **与相邻页的叙事关系**：P07 将错误停在执行链；本页检查修改是否进项目；P09 识别已经构成绕过或污染的修改。
- **最小成立内容**：diff 范围、新依赖、禁止层、测试、Non-goal、commit message 六项。

#### P09｜修复根因 / 绕过失败 / 污染实验
- **页面任务与主结论**：只有保留失败记录与根因分析的修复才可接受；绕过失败和污染实验是红线。
- **主视觉锚点及来源**：三行对照表，展示机制处理、可追溯影响和课程案例；讲义 §四·2。
- **与相邻页的叙事关系**：P08 给审查条件；本页给红线判断；P10 借 SWE-bench 说明测试判定仍有局限。
- **最小成立内容**：三类定义、三类对可追溯性的影响、后两类红线。

#### P12｜演示闭环：执行、核验、越权记录与写入
- **页面任务与主结论**：一次受限执行必须同时留下成功 diff 与越权 / 失败记录，才构成可复盘 trace。
- **主视觉锚点及来源**：`Agent 执行 → diff + pytest → 额外人工核验 → 越权拒绝 → 五项工件写入` 操作链；讲义 §五教学案例。
- **与相邻页的叙事关系**：P11 选定任务并写契约；本页完成执行到写入；P13 将相同结构交给学生实践。
- **最小成立内容**：授权修改、测试与额外核验、一条越权拒绝、五项写入工件。

#### P14｜实践停留页
- **页面任务与主结论**：学生可在投屏尺寸下同时读取产出文件结构和 diff 审查六项，不依赖教师口头重复。
- **主视觉锚点及来源**：左侧文件树，右侧六项审查清单；讲义 §五第五步与 §七。
- **与相邻页的叙事关系**：P13 发布七步任务；本页长时停留支持执行；P15 将工件交给同伴互查。
- **最小成立内容**：任务契约、代码、失败记录、AI 使用记录四类写入位置与 diff 六项。

#### P16｜失败与越权复盘、第 11 课预告与退出卡
- **页面任务与主结论**：本课的一次受限执行是第 11 课可安全重复的自动化循环起点。
- **主视觉锚点及来源**：左侧退出卡与红线复盘，右侧 `一次受限执行 → Edit–Evaluate–Keep/Discard–Repeat 循环` 路径。
- **与相邻页的叙事关系**：承接 P15 同伴互查；回应 P01 的边界、审核与记录；引向第 11 课预算、停止与回退。
- **最小成立内容**：失败 / 越权自查、一次执行向循环的路径、不新增正式提交。
