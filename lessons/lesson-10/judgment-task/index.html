    第 10 课研究任务｜Agent 实现实验与定位失败¶

    输入与待判断问题¶

    MI 用于助教演示和短时诊断；下述“迁移到个人研究”在本人项目上完成，研究方向不限于 MI。

    冻结实验协议、baseline 与一项实际缺口。

    实现通过了测试，是否也实现了实验规格中的研究操作？

    AI 可以参与问题、假设、实验选择、分析和评审。先形成个人初始判断，再比较证据与外部意见；这项课堂诊断不等于项目中禁用 AI。把“当前判断—依据—新证据或反馈—最终处理”写入已有项目，不增加独立作业。

    共同诊断与按需 MI 示例¶

    共同诊断优先使用助教研究现场的实现决策点；下述公开代码题是备用输入，与研究现场题择一使用，不追加一轮作答。自学时可直接用公开题检查本课方法。

    以下是课程构造的科研代码比较，不是实际 Agent 轨迹或论文实验。研究规格已冻结：在归纳式预测实验中，只用训练集估计中心化所需的均值，再用同一个均值变换训练集和测试集。输入是非空训练列表和测试列表，元素均为有限实数；本题不讨论其他输入类型。

    def candidate_a(train, test):
    mean = sum(train + test) / len(train + test)
    return [x - mean for x in train], [x - mean for x in test]

def candidate_b(train, test):
    mean = sum(train) / len(train)
    return [x - mean for x in train], [x - mean for x in test]

train, test = [0.0, 2.0], [4.0, 6.0]
# 现有测试只检查：两份输出长度分别等于 len(train)、len(test)。

    先预测两份实现的输出，指出长度测试能支持哪项判断。再设计一个能检查“均值只由训练集决定”的行为检查：固定训练集、改变测试集时，哪些量应保持不变？写出预期后再运行，依据实际输出决定采用哪份实现、还缺什么检查。若一个实现的下游准确率更高，这会改变你对其是否符合本次规格的判断吗？说明理由。

    本题的训练／测试边界来自给定研究规格；若研究目标允许利用未标注测试分布，需要另立协议并重评双方。不要把本题结论升级为所有研究一律采用同一数据使用方式。原字段校验包保留为结构检查和恢复的按需练习。

    MI 研究现场可取这样的决策点：整 token 的 block 替换和 c_proj 前的单头维度替换都可能运行成功，但它们干预的对象不同。选择哪一种取决于冻结的研究主张；普通“无报错”检查不能证明干预语义正确。这是另一种输入的例子，不要求在公开代码题之后再完成一题。

    MI Demo 与个人项目说明：项目路径。场景中的候选判断是教学问题，未标为实际记录的选项不是实验结果。

    迁移到个人研究¶

    从 L9 的同一个人项目中选一项小动作，如一个指标计算、实验干预、数据处理或推导检查。复用已有规格与可运行输入，先说明怎样确认该动作符合研究意图，再给 Agent 明确动作、可写对象和检查条件。确认限制由工具接口还是人工审核实现，实际生成并执行一个补丁或策略实现。

    第一段完成小动作并保存检查结果；中点反馈后，针对观察到的缺口修改或补查，再用相同输入复验。原结果正确时可以保留实现，实际执行一项尚未覆盖的检查，不人为制造错误。代码项目保存 diff 和行为结果；理论或文献项目实际执行反例核验、原文审计或检索策略，保留原始 AI 输出及可定位依据。所有产物回到原项目。

    课前在既有准备预算内带好一份可运行输入和预期行为；课上最低推进是一个实际动作、相称检查及采用／撤回／待查决定，完整原型继续跨课积累。模型不可用时检查本人已保存的真实 AI 产物并实际运行本地检查；若缺少本人 AI 执行证据，保留待补项，不用共同题或教师回放抵扣。

    验证：正常和失败输入都保留；变化涉及协议时重评可比双方，不把旧结果与新协议混算。

    保存与达标证据：实际 AI 动作、diff、行为检查、结果与个人决定。

    下次输入：L11 将动作接入有预算的运行与恢复流程。

    判断时使用的原理¶

    在已获准范围与预算内，可依据失败证据修复实现并复验。涉及规格、评价协议、权限扩大或根因不清时升级审核。通过已有测试只支持其覆盖的行为，研究指标是否有效另行检查。

    完成标准¶

    水平 判断依据
    需支持 能执行动作，但理由、证据定位或验证仍有缺口
    达标 独立解释选择，证据可定位，完成相称检查并更新个人项目
    优秀 识别替代解释或有效性威胁，用实际检查改变或加强判断

    讨论、自愿协作和 AI 参与不改变个人评分。无改善、有依据地保留原方案或仍不能判断都可成立，但须说明依据及下一项会改变判断的证据。不得以模板填写或教师回放替代本人真实 AI 研究动作。

    普通课课外总量最多 60 分钟，包含阅读、准备、安装排障和项目补全；研究门课用同一预算整理提交，不增加必读。断网时可使用保存材料完成诊断，缺失的实际执行仍需按教师安排补核验。
