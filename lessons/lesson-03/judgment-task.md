# 第 3 课研究任务｜多路发现与自适应检索

## 输入与待判断问题

公开问题：IOI 干预能否跨模板迁移；种子论文 arXiv:2211.00593。

**下一轮检索应换词、换语义表达、沿引文扩展还是停止？**

AI 可以参与问题、假设、实验选择、分析和评审。先形成个人初始判断，再比较证据与外部意见；这项课堂诊断不等于项目中禁用 AI。把“当前判断—依据—新证据或反馈—最终处理”写入已有项目，不增加独立作业。

## 共同材料与比较

从同一个问题比较三条真实可执行路线：词法查询 indirect object identification activation patching；语义问题“Which interventions recover indirect-object predictions across prompt templates?”；由种子论文前向／后向追踪。未运行前不填写命中数，工具名字含 Semantic 不证明接口就是语义检索。

共同实验入口：[个人 MI 项目](../../course/micro-project.md)。场景中的候选判断是教学问题，未标为实际记录的选项不是实验结果。

## 迁移到个人研究

让 Agent 在预算内执行首轮，读取结果后选择一次调整。至少运行两条互补路线，其中一条可为引文扩展；若语义接口不可用，记录并改用可用路线，不伪造语义结果。

**验证：**保存实际请求、工具能力、时间、返回记录、独有相关项和一次调整理由；对两条真实来源核对身份与拟用主张。

**保存与达标证据：**notes/literature-search.md：路线比较、调整、来源审计与下一步决定。

**下次输入：**L4 选择一条关键主张回到图表、方法与代码。

## 完成标准

| 水平 | 判断依据 |
| --- | --- |
| 需支持 | 能执行动作，但理由、证据定位或验证仍有缺口 |
| 达标 | 独立解释选择，证据可定位，完成相称检查并更新个人项目 |
| 优秀 | 识别替代解释或有效性威胁，用实际检查改变或加强判断 |

讨论、自愿协作和 AI 参与不改变个人评分。无改善、有依据地保留原方案或仍不能判断都可成立，但须说明依据及下一项会改变判断的证据。不得以模板填写或教师回放替代本人真实 AI 研究动作。

普通课课外总量最多 60 分钟，包含阅读、准备、安装排障和项目补全；研究门课用同一预算整理提交，不增加必读。断网时可使用保存材料完成诊断，缺失的实际执行仍需按教师安排补核验。
