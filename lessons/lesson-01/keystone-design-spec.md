# 第 1 课关键页设计规格

依据 [正式课堂 PPT 设计准则](../ppt-design-criteria.md) v1.2.0。本文件只规定第 1 课风险较高页面的视觉任务、主视觉锚点、相邻页关系和最小成立内容；屏显文案、讲述、互动、时间和来源以 [slides.md](./slides.md) v1.7.0（34 页）为唯一现行母稿。

## 一、关键页集合

现行关键页为：`P01 / P03 / P04 / P05 / P06 / P07 / P08 / P10 / P18 / P19 / P20 / P21 / P23 / P26 / P28 / P29 / P31 / P34`。

| 风险类型 | 页面 | 选择理由 |
| --- | --- | --- |
| 开场与收束 | P01、P34 | 建立并回应“AI 参与后谁负责” |
| 课堂互动 | P03、P31 | 第一次诊断动作与 27 分钟个人实践主屏 |
| 证据边界 | P04、P05、P06 | 论文身份、系统能力边界、三系统对比、观察性结果与非因果限定 |
| 课程与项目骨架 | P08、P10、P18、P19、P20、P21、P23 | 方法/工作流冲突、项目工件、八阶段因果关系、回退与追溯 |
| 课程命题与控制链 | P07 | 从前沿案例收束到五道质量控制门，不依赖装饰图 |
| 人工审核、真实工件与失败恢复 | P26、P28、P29 | 候选建议审核、diff/log、越权停止、收窄和核验决定学生是否看见可审计交互 |

其他页面不填四字段契约，但仍须通过全局准则的“所有页面”、相应页型和全卷验收。

## 二、关键页契约

### P01｜AI 可以参与科研，研究责任仍由人承担

- **页面任务与主结论**：建立全课核心张力；AI 可以参与动作，但问题、证据、实验和结论的责任仍由研究者承担。
- **主视觉锚点及来源**：课程名与中心判断句形成聚焦构图，背景只保留弱化的“问题—证据—实验—结论”链路。来源为课程结构，不使用生成图。
- **与相邻页的叙事关系**：作为封面模板例外；P02 转入讲师与课程关系，不重复责任链。
- **最小成立内容**：课程名、中心判断句、`2 学分｜32 学时｜研究生专业选修课`。

### P03｜你最近一次把 AI 输出当成了什么？

- **页面任务与主结论**：完成第一次课堂诊断；同一类 AI 输出可能在工作流中被当作线索、草稿、证据或结论。
- **主视觉锚点及来源**：一个横向互动选择带，四个大号编号与角色词作为同一组选择关系；选项可以独立点击/指认，但不用阴影和装饰性卡片。
- **与相邻页的叙事关系**：P02 建立授课者身份，本页让学生暴露已有判断；P04 用真实研究系统案例追问“完整产物”的证据角色。
- **最小成立内容**：问题句、四个选项、课堂投票动作；不显示预设正确答案。

### P04｜AI Scientist 已串联 ML 研究的构思、实验、写作与评审

- **页面任务与主结论**：承认端到端系统能力，同时阻止把 workshop 首轮评审外推为科研普遍成立。
- **主视觉锚点及来源**：左侧以 Lu et al. (2026) Fig.1a 原图裁切为主体，完整保留 Ideation、四阶段 Experimentation tree search、Write-up 与 Paper AI review；右侧以大号 `1/3`、`6.33` 和无卡片边界栏解释证据强度。图注保留作者、期刊、年份、图号与 CC BY 4.0。
- **与相邻页的叙事关系**：回应 P03 的“输出角色”；P05 再从单个系统扩展到多步研究工作流趋势。
- **最小成立内容**：Fig.1a 四阶段系统结构；`1/3` 稿件超过 workshop 平均接受阈值；该稿件平均分 `6.33`（6/7/6）；输出经人工筛选后提交；workshop 首轮评审且论文报告接受率 70%；3 篇均未达 ICLR 主会标准；仅限 ML 计算实验；`完整产物 ≠ 科研成立`。

### P05｜从研究环节到多步系统，人工仍在关键位置

- **页面任务与主结论**：把 P04 的单个 AI Scientist 案例放回时间与类型坐标；从 2023 综述的全流程框架推进到 2026 两套具体多步系统，人工判断与实验核验仍不可省略。
- **主视觉锚点及来源**：Wang et al. 2023 综述、Co-Scientist 与 Robin 的三列固定维度比较矩阵；每列只比较研究场景、连接动作、人工位置和证据边界，并标明论文身份、期刊与年份。第一列必须明确是综述框架，不得伪装成一套实际系统。
- **与相邻页的叙事关系**：P04 已完整讲 AI Scientist，本页不再重复它，而用 2023 综述建立环节框架，再以 2026 Co-Scientist/Robin 展示具体系统如何连接部分动作；P06 随即追问工作流扩展是否等于科学整体改善。
- **最小成立内容**：2023 综述框架、Co-Scientist、Robin，研究场景/连接动作/人工位置/证据边界四个固定维度，以及`从全流程框架到多步系统，人工判断与实验核验始终不可省略`。

### P06｜个人产出扩大，不等于科学整体探索范围扩大

- **页面任务与主结论**：让学生直接读取个人层面与集体层面的方向冲突；个人论文和引用优势与科学整体探索范围扩大不是同一个判断。
- **主视觉锚点及来源**：Hao et al. (2026) 四个关键结果的忠实重绘形成左右对照：个人层面的 `3.02×`、`4.84×` 与集体层面的 `−4.63%`、`−22%`。论文身份、指标名称、样本与识别方法、观察性限定同框；不再缩放完整 Figure 2/3。
- **与相邻页的叙事关系**：P05 描述工作流扩展趋势，本页加入反向证据和方法边界；P07 将冲突收束为课程任务。
- **最小成立内容**：两类结果的可读对照、四个数字及其指标、约 4130 万篇自然科学论文、六学科、标题/摘要模型识别 AI 使用，以及`观察性关联，相关不等于因果`。重绘不得把集体层面结果泛化为所有层面收缩。

### P07｜本课程解决的是“如何控制研究质量”

- **页面任务与主结论**：把 P04-P06 的能力、人工位置和证据边界收束为课程行动框架；AI 可以扩展候选，关键动作必须可核验、可约束、可追溯。
- **主视觉锚点及来源**：一条可编辑的五道质量控制链：定义问题 → 核验证据 → 约束行动 → 限定结论 → 承担责任。每道门以编号、动词和一句检查问题构成同一连续对象；来源为课程结构，不使用生成式人物图。
- **与相邻页的叙事关系**：P06 展示效率与范围可能分离，本页给出课程如何回应；P08 再把研究判断质量和工程工作流质量拆开检查。
- **最小成立内容**：课程命题、五道门、`可核验｜可约束｜可追溯`。删除任意一道门都会使课程控制链不完整。

### P08｜研究判断与工程工作流必须放在一起

- **页面任务与主结论**：建立核心冲突；工程过程可检查，不等于研究主张已经成立。
- **主视觉锚点及来源**：明确标注“虚构教学情境”的研究提交，左侧呈现 `evidence missing / baseline unclear`，右侧呈现 `Context / Permission / Diff / Log`，中间突出 `≠`。
- **与相邻页的叙事关系**：P07 给出课程任务，本页拆开方法质量与工作流质量；P09 再定义课程评价的完整闭环。
- **最小成立内容**：两侧判定、`≠`、`可检查 ≠ 已成立` 和虚构标记。

### P10｜16 周后，你应拥有一个可继续发展的研究雏形

- **页面任务与主结论**：把课程最终状态落到一个持续生长、可继续研究的个人项目，而不是一组孤立作业。
- **主视觉锚点及来源**：研究仓库树为唯一主视觉，显示五个核心工件和 `draft → review → approved → stable` 状态；课程路径压缩为底部次级带，不与仓库争夺视觉中心。
- **与相邻页的叙事关系**：P09 说明评价对象，本页展示具体项目形态；P11 转入进入该项目所需的先修能力。
- **最小成立内容**：研究仓库、五个工件、状态流和一句“所有课堂练习回写同一项目”。四门路径只保留能读清的次级提示，详细门关系由 P13/P22 承担。

### P18｜八阶段让我们知道当前在修改什么

- **页面任务与主结论**：给出全课共同语言；学生能够定位当前修改的是问题、假设、证据、判断、验证还是表达。
- **主视觉锚点及来源**：八节点单线主链与简洁回退提示，使用可编辑结构图；节点、箭头和标签均按投影字号检查。
- **与相邻页的叙事关系**：P17 暴露“报告完整但过程不可查”，本页给出定位骨架；P19/P20 在同一视觉语法上展开阶段内容。
- **最小成立内容**：八个阶段、可回退信号、`无论回退还是迭代，都知道当前在改什么`。

### P19｜阶段 1-4：问题定义、第一性原理分析、机制假设与外部输入摄取

- **页面任务与主结论**：让学生看见阶段 1-4 是一条可质疑的因果结构，而不是四项并列清单；AI 可以扩展候选，不能宣布机制成立。
- **主视觉锚点及来源**：问题定义边界 → 必要条件 → 待验证机制形成连续主链；论文、代码、数据、规范和观察从外部馈入。机制链使用虚线语义并保留问号，来源为本课贯穿案例，不使用外部事实图。
- **与相邻页的叙事关系**：P18 给出八阶段定位，本页展开形成研究主张前的四个阶段；P20 接着展示证据如何进入判断、验证与回写。
- **最小成立内容**：问题边界、必要条件、`阅读卡 → 原文定位 → 限定遗漏变化？` 待验证机制、五类外部输入，以及`AI 可以生成候选，不能宣布机制成立`。

### P20｜阶段 5-8：证据整理、研究判断、原型验证与回写表达

- **页面任务与主结论**：说明证据、判断、验证和结论之间既有正向推进，也必须能反向追溯；证据不会自动生成判断。
- **主视觉锚点及来源**：四象限证据地图、判断记录、含 baseline 的实验规格和结论回写使用不同工件形态；底部反向核验线把结论连回证据、决定和实验。来源为课程八阶段和轻量工件追踪规则。
- **与相邻页的叙事关系**：承接 P19 的待验证机制，把候选转为可审查工件；P21 再说明这些阶段允许带记录地回退。
- **最小成立内容**：支持/反驳/冲突/空白，采用/放弃/边界/待验证，baseline/变量/指标/预算/停止条件/失败，以及结论反向核验问题。

### P21｜八阶段不是瀑布流程，而是带记录的回退

- **页面任务与主结论**：纠正线性误读；研究可以回退，但必须记录为什么回退以及哪些判断受影响。
- **主视觉锚点及来源**：复用 P18 的八阶段对象并显著改变状态：链路弯成循环，四条典型回退高亮，回退原因成为标签。
- **与相邻页的叙事关系**：允许与 P18 保持对象连续性，因为 P19/P20 已展开阶段，且本页从“定位”推进到“带原因回退”；P22 将回退约束连接到研究门。
- **最小成立内容**：阅读→问题、实验→假设、写作→取证、越权→任务与权限四类回退，以及`可以回退，但要知道为什么回退`。

### P23｜追溯与核验：结论可反向检查，AI 输出不跳过核验

- **页面任务与主结论**：收束八阶段段落；任何结论都能反向追问来源与决定，AI 输出不能越过人工核验成为证据。
- **主视觉锚点及来源**：一条双向追溯链为主体，正向表示研究推进，反向表示审查；AI 输出候选在进入证据/结论前经过明确的人工核验边界。
- **与相邻页的叙事关系**：P22 说明错误在哪一道门被阻止，本页说明如何反向查到根因；P24 将原则转为一次 OpenCode 演示。
- **最小成立内容**：`来源 → 主张 → 研究判断 → 行动/实验 → 结果 → 结论`、反向审查问题、人工核验边界。

### P26｜先检查建议是否值得采用，再决定是否写入

- **页面任务与主结论**：把 Agent 输出从“看起来合理”降回候选状态；只有经过研究者审核的建议才可能进入写回。
- **主视觉锚点及来源**：三个明确标注为虚构教学输出的建议进入四问审核轨道；一项标为合理候选、一项待核验、一项标为模型自行补充事实的高风险表述。来源为课程自编固定示例，不构成事实证据。
- **与相邻页的叙事关系**：P25 先建立只读任务契约，本页完成研究者审核；P27 才对被确认的建议授予目标文件写回权限。
- **最小成立内容**：三个有实质内容的建议、四项审核问题、至少一个合理候选和一个高风险表述，以及`采纳｜修改｜拒绝｜待核验`的研究者决定。

### P28｜“完成”之后还要检查 diff 和使用记录

- **页面任务与主结论**：让学生以实际文件变化和记录判断结果，不只听 Agent 自述“完成”。
- **主视觉锚点及来源**：简化但可读的 `git diff` 与 `ai-usage-log.md` 记录构成精读工件；使用明确标注的虚构教学内容。
- **与相邻页的叙事关系**：P27 完成受限写回，本页检查实际变化；P29 把失败和越权同样纳入记录。
- **最小成立内容**：一段删除/增加 diff、一条使用记录、`以实际文件变化为准，不只看 Agent 自述`、虚构标记。Consolas 与 18 pt 下限须在授课环境复核。

### P29｜失败不是重跑到成功，而是工作流评价材料

- **页面任务与主结论**：让学生把越权或失败转化为可审计的恢复过程；失败后应停止、保留记录、收窄任务、在新边界内重试并人工核验，而不是删痕重跑。
- **主视觉锚点及来源**：上部为明确标注的虚构越权请求，中部以范围、隐私、许可、凭据、可逆性和恢复方式六项审计问题定位风险，下部以`停止 → 记录 → 收窄 → 重试 → 核验`五步恢复链形成主行动对象。来源为课程任务契约与伦理模板。
- **与相邻页的叙事关系**：P28 检查成功写回后的 diff/log，本页把同一可审计原则扩展到失败与越权；P30 回到学生可安全选择的最小起点。
- **最小成立内容**：越权请求、六项审计问题、五步恢复链和`失败记录用于评价工作流`。不得只显示 STOP 或风险标签而缺少如何继续。

### P31｜个人实践：完成一次“只读—审核—写回—记录”

- **页面任务与主结论**：作为 27 分钟持续停留的学生行动页，让每人完成一次最小可审计交互。
- **主视觉锚点及来源**：左侧最小工作区，右侧行动与验收链，顶部明确学生可见的剩余时间/时间段；备用路径作为同一任务的替代入口，不另做说明卡片。
- **与相邻页的叙事关系**：P30 完成选题，本页从选择进入执行；P32 用同伴三问检查能否复原“建议—判断—修改”。
- **最小成立内容**：输入范围、只读→审核→有限写回→检查 diff/log、完成条件、模型不可用时的纸面/Markdown 备用路径。

### P34｜首课不求完整，只求留下一个可检查的起点

- **页面任务与主结论**：回应 P01；学生不需要完成研究，但必须留下第一处可检查的人工判断、修改和记录。
- **主视觉锚点及来源**：一个已完成的最小闭环为主体，退出卡字段作为检查点，下一课“权限与披露”作为次级去向；不使用通用致谢页。
- **与相邻页的叙事关系**：承接 P32 的同伴反馈并收束本课；把未解决的材料、权限和披露问题交给第 2 课。
- **最小成立内容**：最小闭环、退出卡、下一课去向和`一个可检查的起点`。

## 三、模板例外与制作约束

- P01 使用封面例外；标准红色内容标题带不压缩中心判断句。
- P06、P28 属于精读工件页，可以扩大正文有效区，但不得移除论文/工件身份、品牌识别与来源位置。
- P03、P31 属于互动任务页；学生动作和完成条件优先于装饰，时间仅在确实面向学生时屏显。
- P04、P10、P21、P23、P31 的现行标题较长，制作前先使用完整标题带可用宽度；仍无法在 30–32 pt 单行显示时，必须同步修改 `slides.md` 标题。
- 动画只用于逐步出现或淡入。P18→P21 的对象连续性用页间递进表达，不依赖 Morph 才能理解。

## 五、进入正式制作的条件

1. 本文件的 12 页契约与 `slides.md` 当前页号、屏显主张和来源一致。
2. 普通页面按全局开放轮廓与三类密度分型，不新增第二套屏显文案。
