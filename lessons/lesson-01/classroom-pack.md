# 第 1 课课堂材料包

## Pi Agent 操作口径

本课主平台为 Pi Agent，OpenCode 等为备选。按 [Pi Agent 最小启动说明](../../course/pi-setup.md)先只读生成建议；教师组织学生判断并确认目标段。Pi 默认没有逐次权限弹窗，只有通过复演的限制配置才用于 Agent 写回；未配置时由助教人工应用批准文本，日志注明实际操作者。`NETWORK off` 指不进行额外联网检索或外部操作，模型后端连接按批准的数据规则使用。后续 diff 核对、人工补修改记录与使用日志的顺序不变；离线材料仍标注构造回放。

## 一、最小 prompt（可复制版）

【可替换处】换成你自己的内容；完整版与字段说明见讲义 §五。

**第一轮（只读，步骤 2）**

```text
读取 AGENTS.md 和 problem-definition.md 中的当前问题。

目标：提出三个范围收敛建议。
每条建议必须包含：建议修改的范围、依据、可能损失、需要研究者确认的问题。

限制：不修改任何文件；不访问项目以外目录；不联网；不把建议写成已证实事实。
```

**第二轮（受限写回，步骤 4）**

```text
根据我确认的第【N】条建议：
1. 本次明确授权：只修改 problem-definition.md 的“当前问题”段；
2. 不写修改记录、AI 使用日志或其他段落；
3. 不修改其他文件，不访问网络。
完成后给出：修改摘要、实际修改的文件、仍需人工核验的内容。
```

教师核对实际 diff 后，人工将原表述与理由记入修改记录，并填写 ai-usage-log.md；这两项不属于第二轮 Agent 写入范围。

## 二、纸面任务契约（模型不可用者使用）

在纸面或 Markdown 中写出：

- 第一轮预期：Agent 只读后可能给出的三条收敛建议（各含范围/依据/损失/待确认）；
- 人工取舍：采纳哪条、拒绝哪两条及理由；
- 第二轮预期写回：目标段落的新表述，以及由人核对后保留到“修改记录”的原表述。

## 三、预期 diff 样例（标"预期非实际"）

```diff
# 预期 diff（模型不可用时的纸面替代；非实际执行结果）
--- a/problem-definition.md
+++ b/problem-definition.md
- 阅读卡能消除摘要遗漏。
+ 对同一组公开计算机论文，结构化阅读卡与自由摘要相比，是否降低生成内容的限定条件遗漏率？
```

纸面路径验收时，根据本人选择形成"预期 diff"并供互查，并在 AI 使用记录中按 §四 口径注明未执行。

## 四、AI 使用记录空白（表头以 starter-template §6 为准）

| 日期 | 工具 / 模型 | 用途 | 关键输入 | Context / 数据来源 | 输出用途 | 人工核验方式 | 问题或误导 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

模型不可用口径：工具/模型栏写"未执行：模型不可用"，用途栏写"纸面完成任务契约与预期 diff"，人工核验方式栏写"教师/同伴纸面核对"；不伪造执行记录。未调用但完成人工判断时，写"本次为人工判断，无模型参与"并记录判断内容。

## 五、纸面验收三项（教师用）

- 任务契约含第一轮只读边界（纸面路径以"写出只读边界"替代"Agent 第一轮没写文件"）；
- 取舍有理由，写回限定目标段落且原表述保留；
- 预期 diff 与使用记录口径一致，标注"预期非实际"。

## 七、教师与助教的演示交接（现行 P22–P28）

- 教师在 P22 指出“阅读卡能消除摘要遗漏”的对象、定义与验证缺口：本次先收窄问题，后续再定义遗漏和准备比较材料。
- 助教从干净演示副本开始，打开含“当前问题”和“修改记录”的 problem-definition.md，以及 AGENTS.md、ai-usage-log.md。初始当前问题为“阅读卡能消除摘要遗漏。”；修改记录与日志留空。
- P23–P24 助教执行第一轮只读建议；教师请学生预测权限和审查建议，不要求跟着操作菜单。
- P25 的三条建议是课堂构造的讨论材料。现场模型输出可能不同：保留实际输出并逐条说明采纳、修改或拒绝；模型不可用时明确切换为构造回放，不将预制内容称为真实模型输出。
- P26 只授权“当前问题”段。P27 先检查实际 diff，再由人填写修改记录与日志。实际输出与屏显示例不同时，解释差别，不强凑示例。
- P28 保留越界失败回放：停止写入、保留输入和差异、仅恢复本次演示副本的越界变化、收窄任务重试、再次核对。预制失败须明确标为构造回放。
- 教师收束：“本次完成阶段一的问题修订。下一步定义遗漏并准备比较材料；阅读卡效果仍待验证。”

无模型时沿用纸面路径，注明“未执行”。复用阅读卡题的学生独立选择一处概念或范围、写明理由，形成自己的预期 diff；直接复制本包示例不算完成判断。
