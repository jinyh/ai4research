# 第 1 课共同诊断｜问题收敛中的取舍

## 先独立判断

**问题：两项收敛建议各改变了什么，哪项更适合当前证据和预算？**

输入：一个宽泛问题；现成项目骨架。先记录判断和依据，再与同伴比较；课堂校准后可修订并写明改变原因。答案有分歧时回到具体记录。已有示例可作方法参考，不替代本人的初始判断。

## 原始材料与待比较选项

教学构造输入，尚无效果实验。原问题：“阅读卡能消除 AI 摘要遗漏吗？”

现有资源：3 段公开教学文本、每段两种保存输出；文本与输出已经公开；有 Python 环境；没有新模型额度。作者希望本学期留下可复查实现。

| 建议 | 研究对象与动作 | 仍需获得的证据 |
| --- | --- | --- |
| A | 比较结构化阅读卡与自由摘要在这些保存输出上的限定条件遗漏 | 人工逐条标注；明确保存输出的构造身份 |
| B | 检查输入校验能否阻止缺字段、空值记录进入阅读卡评价队列 | 错误输入集、正常对照、实际执行 trace |

两项建议都可收窄原问题，但回答的对象不同。

**待决定：**A：研究保存输出差异；B：研究队列可靠性；C：自行修订，但维持现有资源范围。

把“初始判断—证据位置—仍缺什么—核验后决定”写在现有笔记中。允许回答“仍不能判断”，同时指出下一项能改变判断的证据。

## 迁移到本人项目

从 A/B 中选一项或修订一项；在 problem-definition.md 写出研究对象、牺牲的范围、所需证据和待查条件。只改“当前问题”段，人工核准后保存实际 diff。

**验证：**同伴依据 diff 找到范围变化；检查使用记录是否区分 AI 建议和作者决定。没有模型时用人工建议完成，记录实际情况。

**保存位置与达标证据：**problem-definition.md 的修订段＋同一条 AI 使用/人工操作记录及 diff。

**下课去向：**L2 以这次修改的读写动作设权限。

## 完成标准

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

断网时保留同样的判断要求，使用包内文本、存档或本地工件。工程课纸面诊断仅作备用练习，最终仍须补本人实际执行、实质修改和对照评价。提前完成者可寻找一个使自己决定改变的反例；不增加课后任务。
