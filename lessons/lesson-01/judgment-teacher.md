# 第 1 课判断依据与组织提示（教师）

## 揭示顺序

先发 [学生任务](./judgment-task.md)，独立作答与同伴比较后再揭示本文件。既有完整演示和答案属于校准/参考材料，避免在首次作答前投屏。已公开示例和 gold 不得称为未见过的评价集。

## 可接受判断与依据

A 可以训练输出比较，但这些构造输出不足以证明模型效果；B 更适合作为无需额度的默认微型工程问题。允许选 A 并把结论限定到公开输出审计，同时为后续实质实现定义一个独立动作。理由必须联系资源和可检验证据；不能仅因 B 能写代码而选 B。

## 追问与形成性评价

- 学生作出决定时实际使用了哪个原文位置、字段或事件？
- 哪个观察会使决定改变？为何另一个选项暂不采用？
- 回到本人项目后实际改了哪里？同伴能否从输出反查证据？

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

## 本人迁移的两次检查

第一段检查：从 A/B 中选一项或修订一项；在 problem-definition.md 写出研究对象、牺牲的范围、所需证据和待查条件。只改“当前问题”段，人工核准后保存实际 diff。

中点点评：优先处理把示例结论当成本人结果、证据位置不明确、修改未进入工件三类卡点；具体追问以本课争议为准。

第二段检查：同伴依据 diff 找到范围变化；检查使用记录是否区分 AI 建议和作者决定。没有模型时用人工建议完成，记录实际情况。

## 备用路径与负荷观察

材料无法联网时使用本地任务输入；无模型时人工作答并如实标记。工程课记录纸面方法练习，另在后续既定预算内安排 CPU 实际运行。工具排障超过课前准备的 10 分钟即切换备用，不以额外安装作为达标条件。

助教试做记录实际耗时、提示次数、停滞位置和回写是否完成。尚未进行学生计时试做；桌面推演不能替代实际完成时间。超出 60 分钟课外上限时，优先减少输入规模/阅读范围并在课堂补关键判断，不增加课后负担。

## 内容边界

真实来源、实际执行、保存输出回放与教学构造按学生任务所示区分；构造材料只支持方法练习。教师确认与实际授课验证在课次 README 分别登记，本轮不沿用历史通过状态。
