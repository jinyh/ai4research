# 虚构教学样例｜Agent Workflow 评价报告

> **虚构教学工件：以下数值、运行 ID、论文集合和人工审核记录均为课程构造，非真实实验结果。**

## 1. 评价设置

- 动作：用结构化阅读卡摘要论文，强制定位原文。
- 输入：同一批 20 篇虚构教学用 CS 论文清单，版本 `set-v1`；每篇论文分别进入结构化阅读卡组和自由摘要组。
- 协议：虚构 `rubric-v1.2`；主指标为相对于人工建立并经复核的限定条件基准计算的限定条件遗漏率，而不是“缺失字段数 ÷ 5”。
- 对照：自由摘要 baseline；两个条件各运行 3 次，共 `20 × 2 × 3 = 120` 次输出。3 次运行用于演示随机性报告，不是所有学生项目的统一次数门槛。

## 3. 失败与审核

- 图表为主子集的负向结果保留；根因暂记为任务契约边界，不删除、不隐瞒。
- 虚构人工审核 `review-003`：3 条证据角色错标，2 条经补证后采纳，1 条保留异议；后者的依据只是博客转载，暂不能进入正式证据链。这个分布来自具体判断，不要求每次审核必须出现某类处理动作。

## 4. 影响与状态

- 保留阅读卡定位原文步骤，但将图表为主论文标记为不适用范围。
- 证据强度：中等；冲突和缺失已保留。
- 验证门：示例中 A1/A2/A3 与外部有效性仍待补；结果状态应写为“方向支持 H1、机制仍不能判断”，不应标记为 `stable`，也不能用“不显著”证明某个机制不存在。
