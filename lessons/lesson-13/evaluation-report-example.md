# 阅读卡评价报告样例

输入与判定来自[连续小包](../lesson-11/assets/reading-card-workflow/README.md)。三份源文本、六份输出和参考标注均为教学构造；不存在真实模型实验。评价者须逐项复核语义，程序只检查记录与汇总。

## 1. 协议

同一 T01–T03 分别进入 card/free。每份材料每条件一份预制输出，共六份。基准条件为 3+3+2，每条件分母 8；按条件逐项合并。无随机重复，不报告误差条或显著性。命题定义见[统一案例](../../course/reading-card-case.md)。

## 2. 可复算结果

| 对象 | card | free | 判断 |
| --- | --- | --- | --- |
| T01 | 0/3 | 2/3 | 改善 |
| T02 | 1/3 | 1/3 | 无改善 |
| T03 | 2/2 | 1/2 | 负例保留 |
| 合计 | 3/8=0.375 | 4/8=0.500 | card-free=-0.125，限于构造材料 |

来源定位：sources.json → gold.json → outputs.json → annotations.json → 本次运行目录 evaluation.json。T03-c1 与 T03-c2 可逐项反查。

## 3. 判断与局限

Q1 的总体方向在构造材料中一致；H1 机制与 A2 测量解释仍不能判断；A1 其他错误未评价；A3 范围受 T03 负例限制。该包只训练评价方法，不作为阅读卡效果的科研证据，不标 stable。

## 4. 失败与下一步

技术失败是人为注入的 T02-card 超时，保留原事件并用新 run ID 恢复；负例是 T03 输出评价更差。先将图表条件提取不足写为待查原因，核对解析记录或设计对照。下一版本如收窄范围，保留本版本三份材料、原汇总和变更理由。

## 5. 研究决定与披露

决定：保留当前包作为教学评价演示；机制和真实任务效果另行验证。人工检查标注片段、分子分母、T03 与总表一致。未调用模型；回放日志仅说明程序实际执行了保存、恢复和汇总。
