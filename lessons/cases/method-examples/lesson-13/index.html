    L13 按需方法案例输入¶

    身份：保留的教学构造或具名来源分析；按各段说明区分。它不是学生的默认个人项目，也不要求跨课连续完成。以下保留原案例叙述；其中跨课措辞描述该构造包的历史关系，不规定当前课堂进度。

    五、方法示例：从工作流原型到验证门材料¶

    本课使用连续小包已有六份构造输出与参考标注，不从零生成。源文本、输出和标注均为教学构造；程序回放和汇总会产生实际日志。

    1. 从一项标注到一张对照¶

    先对回源文本中的一项限定条件，核验输出是否保留。程序随后检查每项标注完整、引用片段存在，按每条件八项合并：

    材料 阅读卡遗漏 自由摘要遗漏 观察
    T01 0/3 2/3 改善
    T02 1/3 1/3 无改善
    T03 2/2 1/2 阅读卡更差
    合计 3/8 = 0.375 4/8 = 0.500 差为 -0.125；仅限构造材料

    不画误差条，不从本包推断真实科研效果或机制。程序只汇总参考标注，语义判断仍须人工对回原文。

    2. 分层回写判断¶

    对象 当前判断
    Q1 结果 本构造材料总体方向一致；T03 方向相反，必须保留
    H1 机制／A2 测量解释 未提供可区分证据，仍不能判断
    A1 整体质量代价 未标注其他错误，不作整体质量判断
    A3 范围 T03 图表描述材料为负例，范围需进一步检查
    采用决定 先核查 T03 的解析和评价记录，拟定下一版验证；原版本结果保留

    3. 负例、原因候选与下一版本¶

    “图表条件提取不足”先记为原因候选。T03 输出确实遗漏两项条件，但是否由解析、生成步骤或其他因素造成，需要定位记录或补对照。若下一版改字段、修解析或限定文本材料范围，另记版本和评价计划；原三份材料及总体结果不变。

    4. 运行与人工审核¶

    T02-card 的人为超时是技术失败，有失败 run ID 和恢复后的新 run ID；T03 是评价负例，二者分开。人工审核记录写清核验了哪条标注、是否采纳、理由和对应输入/输出。材料能否支持主张按原始来源、内容与范围判断，不能只凭是否同行评议。

    5. 最小课堂与课后¶

    课堂完成一张对照、一项局限和一条判断修订。课后补齐伦理、权限、人工审核和验证门条件。使用教师包完成练习时，离场卡另记本人项目仍缺的输入及回写位置，不能把构造案例当作个人研究结果。

    分层判断的完整构造例¶

    沿用阅读卡构造包：三个源文本各进入两个条件，按参考条件合并后 card 遗漏3/8，free遗漏4/8。这些数值是可复算的教学输出，不是新取得的真实研究结果。

    本例的 Q1 问“同源文本下结构化阅读卡是否减少限定条件遗漏”。H1 提出生成时的结构约束帮助模型关注并保留条件；A2 则提出评价者看见字段或格式提示而改变评分，汇总差未必代表输出实际少遗漏。二者可以同时成立。保持输出语义不变、隐藏格式提示后重评：若差异消失，会加强 A2 的解释；若仍存在，只能削弱这一测量解释，不能单独证明 H1。比较生成机制还需相应生成对照。完整编号见阅读卡构造例。

    层次 现在能说什么 下一步缺什么
    观察 此包合并后的遗漏率差为−0.125，即−12.5个百分点；T03方向相反 核对逐项标注、分母与材料身份
    结果命题 在此构造包内，Q1方向一致 真实目标材料的抽样与不确定性，不能用包内方向推总体
    机制解释 H1与A2均未区分 控制生成和评价呈现的区分性证据
    采用决定 可作为后续验证的候选 核验时间、其他错误与适用范围，尚不足直接采用

    RSI历史结果的有限结论¶

    身份：既有合成环境的实际CPU运行；未新增研究结果。

    RSI 冻结结果中，异质量 K=16 的均匀减随机选择损失区间在零以下，而 K=4、64 跨零。限定设置可以支持有限比较，不能写成均匀分配普遍更好，更不能写成新定向补测机制已成立。同一重复内的方法共享证据，配对差异按独立重复统计。
