    L12 按需方法案例输入¶

    身份：保留的教学构造或具名来源分析；按各段说明区分。它不是学生的默认个人项目，也不要求跨课连续完成。以下保留原案例叙述；其中跨课措辞描述该构造包的历史关系，不规定当前课堂进度。

    五、方法示例：把同一阅读卡任务升级为工作流¶

    继续使用L11 小包，不新换科研题目。统一命题与数字见案例口径。

    要素 实体材料或动作
    任务 回放并评价同材料的两种构造输出
    Context sources.json 与 outputs.json
    Memory／持久状态 state.json；events.jsonl 保存已执行与失败历史
    工具与权限 read_resource 接口按 executor/evaluator 角色检查允许资源
    工件 输入身份摘要、输出事件、参考标注、evaluation.json
    执行 六项固定队列，恢复只处理未完成项
    Evals evaluator 读取 gold/annotations，程序验证结构和引用、汇总人工判定
    人工审核 查看失败后决定恢复，复核语义标注，解释有限结论

    运行 access-check 可产生真实的接口拒绝与记录。该接口未提供操作系统级沙箱，不能把它讲成任意代码都无法访问磁盘文件；课堂说明当前控制模型及实际发生的行为。

    本包选择确定性回放加固定链，因为输入与操作已固定。实际科研动作若需要动态分解和工具选择，再说明使用 Agent 的理由；工具数量与自主程度不是评分目标。

    复演时依次打开输入、一次事件、state、评价报告；本人从输出反查源文本与版本，也可邀请他人开放讨论。只有目录图或预期输出不能替代这个过程。
