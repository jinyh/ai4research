# 第 6 课教师教案｜问题定义、第一性原理与问题门


## 整体复审补充：板书、诊断与串词（2026-09-15）

本节替换同类口头提示，不增加既有时段。开场诊断嵌入现有开场/回顾，后续再沿原实践时段操作。

- **板书主线**：问题谓词 → 反证观察；效果 / 成本 / 采用分开。
- **诊断问题**：效果较好但成本高，究竟推翻了哪条命题？
- **预期回答**：可能影响采用决定，不能直接推翻效果命题。
- **常见误答后的追问**：要求对准命题的范围、结果谓词和不确定性。
- **过渡串词**：“下一课为这个结果命题补机制，并找能区分的观察。”
- **当堂最小产出**：一条可检验问题及一项本人问题门缺口。
- **退出记录**：写“已完成的动作、本人项目仍缺的证据/工件、下次补齐位置”。使用教师包时标明课堂方法练习，不能据此宣称本人研究门通过；正式提交课次仍为第 6、9、13、16 课。


## 一、本课定位

- 学时：2 学时，90 分钟
- 研究链路：阶段一"问题定义"+ 阶段二"第一性原理分析"
- 教学类型：讲授 + 教师演示 + 个人实践 + 同伴互查
- 核心问题：如何把研究空白收敛为范围清楚、可证伪、周期可完成的问题？
- 课堂产出：问题门材料初版（problem-definition.md + 第一性原理推导）
- 正式提交：**问题门材料包**（第 6 课后）

本课必须建立三项共识：

1. 研究空白本身还不是研究问题；它需要被改写为包含条件、对象、干预、结果和可证伪性的结构性问题。
2. 第一性原理分析在本课程中指识别基本约束、作用机制和不可违背条件并推导待验证前提，不是脱离文献的通用捷径；推导结果必须继续接受外部证据检验。
3. 问题门检查的是当前项目版本是否满足九项条件，包括一条已回写的真实失败/死路记录；第 1-5 课所有产出都已回写同一项目。

本课是全课第一次正式提交节点。第 7 课将在这些问题上建立机制假设和实验设计，因此问题定义的质量直接决定后续链路能否展开。

## 二、学习目标

完成本课后，学生能够：

1. 区分主题、研究问题和待验证主张，并把宽泛兴趣改写为范围清楚、可证伪、周期可完成的研究问题；
2. 用非例界定问题边界，说明什么不算本问题；
3. 写出至少一个可证伪命题，指明什么观察结果会使主张不成立；
4. 从基本约束、作用机制和不可违背条件推导待验证前提，并说明第一性原理分析的适用边界；
5. 用"So what?"和"Who cares?"检查问题重要性，并交叉检查问题来源；
6. 用意义、可行性和兴趣完成候选题取舍；如有依据，再记录新颖性线索及其待核验状态；
7. 对照问题门条件完成提交前自查。

### 安全与资源口径

- 不要求学生自费购买 API token；问题改写可由学生在课堂纸面或 Markdown 模板中完成。

**最小课堂产出**：`problem-definition.md` 中选定一个候选题，写出正负边界、一个可证伪命题、一个待验证前提和一个替代解释标记；九项门条件只需标注当前状态。课前累计的候选文献、精读卡和证据地图只做状态核对，不重做。

**课后补全**：只修复九项自查中的真实缺口，补齐本课未完成字段和反馈处理记录，不把删减讲解转成新增必读。

**研究门条件**：课后提交仍严格按 [assignments.md](../../course/assignments.md) Checkpoint 1 九项条件检查；新颖性类别和完整竞争假设设计都不是本门新增硬条件。

**备用路径**：若现场环境故障，学生在纸面或 Markdown 模板中完成问题重写、非例和可证伪命题；第一性原理推导可在纸面完成四步清单；同伴互查改为纸面交换检查；不把课堂时间用于逐台排障。问题门提交在课后完成，不要求课堂内提交。

## 六、教师演示脚本

1. 从阅读卡题池选择一题，写理由、非例和 Q1 结果命题。
2. 第一性原理提出待检验前提，不能凭相同材料与标准就确认结构因果。
3. 留下 H1/A2 区分线索，质量、成本和范围分别记录。
4. 问题门九项标已满足/待补/未满足；阅读卡方向取舍作为构造门检例，真实个人失败按实际记录；MI 只供课后迁移。

## 七、课堂产出验收

以下先检查课堂最低产出，不把问题门的完整条件伪装成当堂完成：

- [ ] `problem-definition.md` 更新版：研究问题不是纯主题词，包含条件、对象、干预和结果
- [ ] 至少一个非例，且非例不是"不做无关研究"这类无约束表述
- [ ] 至少一个可证伪命题，指明什么观察会推翻主张
- [ ] 从第一性原理推导中收敛一个待验证前提，并能指出其证据地图依据
- [ ] 推导基于第 5 课证据地图，而非凭空构造
- [ ] 问题重要性说明包含"So what?"和"Who cares?"两个检查
- [ ] 课程周期可行性已说明
- [ ] 候选题池与选题理由字段：≥3 候选及路径标签、四维比较与选定理由；新颖性类别仅在有依据时记录
- [ ] 一个替代解释标记，作为第 7 课竞争假设设计的输入
- [ ] 同伴互查门条件检查记录（9 项逐项标注已满足/待补全/未满足）

课后再补齐真实失败/死路记录、AI 使用记录和九项自查中的其他缺口，然后提交问题门材料包。具体条件以 [assignments.md](../../course/assignments.md) Checkpoint 1 为准。

## 八、讲后复盘

教师课后记录：

- 学生是否仍停留在"主题当问题"的层次？
- 非例是否过宽或过窄？
- 可证伪命题是否真正指明了推翻条件，还是只写了"是否有效"？
- 第一性原理推导是否基于证据地图，还是凭空构造？
- 问题重要性是否经过"So what?"检查，还是只说"新颖"？
- 候选题池是否只有文献空白一条路径？四维比较是否真的写了取舍理由，还是只勾选？
- 问题门 9 项条件中，哪一项学生最容易不满足？失败记录是否真正回写了研究工件？
- 第 7 课需要在机制假设中重点补哪个环节？
