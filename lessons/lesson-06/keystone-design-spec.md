# 第 6 课关键页设计规格

依据 [正式课堂 PPT 设计准则](../ppt-design-criteria.md) v1.2.0。屏显文案、讲述、互动、时间和来源以 [slides.md](./slides.md) v1.0.0 为唯一现行母稿。

## 一、关键页集合

首轮关键页：`P01 / P02 / P04 / P05 / P07 / P10 / P12 / P14 / P15 / P16 / P18 / P21`。

| 风险类型 | 页面 | 选择理由 |
| --- | --- | --- |
| 开场与收束 | P01、P21 | 必须建立并回应“空白如何收敛为可检验问题并进入机制假设” |
| 上游连接与概念区分 | P02、P04、P05 | 证据地图四视图、主题/问题/主张与虚构 G1 容易混写 |
| 选题与核心方法 | P07、P10、P12、P14 | 候选题容易被限定在文献空白一条路径；可证伪命题与第一性原理容易被误读为口号或既成结论 |
| 问题门 | P15、P16 | 八项条件必须与权威源逐项一致，累计工件不得伪装为单课自动产出 |
| 课堂行动 | P18 | 20 分钟停留页必须支持问题定义、推导和选题理由的最小闭环 |

## 二、关键页契约

### P01｜从空白进入问题门
- **页面任务**：定位阶段一、阶段二和第一次正式提交。
- **主视觉锚点**：`空白候选 → 结构性问题 → 问题门` 单链。
- **相邻关系**：P02 回扣第 5 课工件；P21 送入第 7 课。
- **最小成立内容**：课名、核心转换、问题门节点。

### P02｜第 5 课工件还缺什么
- **页面任务**：把直接/补充/冲突/空白四视图转成四个待解问题。
- **主视觉锚点**：已有工件与未解问题左右对照。
- **相邻关系**：承接 P01；P03 明确产出。
- **最小成立内容**：四视图、空白三步检验、2:16 短互动。

### P04｜主题、问题与主张
- **页面任务**：阻止把主题或待验证主张误当研究问题。
- **主视觉锚点**：三层对照表。
- **相邻关系**：P05 将虚构空白改写成结构性问题。
- **最小成立内容**：三层表述、各自缺口、五要素。

### P05｜虚构 G1 只演示改写动作
- **页面任务**：展示从空格描述补全条件、对象、干预、结果和比较。
- **主视觉锚点**：空白候选到结构性问题的转换。
- **相邻关系**：承接 P04；P06 检查重要性。
- **最小成立内容**：五要素、画面虚构标记、待真实窄检索状态。

### P07｜候选题不能只来自文献空白
- **页面任务**：阻止"关键词 → 论文 → 空白"单线选题；候选题池经来源交叉检查与四维比较后才收敛为研究问题。
- **主视觉锚点**：来源交叉检查问句（"没有这个空白还值得回答吗"）+ 四维选题标准卡（意义/新颖性/可行性/兴趣）。
- **相邻关系**：承接 P06 重要性检查；P08 起进入非例与可证伪命题的边界界定。
- **最小成立内容**：交叉检查问句与两条出路、四维表、新颖性三类（问题新/视角新/方法新）、"新≠没人做过、意义优先"判断句、虚构题池示范标注。

### P10｜可证伪命题必须写出推翻条件
- **页面任务**：把“有用”改成可观察、可对照、可推翻的命题。
- **主视觉锚点**：不可证伪与可证伪对照。
- **相邻关系**：P11 引入竞争假设。
- **最小成立内容**：条件、干预、结果、对照、推翻条件。

### P12｜第一性原理不是脱离证据的捷径
- **页面任务**：锁定课程内定义和适用边界。
- **主视觉锚点**：基本约束/机制/不可违背条件与外部证据回路。
- **相邻关系**：P13 给四步骨架；P14 完整演示。
- **最小成立内容**：不替代检索、不自动成立、继续外部检验。

### P14｜推导产出待验证前提，不产出实证结论
- **页面任务**：完整演示四步推导。
- **主视觉锚点**：约束→机制→不可违背条件→待验证前提。
- **相邻关系**：承接 P13；P15 用门条件检查当前项目。
- **最小成立内容**：四步、虚构标记、与第 5 课证据地图的连接。

### P15｜八项问题门条件
- **页面任务**：逐项呈现 assignments.md Checkpoint 1 权威条件。
- **主视觉锚点**：可勾选的八行清单。
- **相邻关系**：P16 演示累计状态核对。
- **最小成立内容**：八项完整条件；AI 错误/过度概括/遗漏或已检查风险完整口径；候选题池与选题理由为课程扩展字段、不加入八项门条件。

### P16｜累计工件不是单课自动完成
- **页面任务**：演示如何诚实标记已满足、待补全和未满足。
- **主视觉锚点**：八项状态表与缺口列。
- **相邻关系**：P15 给规则；P17-P18 只补本课重点字段。
- **最小成立内容**：第 3-6 课累计路径、四视图、AI 连续记录、虚构标记。

### P18｜20 分钟问题定义与推导停留页
- **页面任务**：支持个人完成候选题池四维比较、研究问题、非例、命题、推导和重要性说明。
- **主视觉锚点**：可抄写的字段模板（含候选题池与选题理由扩展字段）与进度顺序。
- **相邻关系**：P17 解释任务；P19 用门条件互查。
- **最小成立内容**：写入位置、七步任务、候选题池与选题理由字段、时间提示、备用路径。

### P21｜待验证前提进入第 7 课机制假设
- **页面任务**：收束问题门并明确下一步不是直接做实验。
- **主视觉锚点**：`问题门 → 待验证前提 → 机制假设 → 实验规格`。
- **相邻关系**：回应 P01，连接第 7 课。
- **最小成立内容**：退出卡、保存当前项目、第 7 课输入。

## 三、模板与视觉边界

- 保留交大模板 master/layout、红色标题带、校徽、主题字体和页码。
- P05、P14、P16 画面和 speaker notes 同时标注虚构教学样例；不得伪造论文、DOI、检索命中或实证结果。
- P07 四维比较示范题池（G1/C2/C3）为虚构教学样例，画面与 notes 标注；不得把候选题池与选题理由写成门条件新增项。
- P15 八项门条件不得省略、换义或用缩写掩盖“过度概括/已检查风险”的合法路径。
- P16 必须用“累计/核对”表达，不得把 ≥10 篇候选文献或 ≥3 张完整精读卡写成某一课当堂自动产出。
- P18 为持续实践停留页，正文不低于 18 pt，优先保证后排可读和可抄写。
