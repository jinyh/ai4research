# 正式课堂 PPT 设计准则

本准则规定全 16 课正式课堂 PPT 的共同视觉语言与设计验收方式。目标不是追求统一模板感，而是让 CS/AI 研究生在投影环境中迅速看清主张、证据、研究对象和需要采取的行动。

课次目标、屏显文案、证据角色与学生动作以各课 `slides.md` 为准；课次关键页和例外写入该课设计规格。文件技术、证据框和导出后检查见 [PPT 质量门](../course/ppt-quality-gates.md)。历史试制稿只用于比较，不是现行内容母版。

## 一、品牌与基础系统

### 1. 模板继承

- 正式课件保留交大模板的 master → layout → slide 层级、校徽与标识、主题字体、主题色和页码；不得用覆盖层仿造另一套母版。
- 标准内容页沿用交大红标题带。封面、章节过渡、全屏精读页和互动页可以使用有记录的模板例外，但仍须保留可识别的品牌元素。
- 模板只提供品牌骨架，不提供完整教学页型。正文区可以扩展有限的证据页、机制页、工件页、路线页和互动页构图；扩展必须服从本准则的网格与字体规则。

### 1.1 封面与收束页固定信息层级

- **封面只承担识别任务**：屏显正文只保留“第 N 讲 + `course/syllabus.md` 的正式课名”；不叠加英文副标题、方法判断、阶段说明、课程口号、学习目标或方法链。课名较长时允许同一标题框内两行排布，但不得另造短标题。
- **交大封面标题位置**：标题在模板中部两条横线之间水平居中，并与校门线稿保持足够留白；不得压住上横线、校门屋脊或底部校训。标题框的具体坐标以第 3 讲正式封面为当前对齐基准，实际渲染后再做字体替换检查。
- **收束顺序固定**：正式课堂内容结束后，先设置独立的“本讲知识点总结”，再进入作业/持续回写、退出卡或下一讲预告；第 16 讲则在最终提交与课程收束前总结。总结页只回收本讲已经建立的主链、关键判断与行动边界，不引入新知识或新任务。
- **总结页不与行政动作混页**：知识点总结不和作业要求、提交格式、阅读清单或下一讲预告挤在同一页；若原尾页合并了两类任务，应拆页，并在 90 分钟既有收束段内重新分配时间，不擅自延长课时。

### 2. 网格与表面

- 画布为 16:9。标准页左右安全边距不小于 0.55 英寸；正文从标题带下方开始，底部避开页码与品牌页脚。
- 正文采用 12 列网格，可形成 4/8、5/7、6/6 等比例；每页最多两个主要纵向区域。网格用于对齐，不用于制造 12 个小面板。
- 采用扁平学术风：不使用装饰性阴影、立体效果和渐变；普通分组优先依靠对齐、留白和细分隔线。
- 卡片只在它确实代表一条记录、一个工件、一个独立选项或一个流程节点时使用。等宽卡片矩阵不得替代主张、证据关系或研究对象。

### 3. 字体与字号

- 沿用模板字体：中文使用微软雅黑，英文使用 Arial；代码和 diff 使用 Consolas。正式授课前在授课电脑检查字体替换。
- 内容页标题 30–32 pt，并保持单行；正文 22–24 pt；精读标注、代码和表格文字不低于 18 pt；来源、许可与页码 10–12 pt。
- 多行讲述性正文和列表默认采用 1.3 倍行距；代码、diff、目录树、表格、短标签及紧凑流程节点可保持较紧行距。行距调整不得造成文字溢出或遮挡，也不得以缩小字号补偿。
- 小于 18 pt 的文字不得承担课堂阅读任务。虚构内容标记、权限/任务契约、风险状态、研究门和课后动作都属于教学信息，不按来源脚注豁免；内容过多时先裁切、改写或拆成递进页，不以缩小字号解决。
- 先把标题框扩展到标题带内除校徽与斜切端之外的可用宽度；仍放不下时同步压缩 `slides.md` 中的屏显标题，完整限定移入正文或 speaker notes。不得只在 PPT 中另造一套短标题。
- 页眉标题、年份、卷号、统计量和短标签为字体替换预留约 20%–30% 宽度。

### 4. 语义色

| 用途 | 颜色 | 规则 |
| --- | --- | --- |
| 品牌、关键风险、删除/失败 | 交大红 `#C8161E` | 标题带可常驻；正文强调从严使用 |
| 主要结构与正文强调 | 深蓝 `#1F4D78` / 灰蓝 `#44546A` | 主链、标题外的主要信息 |
| 通过、新增、已核验 | 状态绿 `#2E7D5B` | diff 增加、通过状态 |
| 待确认、提醒、形成性节点 | 橙 `#ED7D31` / 黄 `#FFC000` | 不与正式通过混用 |
| 次要信息与背景层级 | 灰 `#A5A5A5` / 浅灰 | 弱化，不承载唯一差异 |

状态不能只靠颜色表达，必须同时使用文字、符号、线型或位置。单页正文通常只使用一种主结构色和一种状态/强调色，论文原图与数据图的必要颜色除外。

## 二、叙事与构图

每页只承担一个叙事任务并给出一个主要结论。标题优先写成教师能够直接说出口的判断或问题；封面、章节过渡和课堂任务页可使用必要的字面标签。

以下轮廓是开放参考，不是封闭枚举。课次规格可以因内容新增轮廓，但须说明它解决的关系与相邻页差异。

| 轮廓 | 适用 | 视觉特征 |
| --- | --- | --- |
| 聚焦 | 封面、张力、过渡、收束 | 一个判断、问题或视觉锚点占主体 |
| 主链/机制 | 流程、八阶段、研究链路 | 单线节点、因果或回退关系 |
| 证据框 | 论文结论、数据、图 | 来源身份、图与本页结论同框 |
| 工件视图 | 仓库、diff、日志、证据表 | 真实、脱敏或明确标注的教学工件占主体 |
| 对照 | 配置、方法、前后状态 | 两域有明确差异点，删一域信息有损失 |
| 路线/门槛 | 课程路线、研究门、成熟度 | 横轴、路径或门槛标记 |
| 责任分工 | 个人与同伴、人和 Agent | 两侧承担不同角色与决定权 |
| 否定清单 | 非例、红线、禁止事项 | “不做”列表配一句正面对照 |
| 比例/评分条 | 评分、预算、权重 | 清单负责名称，按权重缩放的条形负责比例 |
| 互动任务 | 投票、练习、互查、退出卡 | 学生动作、输入与可检查结果清楚可见 |
| 图形优先 | 检索流程、状态规则、核验 trace | 单张图承载主信息，文字只做标签与结论 |

### 图形优先页

核心内容可由一张流程、结构或 trace 图承载时，优先以图承载：图即该页的主视觉锚点，文字只承担标签与结论（对齐关键页契约的"主视觉锚点优先承载"）。这是正向规则：先问"这页能不能用一张图说清楚"，再决定文字与卡片的剩余角色。

### 叙事优先的轮换规则

- 禁止连续页面无意义地复用同一套卡片、两栏或流程构图。
- 同一研究对象可以跨页递进；后页必须在状态、焦点、关系或学生任务上发生可见变化，而不是只替换文字。
- 连续机制讲解可以保持对象位置与视觉语法，以降低重新定位成本。不得为了“换轮廓”破坏本应连续的推理。
- 全卷验收时按教学段检查重复与节奏，不执行“任意 3 页/5 页”的机械计数门槛。

## 三、关键页设计契约

关键页由误读风险触发，不设固定数量。开场与收束、核心模型、关键证据、主工件或演示、复杂路线和长时间停留的学生行动页原则上均应列入课次规格。

关键页在制作前填写四字段：

1. **页面任务与主结论**：这页在整堂课中推进什么判断、问题或行动？不得只写“介绍概念”。
2. **主视觉锚点及来源**：学生首先判断的对象或紧密耦合对象组是什么？它来自论文、机制重绘、真实/教学工件还是概念示意？
3. **与相邻页的叙事关系**：本页延续、改变或解决了什么？若复用同一对象，状态变化是什么？
4. **最小成立内容**：删到只剩什么，这页仍能完成任务？其余进入 speaker notes、相邻页或讲义。

关键页的主视觉锚点通常占有效内容区约 40% 以上，但这是视觉支配的经验值，不是像素硬门槛。对照、责任分工和证据框可以由一组紧密相关对象共同形成主视觉；封面和互动页可以由大字判断、问题或选项关系形成视觉锚点。

## 四、视觉来源

| 页面角色 | 首选来源 | 边界 |
| --- | --- | --- |
| 实证证据 | 论文原图、准确裁图或忠实重绘 | 题名、期刊与年份、图和本页结论同框；重绘保留变量、数字和边界 |
| 结构/机制 | 可编辑的简单结构图；必要时使用适合关系复杂度的图形工具 | 节点、连线、回路和标签在投影尺寸检查；示意关系不得伪装成实证结果 |
| 工件/操作 | 真实或脱敏工件；明确标注的虚构教学工件 | 不生成或仿造真实产品 UI、日志或研究证据 |
| 路线/评分 | 横轴、路径、门槛或按权重缩放的条形 | 不用等宽方块表示比例或时间 |
| 概念/假设 | imagegen 概念图或生成式信息图 | 只表现抽象关系或待验证假设；不承载数值、实证关系、真实 UI 或论文结论 |

生成式信息图的精确标签、箭头和数值必须使用可编辑图层准确叠加，并在 speaker notes 标注“概念示意，非证据”。外部资产和非平凡事实在 notes 中保留 `[Sources]` 块；教学虚构数据或工件同时在画面和 notes 标明为虚构。

一个可判断的研究对象优先于三张概念卡片。面向 CS/AI 研究生优先呈现 Git/diff、研究仓库、失败日志、证据缺口表、实验规格和可复现检查等对象，同时明确它们适用的研究类型与方法边界。

### assets 唯一图源与 handout 嵌图规范（2.0）

- 课级 `assets/` 是该课唯一图源：同一文件既嵌入 `slides.pptx` 又被 `handout.md` 以 `![](assets/xxx)` 引用，禁止两套副本；跨课复用用相对链接指回源课，不复制。
- 命名四式：论文原图 `<来源>-<年份>-<对象>-fig<n>.png`；忠实重绘 `…-redraw.svg`；自绘结构图 `<主题>-<对象>-structure.svg`；工件截图 `mi-trace-<步骤>.png`（工件类按 `<主题>-<工件>-screenshot.png` 扩展）。
- `assets/README.md` 逐图登记出处块：来源角色、出处、许可或虚构标记、脱敏状态，并写明嵌入位置。
- handout 嵌图：相对路径引用；图下附出处块引用块，内容与登记一致；SVG 透明底，须在站点浅色底清楚可读；结构图不伪装实证关系；虚构内容画面与出处块双标。
- 发布前置：图片文件先在 `web/scripts/link_content.py` 白名单登记（逐文件软链）并运行生效，之后才在 handout 引用；`assets/README.md` 属备课元数据，不进发布白名单。

## 五、密度与动画

### 三类密度

- **聚焦页**：低密度。一个主张或问题 + 一个主视觉锚点 + 必要限定。
- **说明页**：中密度。一个主结论 + 可在一屏读完的结构、清单或关系。
- **精读工件页**：允许局部高密度，但必须裁取学生需要阅读的部分并放大；必要时分步揭示或拆页，不能把整篇论文图、终端或表格缩成背景纹理。

母稿是课堂叙事源，不是逐字屏显稿。禁止把讲义段落原文搬上屏、用更多卡片填空，或在没有证据阅读任务的页硬塞图片。

### 动画

- 只使用“出现”或“淡入”控制讲述顺序；不使用装饰性飞入、路径动画或依赖 Morph 才能理解的关系。
- 动画后的静态最终状态必须完整可读，导出 PDF 或动画失效时不得丢失结论、因果关系或任务条件。

## 六、分层设计验收

### 所有页面

1. 三秒内能否看出本页主要判断、问题或动作？
2. 标题和短标签是否单行，承担教学任务的文字是否达到字号下限？
3. 页面是否以一个构图组织内容，而不是 UI 面板或无意义卡片矩阵？
4. 视觉来源是否与主张角色匹配，虚构与生成内容是否清楚标注？
5. 状态和差异是否同时由颜色之外的方式表达？
6. 实际构图、屏显对象和文件名是否与现行 `slides.md`、课次设计规格及 `course/` 权威模板一致？

### 关键页

1. 四字段契约是否在画面中成立？
2. 主视觉锚点是否形成清楚的视觉支配，而非被标题、装饰或次要面板分散？
3. 与相邻页的延续或变化是否有教学理由？

### 精读工件页

1. 学生需要读取的变量、代码、数字或差异是否在投影尺寸清楚可见？
2. 裁切和放大是否保留判断所需上下文，且只要求完成一个明确阅读任务？

### 全卷

1. 开场提出的问题是否在结尾得到行动、综合或下一步回应，而不是以通用“谢谢”结束？
2. 各教学段是否有稳定视觉语法，同时避免连续无意义复用？
3. 标准页与模板例外是否一致可识别，字体、语义色、边距、页码和来源位置是否稳定？
4. 是否逐页对照母稿视觉结构和关键页契约，而不是只检查渲染、溢出与模板保真？

技术、教学与文件验收不得互相替代。导出后重开、图层遮挡、字体替换、裁切、换行、来源对应和空 placeholder 等最终门槛以 [PPT 质量门](../course/ppt-quality-gates.md) 为准。

## 七、课次规格

- 每课在制作前由课次设计规格列出风险触发的关键页、四字段契约和模板例外；不在本文件维护具体页码。
- 普通说明页不填四字段，但仍通过“所有页面”和相应页型验收。
- `slides.md` 的视觉结构与关键页四字段契约是正式验收依据；实现若有意偏离，必须先回写母稿或在课次规格中记录偏离理由。
- 视觉试制与历史里程碑保留其当时判断，不因本准则更新而回写成现行验收记录；正式 PPT 必须重新映射当前 `slides.md`。
