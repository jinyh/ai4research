# 第 4 课共同诊断｜同一主张的证据裁决

## 先独立判断

**问题：原文支持哪种转述，支持到哪里？**

输入：L3 已核验身份和一条拟用主张的来源。先记录判断和依据，再与同伴比较；课堂校准后可修订并写明改变原因。答案有分歧时回到具体记录。已有示例可作方法参考，不替代本人的初始判断。

## 原始材料与待比较选项

真实来源：Keshav (2007), How to Read a Paper，DOI 10.1145/1273445.1273458。用[公开 PDF](https://cs.uwaterloo.ca/~Brecht/courses/856/readings/how-to-read/keshav-paper-reading.pdf)核对以下定位；摘要和标题只作入口。

| 位置 | 要检查的原文对象 |
| --- | --- |
| p.83 摘要、§2 | 方法目的与三遍结构 |
| p.83 §2.1 | 第一遍的参考时长和目标 |
| p.83 §2.2、p.84 §2.3 | 第二遍与第三遍的理解深度 |
| p.84 §4 | 作者使用经验及支持强度 |

两种待裁决转述均为教学构造，并非实际模型输出：

A：“作者提出三遍阅读法，第一遍约 5–10 分钟；该方法可作为阅读卡设计的参考。”

B：“论文以对照实验证明三遍法使阅读时间减少 50%，因此阅读卡可以提高所有科研任务的效率。”

请在原文中寻找支持和不支持的位置；检查全文有无 B 所称的实验。

**待决定：**A、B、两者均不足或仍不能判断；可部分接收一句中的某个主张。

把“初始判断—证据位置—仍缺什么—核验后决定”写在现有笔记中。允许回答“仍不能判断”，同时指出下一项能改变判断的证据。

## 迁移到本人项目

围绕本人拟用主张完成第一张完整阅读卡：AI 导航→原文核验→AI 质疑→偏差审计→人工定稿；无 AI 时以人工提问替代并标记。单列“支持本人项目什么、仍缺什么”。

**验证：**同伴由转述反查至少两个位置；把作者自述局限与个人判断分栏；两种准入态 verified / verified-with-caveat 都可用，后者保留限定。

**保存位置与达标证据：**reading-cards.md 第一张完整卡及个人判断。

**下课去向：**L5 带这张卡和一项条件不同的证据，开始综合并补第二张卡。

## 完成标准

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

断网时保留同样的判断要求，使用包内文本、存档或本地工件。工程课纸面诊断仅作备用练习，最终仍须补本人实际执行、实质修改和对照评价。提前完成者可寻找一个使自己决定改变的反例；不增加课后任务。
