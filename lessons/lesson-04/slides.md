## P08｜Fig.6 的比较对象与操作

### 屏显内容

读图前先统一 M、C、K 和 F

| 记号 | 本案例含义 |
| --- | --- |
| M / C | 完整模型 / 候选电路 |
| K | 从 C 中选出、两边同样移除的节点 |
| F | IOI 平均 logit(IO) − logit(S) |

移除用同模板 p_ABC 均值替换；C 外节点也已消融。

### 视觉结构

沿用模板的原生两列定义表；指标定义与操作说明分开，取代恢复比例图。

### 教师讲述备注

C是M的子图。运行C时先移除C外节点，再分别在C和M移除同一个K。节点按注意力头及token位置界定。§2.1用p_ABC同模板样本平均激活替换节点输出，p_ABC含三个不同名字，不是删除参数。F是IO相对S的平均logit差，不是准确率。恢复比例算例移至讲义按需段，此处不给Fig.6的结果解释。

### 互动／操作

### 建议时间

3 分钟，含学生操作。
