# 第 2 课教师教案｜科研伦理、Agent 权限、研究工件与追踪

## 一、本课定位

- 学时：2 学时，90 分钟
- 研究链路：全链路约束
- 核心问题：如何把科研伦理要求转成 Agent 可执行、研究者可检查的边界？
- 教学类型：案例判断 + 原始来源精读 + 教师演示 + 两段个人实践 + 临时结对
- 正式提交：无

本课沿用第一课的同一研究动作，只增加风险判断、权限和披露。课堂不要求学生同时填满伦理清单、权限矩阵、工件追踪和多套 contract。

## 二、学习目标

学生完成本课后能够：

1. 按对象、动作与环境识别 AI 辅助科研风险；
2. 用五字段风险卡作出允许、有条件允许或禁止的判断；
3. 填写一行包含人工确认点与禁止事项的权限矩阵；
4. 解释 research harness 如何连接版本化协议、权限、人工确认与 trace；
5. 区分工件成熟度与完成百分比，并用 AI 使用记录还原一次判断。

## 三、课前准备

### 教师

- [ ] 复核 NASEM、CAS 与上海交大规范原始来源和授课日期
- [ ] 只使用公开或虚构案例，不使用真实学生、合作或评审材料
- [ ] 准备过宽/最小两份权限配置和“改指标但未留 diff”的失败案例
- [ ] 演示仓库预置风险卡、权限矩阵和 AI 使用记录空表
- [ ] 准备 Markdown 静态 trace 与 [classroom-pack.md](./classroom-pack.md)

### 学生

- [ ] 带第 1 课个人项目和首条 AI 使用记录
- [ ] 选择一个公开、低风险科研动作；不得把真实保密材料带入练习
- [ ] OpenCode 或等价环境不可用时使用 Markdown 备用路径

## 六、教师演示脚本

演示动作：“为一份虚构未公开合作稿设计不外发原稿的 AI 辅助路径”。先用风险卡得出“原稿禁止默认发送”，再选用经授权公开版本或人工抽象问题作为替代输入。

第一轮只读：Agent 只读 `agent-permissions.md` 和人工写好的虚构对象描述，指出一处过宽或缺失权限，返回风险与最小替代；不读原稿、不写文件、不联网、不批准修改。

教师判断后，第二轮仅写：

1. `agent-permissions.md` 一行；
2. `ethics-and-compliance.md` 一张风险卡；
3. `ai-usage-log.md` 一条记录。

禁止修改问题、指标、工件状态或项目外文件。完成后检查实际 diff、AI 使用记录和外部状态。若学生已向模型发送未公开材料，用“停止—评估—记录—按需沟通—切换合规路径”恢复，不用隐瞒或重复发送来掩盖问题。

## 七、课堂最低产出与备用路径

- [ ] 五字段风险卡一张
- [ ] 权限矩阵一行，其中包含具体人工确认点和禁止事项
- [ ] AI 使用记录一条，写明 Context、输出用途、采用/拒绝与核验方法
- [ ] 完成一次只读边界审查；未调用模型时记录人工判断

`artifact-tracking.md` 在课后更新，不作为课堂第四张表。无模型/无网络路径直接编辑 Markdown，并如实记录“未执行”或“本次为人工判断”，不得伪造模型运行。

课堂只验收上述三件工件和一次边界审查；课后只沿用它们更新早期项目，不正式提交；第 6 课问题门再检查当时项目版本的完整条件。

## 八、讲后复盘

- 学生能否区分对象、动作和环境，而不是按工具品牌判断？
- P03 的理由交换是否提高了判断质量，还是造成从众？
- “已经发送后的恢复路径”是否让学生理解透明和协调责任？
- 学生能否用一句话解释 research harness，而不把它等同于 OpenCode？
- 三件最小工件是否能在课堂内完成并互相解释？
