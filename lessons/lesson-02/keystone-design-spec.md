# 第 2 课关键页设计规格

依据 [正式课堂 PPT 设计准则](../ppt-design-criteria.md) v1.2.0。本文件只规定第 2 课风险较高页面的视觉任务、主视觉锚点、相邻页关系和最小成立内容；屏显文案、讲述、互动、时间和来源以 [slides.md](./slides.md) v1.8.0（25 页）为唯一现行母稿。

## 一、关键页集合

首轮关键页为：`P01 / P03 / P07 / P09 / P10 / P11 / P12 / P14 / P16 / P18 / P20 / P22 / P25`。

| 风险类型 | 页面 | 选择理由 |
| --- | --- | --- |
| 开场与收束 | P01、P25 | 建立并回应“效率不能替研究者突破边界” |
| 课堂判断与行动 | P03、P22 | 第一次学生判断与两段个人实践主屏（含中点点评停顿位） |
| 核心方法 | P07、P12、P14 | 风险卡、权限维度与人工确认点决定学生能否把原则转成规则 |
| 高风险边界 | P09、P10、P11 | 未公开材料、生成数据和指标变更最容易被错误泛化 |
| 工件与记录 | P16、P18 | 工件成熟度与日志信息量决定结论能否追溯 |
| 教师演示 | P20 | 只读任务契约必须在投影尺寸下可精读 |

其他页面不填四字段契约，但仍须通过全局准则的“所有页面”、相应页型和全卷验收。

## 二、关键页契约

### P01｜第2讲 科研伦理、Agent 权限、研究工件与追踪（封面）

- **页面任务与主结论**：封面只承担识别（`ppt-design-criteria.md` §1.1）：第 2 讲 + 课名；五步路径线移 P02、核心判断句移 P03 收束。
- **主视觉锚点及来源**：标题居中于模板；不在封面另加装饰性图片或阶段说明。
- **与相邻页的叙事关系**：P02 从第 1 课受限交互暴露四个尚未解决的问题，并承接五步路径横条；P03 要求先作判断。
- **最小成立内容**：`第2讲`、`科研伦理、Agent 权限、研究工件与追踪`。

### P03｜案例：可以把未公开合作稿交给外部模型吗？

- **页面任务与主结论**：在展示规范前暴露学生的初始边界判断；现有信息不足以直接授权全文上传；以本课主判断"效率不能替研究者决定哪些边界可以突破"收束（原封面判断句本页承接）。
- **主视觉锚点及来源**：左侧虚构合作稿对象卡（文件元信息 + 请求动作，虚构双标：虚构教学情境 + 不承担实证结论），右侧“允许／有条件允许／禁止”三档选择形成单一判断关系。
- **与相邻页的叙事关系**：P02 提出四个问题，本页要求先作判断；P04、P05 再提供价值与规范依据。
- **最小成立内容**：对象卡元信息（未投稿、含未公开数据、请求动作）、三档选择、一个决定性理由和虚构标记。

### P07｜五字段把伦理担忧变成可执行判断

- **页面任务与主结论**：把抽象伦理担忧转为可复核的任务判断。
- **主视觉锚点及来源**：`Asset → Action → Risk → Control → Owner` 五段链，Owner 回连 Action 表示责任闭环；课程教学框架。
- **与相邻页的叙事关系**：P06 将问题具体化，本页给出字段；P08 将字段结果收束为三种处置。
- **最小成立内容**：五字段、方向关系、`注意安全 ≠ 控制措施`。

### P09｜未公开不等于一律禁止，授权也不是唯一条件

- **页面任务与主结论**：阻止“未公开一律禁止”和“共同作者同意即可上传”两种过度简化；以第二次投票（"作为审稿人收到，判断变不变"）让学生体验式得出两栏区分。
- **主视觉锚点及来源**：作者工作稿与正式评审稿两条分流路径，下接五项可检查条件；替代路径不上屏显，留讲义 §八 指针；规范来源保留在 notes。
- **与相邻页的叙事关系**：P08 给出处置框架，本页完成 P03 的课堂裁决；P10 转入生成数据边界。
- **最小成立内容**：两类稿件、默认拒绝、五项条件；五种替代路径以讲义 §八 分条列示为据。

### P10｜生成数据的使用边界

- **页面任务与主结论**：区分“模拟数据测试工程行为”和“生成数据支撑经验结论”。
- **主视觉锚点及来源**：模拟数据与真实数据两条分离管线，结果端禁止合并标签；概念结构，不伪装为真实实验结果。
- **与相邻页的叙事关系**：延续 P09 的材料边界；P11 再把边界推进到评价协议。
- **最小成立内容**：有条件允许、四项控制、两条不得混同的数据管线。

### P11｜评价指标变更的人工门

- **页面任务与主结论**：说明指标变更属于研究判断，不能由 Agent 在看到结果后无记录地自行完成。
- **主视觉锚点及来源**：`Agent 建议 → 暂停 → 人工说明 → 版本化协议 → 再运行` 主链与被截断的越权旁路。
- **与相邻页的叙事关系**：P10 处理数据角色，本页处理评价协议；P08 以五检查点底条把控制扩展到全工作流。
- **最小成立内容**：人工门、版本化协议、禁止旁路。

### P12｜权限要按动作和维度拆开

- **页面任务与主结论**：让学生同时检查动作类型和权限维度，避免只写文件读写。
- **主视觉锚点及来源**：项目目录为中心，上方六类动作，下方 `Path / Command / Network / External write` 四行检查；不使用产品界面截图。
- **与相邻页的叙事关系**：P08 说明何时控制，本页说明控制什么；P13 解释保护原则（默认拒绝与最小权限合并页）。
- **最小成立内容**：六类动作、四个维度、一个 external write 非例。

### P14｜权限矩阵：字段与人工确认点

- **页面任务与主结论**：把保护原则落到长期权限矩阵，并让确认点对应会改变研究判断或外部状态的动作。
- **主视觉锚点及来源**：两行可读权限矩阵为主体，表头以 starter-template §8 六列（对象或能力｜只读范围｜可写范围｜是否允许执行｜人工确认点｜禁止事项）为唯一基准；确认点与禁止列视觉突出；下方六项汇入 `Pause for review`。
- **与相邻页的叙事关系**：收束 P12–P13 的原则；任务契约六字段降入备注与讲义 §五，不占屏显。
- **最小成立内容**：两行矩阵、确认点、禁止事项和 `Pause for review`。

### P16｜文件与工件成熟度的区别

- **页面任务与主结论**：文件存在不等于主张已经成熟，状态也不是完成百分比。
- **主视觉锚点及来源**：左侧文件位置，右侧 `draft → review → approved → stable` 状态轨迹与回退箭头；课程工件定义。
- **与相邻页的叙事关系**：P15 完成权限配置比较，本页进入演示所需工件状态；状态迁移六问入本页备注与讲义 §六。
- **最小成立内容**：文件／状态问题对照、四状态、回退、`stable` 的双证据原则。

### P18｜日志的信息量标准

- **页面任务与主结论**：让学生区分可复核记录与形式化声明。
- **主视觉锚点及来源**：同一任务的“有用记录／无用记录”上下对照，可复核字段在投影尺寸可读。
- **与相邻页的叙事关系**：P22 说明追踪表字段，本页说明日志最低信息量；P24 随即进入教师演示。
- **最小成立内容**：Context、实际输出、采用／拒绝、核验、问题、diff 与一个空泛反例。

### P20｜第一轮只读：先找风险和过宽权限

- **页面任务与主结论**：让学生精读一份只读任务契约并识别仍需人工判断的内容。
- **主视觉锚点及来源**：真实可执行的课程 Prompt 占页面主体，右侧 `Asset / Action / Control / Review` 作为阅读索引；不仿造产品 UI。
- **与相邻页的叙事关系**：P24 交代演示任务与目标工件；本页只分析不写入；P26 才进入批准后的限定写回。
- **最小成立内容**：输入文件、三项输出、四项限制和人工判断提示。

### P22｜个人实践：完成最小可审计闭环

- **页面任务与主结论**：作为覆盖两段个人实践全程（第一段约 10 分钟、教师中点点评约 5 分钟、第二段约 10 分钟）的行动页，让每位学生完成风险、权限与记录的最小闭环。
- **主视觉锚点及来源**：六步任务链和明确完成条件为主体，步骤分组为"第一段（步骤 1-2）/第二段（步骤 3-6）"，两组之间预留教师中点点评停顿位；屏显含候选动作三选一与五件套自检条；屏显不出现课堂计时分钟数；备用路径与同一任务并置。
- **与相邻页的叙事关系**：P26 完成教师示范，本页转入个人项目；P28 用三问检查边界是否清楚。
- **最小成立内容**：六步任务（含步骤 6 只读权限自查，无模型转课后）、禁用敏感材料、课堂至少追踪 1 项早期工件、四项工件第 3 课前补齐、Markdown 备用路径。

### P25｜课后继续推进，第 3 课带着边界开始检索

- **页面任务与主结论**：回应 P01；边界不是一次性声明，而要随第 3 课联网检索继续更新。
- **主视觉锚点及来源**：必读、项目更新、检索准备、任选阅读四项连续去向，形成从本课记录到下课行动的单一路径。
- **与相邻页的叙事关系**：承接 P28 同伴互查并收束本课；将新来源、新条款和新记录交给第 3 课。
- **最小成立内容**：四项任务、单线四去向路径、`持续回写个人项目，不单独提交`。

## 三、模板例外与制作约束

- P01 使用交大封面版式；不在封面另加装饰性图片。
- P20 属于精读工件页，可扩大正文有效区，但 Prompt 字号不低于 18 pt。
- P03、P22 属于互动任务页；学生动作和完成条件优先于装饰，屏显一律不出现课堂计时分钟数。
- P14 的矩阵只显示两行代表性记录；完整模板保留在讲义与项目模板，不缩小成不可读截图。
- P09、P12、P14、P16 可使用连续视觉语法，但后页必须改变对象状态或判断焦点。
- 动画只使用出现或淡入；静态最终状态必须完整可读。
