# 第 2 课关键页设计规格

本文件只规定高误读风险页的页面任务、主视觉、相邻页关系和最小成立内容。屏显文案与来源以 [slides.md](./slides.md) v1.10.1 为准。

## 一、关键页集合

`P01 / P03 / P04 / P05 / P06 / P07 / P09 / P10 / P11 / P12 / P13 / P15 / P17 / P18 / P20 / P22 / P23 / P25 / P26`

## 二、关键页契约

| 页面 | 页面任务与主结论 | 主视觉锚点 | 相邻页关系 | 最小成立内容 |
| --- | --- | --- | --- | --- |
| P01 | 只识别课次 | 第 2 讲 + “科研伦理与 Agent 边界” | P02 回扣第一课 | 不把完整正式课名塞进封面 |
| P03 | 先独立判断再表达理由 | 虚构对象卡 + 个人判断 | P04/P05 提供规范依据 | 虚构双标、三档选择、决定性理由；不显示分钟数 |
| P04 | 用原始来源建立六项价值 | 可读的 NASEM 原文裁图 | 从案例上升到价值 | 原始来源、六项价值和动作问题同框 |
| P05 | 两项制度来源并列 | CAS 网页与 SJTU PDF 左右等宽截图 | 回到具体任务执行更严格要求 | 来源身份、各自作用；不画成上下级关系 |
| P06 | 说明风险来自对象×动作×环境 | 无文字科技线稿并列同一执行环境的允许/禁止路径；文字均可编辑 | 将规范转为方法 | 具体对象、动作、核验与越界差异 |
| P07 | 保留五字段支架但不展示空表 | 一行填好的风险记录 | P08 用三类处置练习 | Asset/Action/Risk/Control/Owner 均具体 |
| P09 | 发送前检查 | 五条件连续路径 | P10 处理条件失守后的恢复 | 条件可检查；不把条件式框架当上传授权 |
| P10 | 已经发送后的恢复 | 停止→评估→记录→沟通→切换 | 回应现实落差并进入生成数据边界 | 不用删除/隐瞒代替恢复 |
| P11 | 单一批准按钮可能是假治理 | 指标变更失败链 | P12/P13 给修复架构 | 改指标=改版本化文件=留 diff |
| P12 | 双层边界属于同一个 harness | 研究判断与执行权限的连接 | P13 完整显示执行循环 | 不是两条互斥路线 |
| P13 | 定义 research harness | 无文字科技线稿围绕一个研究任务连接协议、权限、人工确认和 trace；术语均可编辑 | 连接判断约束与执行约束 | OpenCode 只作为执行实例，不是定义本身 |
| P15 | 权限矩阵先写一行 | 单行可读矩阵 | 从原则进入课堂产出 | 确认点、禁止事项与更窄授权规则 |
| P17 | 工件状态不是完成百分比 | 四状态正向成熟度 + 红色反向回退箭头 | P18 用实例解释迁移依据 | 状态语义、迁移依据与回退规则 |
| P18 | 用一个工件生命周期说明追踪 | 同一 evidence-map 的四次变化 | 解决抽象表格干燥问题 | 新增/修复、复核依据、下游用途 |
| P20 | 标记教师演示 | 大字风险—权限—审查—写回—日志 | P21/P22 展开同一任务 | 不教授平台菜单 |
| P22 | 教师演示有限写回 | 三件批准写回工件 + 明确禁止项 | 承接 P21 只读审查；P23 才由学生实践 | 只写权限一行、风险卡、AI 记录，不改问题、指标或状态 |
| P23 | 学生完成三件最小工件 | 大任务 + 三项检查 | 两段实践共用同一页；P24 临时结对 | 风险卡、权限一行、AI 记录；追踪表移课后 |
| P25 | 收束所有框架为一条闭环 | 复用 P13 harness 母题 + 任务→风险→边界→记录 | P26 只处理课后接口 | 对象卡、五条件、三档和矩阵不再并列为多套 contract |
| P26 | 课后持续更新 | 四步去向链 | 进入第 3 课检索 | 追踪表为课后持续记录，不新增课堂表单 |

## 三、制作与验收

- P04/P05 必须使用可核验的原始来源截图；来源脚注与图片登记一致。
- 任务、风险、权限、状态、虚构标记和学生动作不低于 18 pt。
- P13 应看成围绕一个任务的闭环，不是四个平行产品功能。
- P20–P22 明确为教师演示；P23 才是学生实践，学生可使用任一合规环境或 Markdown 备用路径。
- P24 标“临时结对”；固定同伴组在第 6 课前建立。
- 完整渲染必须来自最终正式 `slides.pptx`，旧 contact sheet 不得作为证据。
