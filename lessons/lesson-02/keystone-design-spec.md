# 第 2 课关键页设计规格

本文件只规定高误读风险页的页面任务、主视觉、相邻页关系和最小成立内容。屏显文案与来源以 [slides.md](./slides.md) v1.12.1 为准。


## 2026-09-15 内容复审后的制作约束

本轮页面标题、屏显、教师备注和学生动作以同目录 `slides.md` 为准。下方既有视觉方案保留布局取舍价值，涉及旧假设编号、旧样本/数值、旧状态方向的描述已被本轮母稿替代，不可据旧图直接复刻内容。优先沿用交大模板与现有可编辑布局；L01 P03 展示具体主张与证据缺口；L07 分开结果和机制；L09–L15 使用可复算构造包。重新制作时逐页校验映射，尚未据本轮内容重建 PPT。

## 二、关键页契约

| P01 | 只识别课次 | 第 2 讲 + “科研伦理与 Agent 边界” | P02 回扣第一课 | 不把完整正式课名塞进封面 |
| P03 | 先独立判断再表达理由 | 放大虚构未公开合作稿情境及个人外部模型使用环境，右侧给允许、有条件允许、禁止三档选择；初始屏显不提前显示判断答案。 | P04/P05 提供规范依据 | 虚构双标、三档选择、决定性理由；不显示分钟数 |

| P05 | 两项制度来源并列 | CAS 网页与 SJTU PDF 左右等宽截图 | 回到具体任务执行更严格要求 | 来源身份、各自作用；不画成上下级关系 |

| P07 | 保留五字段支架但不展示空表 | 一行填好的风险记录 | P08 用三类处置练习 | Asset/Action/Risk/Control/Owner 均具体 |
| P09 | 发送前检查 | 五条件连续路径 | P10 处理条件失守后的恢复 | 条件可检查；不把条件式框架当上传授权 |
| P10 | 已经发送后的恢复 | 停止→评估→记录→沟通→切换 | 回应现实落差并进入生成数据边界 | 不用删除/隐瞒代替恢复 |
| P11 | 区分模拟数据与真实观测的用途和结论边界 | 模拟数据与真实观测的可用任务、可支持结论和越界说法用原生表格比较；明确课堂构造身份，作为短迁移例。 | P12 再以指标变更迁移到执行治理 | 材料身份、允许用途、可支持与越界结论 |

| P15 | 权限矩阵先写一行 | 原生六列表格保留对象或能力、只读范围、可写范围、是否允许执行、人工确认点、禁止事项；只填合作稿替代输入这一行，突出写回前确认文件与段落。 | 从原则进入课堂产出 | 确认点、禁止事项与更窄授权规则 |
| P17 | 工件状态不是完成百分比 | 原生状态链显示 draft、review、approved、stable 及各次迁移依据；反向连线标出新证据或边界变化导致回退，单一证据不得支持 stable。 | P18 用实例解释迁移依据 | 状态语义、迁移依据与回退规则 |
| P18 | 用一个工件生命周期说明追踪 | 同一个 evidence-map.md 以四次状态记录展开，逐次标明新增内容、复核依据和下游用途；保持工件身份而改变证据与判断。 | 解决抽象表格干燥问题 | 新增/修复、复核依据、下游用途 |
| P20 | 标记教师演示 | 大字风险—权限—审查—写回—日志 | P21/P22 展开同一任务 | 不教授平台菜单 |
| P22 | 教师演示有限写回 | 三件批准写回工件 + 明确禁止项 | 承接 P21 只读审查；P23 才由学生实践 | 只写权限一行、风险卡、AI 记录，不改问题、指标或状态 |
| P23 | 学生完成三件最小工件 | 左侧保留动作、两段顺序及三个保存文件，右侧给同一案例的权限行、风险卡、使用记录完成示例；样例明确标为课堂构造，未运行时如实记录。 | 两段实践共用同一页；P24 临时结对 | 风险卡、权限一行、AI 记录；追踪表移课后 |

| P26 | 课后持续更新 | 四步去向链 | 进入第 3 课检索 | 追踪表为课后持续记录，不新增课堂表单 |

## 三、制作与验收

- P04/P05 必须使用可核验的原始来源截图；图旁来源身份、备注完整引用与图片登记一致。
- 任务、风险、权限、状态、虚构标记和学生动作不低于 18 pt。
- P13 的检查、执行、trace、下一步及人工确认分支均必须可编辑；未获批准时保持停止，后续动作重新检查。
- P20–P22 明确为教师演示；P23 才是学生实践，学生可使用任一合规环境或 Markdown 备用路径。
- P24 标“临时结对”；固定同伴组在第 6 课前建立。
- 完整渲染必须来自最终正式 `slides.pptx`，旧 contact sheet 不得作为证据。

## 本轮代表页与反回归检查

本课先检查 P13 harness、P15 权限一行与 P23 实践停留页。五类代表页已获用户认可，并按去除底部制作说明的反馈扩展至整课。

- 当前交大母版、校徽、红标题带和页脚保留。AItalk 仅提供构图与验收参考，不复制维护 skill 或切换 SVG 生产引擎。
- 不使用删除正文图形后仅恢复文字的批量处理。每页明确声明必需对象、连接关系与文字角色，并在最终 PPTX 中复查。
- 文字按实际角色设定字号，不按位置、字符数猜测来源或正文；正文 22–24 pt，工件及必要标注至少 18 pt。
- 遮标题后检查主体语义；全尺寸看阅读质量，联系表看教学节奏。技术结果与视觉审阅分别记录。
