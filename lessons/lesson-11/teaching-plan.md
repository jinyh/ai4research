# 第 11 课教师教案｜实验自动化与 AutoResearch 循环



## 本轮共同诊断与迁移（2026-10-12）

本课核心判断：应该恢复、回退还是停止，哪些记录必须保留？

按[学生任务](./judgment-task.md)先独立作答，再由教师校准并开放讨论；[教师依据](./judgment-teacher.md)在校准时揭示。首次共同判断前，完整示例只展示相邻案例的方法，不展示本题答案。

**迁移：**在同一微型项目执行 changed.py，使用 execute --fault-once；检查失败后状态，人工批准后恢复，比对 run_id 与完成任务，解释预算耗尽、完成或停止决定。

**达标：**验证中断保留、重启不重复成功任务、输入或实现改变须新建目录。保留无改善和负结果；原阅读卡 replay 仅作相邻示范，权限接口不等于系统隔离。

**下次输入：**L12 以已验证动作设计一个实质工作流环节。

**课外：**指定阅读15分钟＋准备10分钟＋补全35分钟。安装与排障计入每课60分钟总上限；超时先缩小任务。


## 一、本课定位

- 学时：2 学时，90 分钟
- 研究链路：阶段七"原型验证（实验追踪）"
- 教学类型：讲授 + 教师演示 + 个人实践 + 个人复核与开放质询
- 核心问题：如何在固定指标、预算和停止条件下自动迭代，而不让评价协议漂移或失败被删除？
- 课堂产出：受限循环说明（四约束 + 五步骨架 + 审核点）+ 至少一次失败迭代记录 + 四约束短分析
- 正式提交：无（验证门在第 13 课后）

本课必须建立三项共识：

1. 实验自动化循环不是"跑很多次"，而是"假设→运行→度量→评价→回写/回退"五步在固定约束下可重复运行，每步留下可审查工件。
2. 固定指标、预算、停止条件、回退机制四项缺一不可；缺一项循环就退化为无界搜索或隐性 p-hacking。
3. AutoResearch / AI Scientist 是分析对象，不是结论外推的依据；它们在哪些维度上"已由系统处理"、哪些维度上"仍需人工判断"是本课的核心判断训练。

本课承接第 10 课受限 Agent 执行——把"跑通一次"扩展为"可重复运行的循环"。本课为第 12 课个人工作流设计铺垫——第 12 课会把本课的循环骨架重新组合为服务于学生自己科研动作的工作流。

## 二、学习目标

完成本课后，学生能够：

1. 说明 `Edit → Evaluate → Keep/Discard → Repeat` 循环的适用与不适用条件；
2. 为自动迭代设置固定指标、预算、停止条件和回退机制；
3. 识别指标被工作流篡改的失败模式，避免评价协议漂移；
4. 用八维框架拆解 AutoResearch / AI Scientist，指出每个维度上系统已处理与仍需人工判断的部分；
5. 写出失败实验保留规则，避免选择性删除；
6. 把自己一个可重复科研动作改写为受限循环，标出人工审核点与回退路径。

### 安全与资源口径

- 不要求学生自费购买 API token；循环可在纸面或 Markdown 模板中完成骨架设计。
- 不向外部模型发送未公开论文、敏感数据或学生私人材料（沿用第 2 课伦理检查）。
- 循环运行如使用大模型 API，记录 API 提供方、版本、调用日期；费用由学生自控，不构成评分项。
- 本课不要求循环跑完所有迭代，只要求跑通骨架与至少一次失败迭代记录。

## 四、90 分钟流程

| 时长 | 环节 | 页面/材料 | 课堂结果 |
| --- | --- | --- | --- |
| 5 分钟 | 入口诊断与材料确认 | P01、P03；判断任务包 | 打开输入，写下待判断问题 |
| 10 分钟 | 核心方法与相邻案例示范 | P04、P07、P08；判断任务包 | 示范不同对象上的方法，不揭示共同题答案 |
| 10 分钟 | 对共同任务独立作答 | P03；判断任务包 | 每人记录初始决定、依据和缺证 |
| 10 分钟 | 公开比较判断与证据 | P03；判断任务包 | 先独立作答，再比较依据与分歧 |
| 5 分钟 | 教师揭示依据、校准关键误区 | P10、P11、P13；判断任务包 | 允许不同结论，核对推理与范围 |
| 15 分钟 | 本人项目迁移一 | P16；判断任务包 | 完成决定及第一项核验 |
| 5 分钟 | 教师中点点评 | P16；判断任务包 | 处理共性卡点，不替作者选答案 |
| 15 分钟 | 本人项目迁移二 | P16；判断任务包 | 实际回写并完成相称验证 |
| 10 分钟 | 个人反查与修改 | P18；判断任务包 | 从输出反向找证据并决定修订、补证或保留 |
| 5 分钟 | 收束、记录下次输入 | P19、P20；判断任务包 | 核对产出与课外预算 |

总计 90 分钟；独立共同作答 10 分钟、本人迁移 15＋15 分钟，中间有教师点评。首次判断在入口开始；主要独立共同作答在开课 15 分钟后。其余页为按需方法参考，不要求顺序逐页讲完。

**本课输入：**L10 已核准的动作；冻结队列与预算。

**两段本人迁移：**在同一微型项目执行 changed.py，使用 execute --fault-once；检查失败后状态，人工批准后恢复，比对 run_id 与完成任务，解释预算耗尽、完成或停止决定。

**验证与输出：**验证中断保留、重启不重复成功任务、输入或实现改变须新建目录。保留无改善和负结果；原阅读卡 replay 仅作相邻示范，权限接口不等于系统隔离。本人队列运行目录、恢复证据与停止决定。

**备用：**断网使用任务包；工程课最终仍须实际运行。

## 六、教师演示脚本

1. 打开 assets/reading-card-workflow/README.md，说明全部输出为构造回放、无模型调用。
2. replay --fault-once 注入 T02-card 失败，查看 events 与 state 后决定恢复。
3. 再次 replay 只补未完成项，旧失败与新 run ID 均保留。
4. evaluate 显示 T01 改善、T02 无改善、T03 负例；区分技术失败和评价结果。
5. 用 AutoResearch 作方法选优的短对照，保留完整八维材料为课后参考。
