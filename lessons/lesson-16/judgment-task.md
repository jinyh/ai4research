# 第 16 课共同诊断｜结论到决定的反向抽查

## 先独立判断

**问题：展示结论能一路反查到什么，哪处断点会改变决定？**

输入：L15 修订版、实际运行与反馈处理。先记录判断和依据，再与同伴比较；课堂校准后可修订并写明改变原因。答案有分歧时回到具体记录。已有示例可作方法参考，不替代本人的初始判断。

## 原始材料与待比较选项

抽查规则对全班一致，直接使用本人项目：

1. 展示者选一条关键结论并定位结果表/证据项。
2. 同伴从该项反查运行 ID、输入版本和评价定义。
3. 作者指出上游取舍：为何选此 baseline、范围或停止规则。
4. 再展示一次真实失败、放弃的备选或未决问题，并解释如何改变结论或行动。

若某环节打不开，先记录缺口；保存输出可用于查看，但不能冒充现场运行。

**待决定：**证据链完整、局部可修复缺口、当前不能支撑结论三种情况如何处理？

把“初始判断—证据位置—仍缺什么—核验后决定”写在现有笔记中。允许回答“仍不能判断”，同时指出下一项能改变判断的证据。

## 迁移到本人项目

全员闪电展示；固定 3–4 人组轮流反查。直接打开现有材料，说明一个关键取舍、失败或未决问题，并完成最终提交与复盘。

**验证：**每位学生留一条由真实同伴完成的反查记录；教师另记抽查对象与范围。断网使用本地工件，机器故障展示保存 trace 并约定实际运行复核。

**保存位置与达标证据：**论证门与最终个人项目：报告、工作流、原始证据与复盘。

**下课去向：**课程收束；仅修明确反馈缺口，不新增研究任务。

## 完成标准

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

断网时保留同样的判断要求，使用包内文本、存档或本地工件。工程课纸面诊断仅作备用练习，最终仍须补本人实际执行、实质修改和对照评价。提前完成者可寻找一个使自己决定改变的反例；不增加课后任务。
