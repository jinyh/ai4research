# 第 16 课教师教案｜学生最终分享、论证门与期末项目


## 整体复审补充：板书、诊断与串词（2026-09-15）

本节替换同类口头提示，不增加既有时段。开场诊断嵌入现有开场/回顾，后续再沿原实践时段操作。

- **板书主线**：问题 → 证据 → 判断 → 工作流作用 → 边界。
- **诊断问题**：总展示能否只放成功结果？
- **预期回答**：应能反查关键依据、失败/局限、人工判断和AI核验。
- **常见误答后的追问**：普通技术故障进入修复，不能和伪造记录混为一谈。
- **过渡串词**：“用抽查发现的具体缺口完成最终修订与归档。”
- **当堂最小产出**：本人论证门完整材料及真实抽查记录。
- **退出记录**：写“已完成的动作、本人项目仍缺的证据/工件、下次补齐位置”。使用教师包时标明课堂方法练习，不能据此宣称本人研究门通过；正式提交课次仍为第 6、9、13、16 课。


## 一、本课定位

- 学时：2 学时，90 分钟
- 班级容量：按 25 人满员推演
- 输入：第 15 课已评审和修改的项目工件、展示页、证据与工作流 trace
- 课堂产出：全员展示完成记录、分组演示与抽查记录、课程复盘初版
- 正式提交：第 16 课论证门与期末个人项目合并包

本课不再讲授新的方法框架，也不要求学生另做一份与项目仓库分离的汇报文档。全员都获得公开表达机会，再在小组中展示可核验证据与工作流。

## 二、学习目标

学生能够：

1. 在闪电报告中说清研究问题、关键结果状态和结论边界；
2. 在分组演示中定位一条证据或工作流 trace、一次失败和一个人工判断；
3. 说明 AI 的有效、误导与核验边界；
4. 将第 15 课反馈处理落实到实际工件；
5. 完成论证门与课程复盘的最终自查。

## 三、90 分钟与 25 人容量推演

| 环节 | 整数分钟 | 容量设计 | 教师动作 | 学生产出 |
| --- | ---: | --- | --- | --- |
| 开场 | 5 | 全班 | 说明两层展示、换场和抽查规则 | 打开闪电页与项目材料 |
| 全员闪电报告 | 50 | 25 人×2 分钟时段（含交接）；严格连续换人 | 只记录问题、结果状态与边界，不逐人长评 | 25 份公开报告记录 |
| 分组证据/工作流演示及抽查 | 25 | 7 组并行（4 组×4 人＋3 组×3 人）；每人约 5—6 分钟 | 巡回抽查 2—3 人的实验 ID、引用或 trace | 分组核验表、抽查记录 |
| 全课复盘 | 10 | 全班 | 汇总支持／反驳／仍不能判断、失败与责任 | 八阶段复盘初版 |
| **合计** | **90** |  |  |  |

首次学生动作在开场即发生：打开已有闪电页和项目材料，定位待展示的结论。换场计入每人的 2 分钟时段：闪电报告页预先按名单排序；报告者在时段结束前完成表达并交接，不将 50 分钟全部按净发言时间排满。若实际人数少于 25 人，节省时间优先增加分组质询，不增加教师讲授。

## 四、两层展示契约

### 全员闪电报告

只回答三项：研究问题和关键判断；最关键结果及其“支持／反驳／仍不能判断”状态；当前结论边界。不得把五个问题全部塞进两分钟。

### 分组证据/工作流演示

展示：一条证据或实验记录如何回到结论；Agent Workflow 改善了哪个动作；一次失败及修复；一个不可外包的人工判断；AI 如何被核验。组员按门条件追问并记录。

### 教师抽查

指定一条实验 ID、引用或工作流 trace。普通环境故障、依赖缺失或诚实记录的复现失败进入修复与复盘；编造结果、隐瞒失败、越权访问或伪造记录才按学术规范红线处理。

## 五、统一案例提醒

需要示范时使用[贯穿案例](../../course/reading-card-case.md)：3 份教学构造源文本、6 份固定输出、8 项基准条件；遗漏率 3/8 与 4/8，T03 为负例。Q1 在包内方向一致，H1/A2 未决，其他质量未测；没有模型调用或随机重复。示例只示范反查路径，不能替代个人项目的论证门证据。本课教师内容复核状态仍以 README 为准。

## 七、教师执行清单

课前：收集 25 人顺序；按 7 组分配；检查每人闪电页只含三项；准备抽查表；准备离线记录模板。

课堂中：严格控制连续换人；不在每人后点评；分组阶段抽查 2—3 人；遇普通故障记录根因和修复责任，不当场逐台排障；发现红线证据时单独记录并按 assessment.md 处理。

结束前：确认展示记录、抽查结果、复盘初版和提交路径均可定位；提醒本课正式提交条件以 assignments.md Checkpoint 4 为准。

## 八、验收与备用路径

- [ ] 25 人容量下全员获得含交接的 2 分钟公开报告时段；
- [ ] 每位学生在分组中展示证据/工作流，而非只听报告；
- [ ] 教师抽查有对象、位置、结果和后续动作记录；
- [ ] 五个必答问题由两层展示共同覆盖；
- [ ] 反馈处理记录不要求机械拒绝；
- [ ] 普通失败与学术规范红线已区分；
- [ ] 课程复盘回到八阶段链路和不可外包判断。

设备故障时闪电报告用静态页继续；分组演示改为日志、截图、diff 或纸面追踪；抽查不能现场完成时记录为课后核验，不自动判红线。

## 九、讲后复盘

记录实际换场损耗、25 人是否全部完成、分组每人是否有足够演示时间、抽查是否误伤普通技术失败、以及哪些论证门缺口需在成绩确认前按规则修复。
