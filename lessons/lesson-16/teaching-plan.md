# 第 16 课教师教案｜学生最终分享、论证门与期末项目

## 一、本课定位

- 学时：2 学时，90 分钟
- 研究链路：阶段八"回写与表达成案+全链路收口"
- 教学类型：讲授 + 学生陈述 + 教师抽查 + 同伴门条件互查 + 课程复盘
- 核心问题：研究闭环是否完整？个人工作流是否可审计、可复用？每个关键结论能否从问题、证据、判断、实验反向追溯到结论？
- 课堂产出：论证门材料初版（`report.md` 收口版 + 可追溯证据链 + 最终 Agent Workflow 收口 + 伦理与 AI 披露确认 + 工件状态一致性）+ 课程复盘初版
- 正式提交：**论证门材料与最终个人项目合并提交**（第 16 课，全课第四次正式提交，权重最高）

本课必须建立三项共识：

1. 论证不是"写完一篇短文"，而是每个关键结论能从问题、证据、判断、实验反向追溯到结论；论证门检查的是可追溯链路，不是分段汇报。
2. 期末项目提交的是当前项目版本（链接/tag/压缩包），不重复制作汇报文档；第 1-15 课所有产出都已回写同一项目，本课只做收口、抽查和复盘。
3. 课程复盘不是感想，是对八阶段研究链路在本人项目中作用的反思，含 AI 使用边界和不能自动化的判断——呼应第 1 课"研究责任仍由人承担"。

本课是全课第四次正式提交节点，也是"回写、评审与表达"模块（第 14-16 课）的末课，更是全课的最后一课。本课收口全课：第 1 课八阶段链路、第 2 课伦理与权限、第 6 课问题门、第 9 课判断门、第 13 课验证门、第 14 课论文式写作、第 15 课同行评审预检，全部在此汇总为论证门与期末项目合并检查。教师可抽查一次复现、一个引用或一条工作流 trace。

## 二、学习目标

完成本课后，学生能够：

1. 把论文式短文组织成"问题→证据→判断→实验→结论"的可追溯链路，每个关键结论至少绑定一项直接证据或实验结果及一个上游研究判断；
2. 对照期末项目模板逐项核对全工件，确认提交包完整、工件状态追踪表与实际门检查结果一致；
3. 用 3-5 分钟陈述研究问题、关键证据、工作流真实作用、AI 使用边界和结论适用边界；
4. 处理第 15 课同行评审意见，记录采纳、拒绝和修改理由；
5. 讨论内部、外部、构念和结论有效性对本项目的威胁，或给出适合本项目类型的等价威胁分析；
6. 对照论证门条件完成提交前自查（逐项对齐 assignments.md Checkpoint 4 之 10 项）；
7. 复盘八阶段研究链路在本人项目中的作用，说明 AI 在哪里有效、哪里误导、如何核验，以及哪些判断不能自动化。

### 安全与资源口径

- 不要求学生自费购买 API token；陈述和复盘可在纸面或 Markdown 模板中完成。
- 不向外部模型发送未公开论文、敏感数据或学生私人材料（沿用第 2 课伦理检查）。
- 复现抽查如需运行工作流，记录 API 提供方、版本、调用日期；调用费用由学生自控，不构成评分项。
- 失败日志必须保留，不得为了"演示成功"静默重跑删除失败痕迹（学术规范红线，沿用第 13 课）。
- 论证门材料提交指向当前项目版本，不重复制作汇报文档。
- 陈述超时按选课人数采用分会场、海报/演示轮转或课前短视频，论证门标准不变（见备课规划第 16 课风险与预案）。

## 六、教师演示脚本

### 演示前状态

- 演示项目只含公开或贯穿案例内容；
- 投屏前确认终端不显示凭据；
- 准备第 13 课 evaluation-report.md 收口版样例；
- 准备第 14 课 `report.md` 收口版样例（论文式短文 + 可追溯证据链 + 复盘）；
- 准备"分段汇报冒充论证"反例；
- 准备"结果无实验 ID"反例；
- 准备论证门条件自查清单（10 项，可投屏）；
- 准备 Alley 2013 陈述结构投屏版；
- 准备陈述时间控制表；
- 选定 2-3 个学生的实验 ID、引用或工作流 trace 用于复现抽查。

### 演示步骤

1. **论证不是分段汇报（0-12 分钟段内）**：展示"分段汇报冒充论证"反例（问题段写背景、方法段写做了什么、结果段写数字、结论段写"方法有效"），让学生指出它没回答什么——证据链在哪？实验 ID 在哪？哪个判断支持结论？改写为可追溯论证单元（主张→证据→推理→边界）。展示贯穿案例的论证链收口：短文结果段"阅读卡工作流把遗漏率从 0.31 降到 0.18"必须能反查到 `exp-001..exp-010`（实验 ID）和 `E3`（证据项）。

2. **可追溯链路与陈述结构（12-25 分钟段）**：演示把贯穿案例压缩为 3 分钟五段陈述：问题（0:00-0:40）→证据（0:40-1:20，含 `exp-001..exp-010` 和 `E3`）→工作流（1:20-2:00，含 baseline=自由摘要、3 次运行、改善遗漏率但 2 篇图表论文反高）→AI 使用（2:00-2:30，有效=关键词扩展，误导=3 条证据角色错标经人工审核拦截，核验=回源和双盲 rubric）→边界（2:30-3:00，n=20 CS 单一、A2 未排除、不外推）。强调：听众听完应该能够复述你的研究论证，并知道去哪里检查每一条主张。

3. **学生陈述与复现抽查（25-45 分钟段）**：学生按 3 分钟/人陈述（超时按分会场/海报/短视频）。教师在陈述间隙或陈述后抽查 2-3 个学生的实验 ID、引用或工作流 trace：指定一个实验 ID 要求现场或课后复现；指定一条引用要求回到原文核验；指定一条工作流运行记录要求展示从输入到输出的完整 trace。抽查不是新增作业，是对已有材料的核验。抽查失败按学术规范红线处理。

4. **论证链收口与修改落实（45-65 分钟段）**：投屏贯穿案例的修改落实：第 15 课同伴评审提出三项修改（补实验 ID、补 baseline 标注、把"方法效应"改为相关性表述并补 A2 未排除），处理记录为修改一采纳、修改二采纳、修改三采纳（已改为相关性表述，结论从"工作流降低遗漏率"改为"小样本下工作流组遗漏率低于 baseline，但时间投入替代假设未排除"）。强调：拒绝理由不能"感觉不对"，要写具体问题。

5. **工件状态一致性与复盘（65-78 分钟段）**：演示工件状态追踪表一致性检查：`problem-definition.md` approved（第 6 课）、`experiment-spec.md` approved（第 9 课）、`agent-workflow.md` approved（第 13 课）、`evaluation-report.md` approved、`report.md` approved（本课）、关键结论 H1 标"支持（待验证）"非 `stable`。演示八阶段复盘：问题从宽泛主题收敛为可检验问题；第一性原理必要条件经受住实验；主假设 H1 被小样本支持，A2 未排除；工作流改善遗漏率但暴露任务契约边界（图表为主论文）；结论可反向追溯但边界受限。演示 AI 使用边界复盘：有效=关键词扩展和术语解释；误导=3 条证据角色错标（原文是博客转载不是同行评议论文）；核验=回源和双盲 rubric；不可自动化=问题重要性、baseline 公平性、结果是否支撑结论、AI 参与披露。

### 演示判断点

1. 分段汇报和可追溯论证的区别是什么？
2. 结果表/图为什么要追溯到实验 ID？不追溯会怎样？
3. 威胁有效性"可能存在威胁"和具体威胁的区别是什么？
4. 同行评审修改落实时，拒绝理由为什么要具体？
5. `stable` 标记为什么要满足两项独立证据？单一证据为什么必须降级？
6. 陈述五段结构为什么不是五个并列段落，而是一条压缩版可追溯链路？
7. 复盘的"AI 使用边界"和"不能自动化的判断"分别回答什么？

### 失败演示

可预先准备两个反例：

- **反例一：分段汇报冒充论证**。展示一个写着"我研究了 X，我做了 Y，结果是 Z，方法有效"的报告，让学生指出它没回答什么——证据链？实验 ID？哪个判断支持结论？改写为可追溯论证单元。

- **反例二：结果无实验 ID**。展示一个结果段只写"实验结果表明遗漏率下降"但不给实验 ID 或运行记录位置的报告，让学生指出这是学术规范红线（结论无法追溯到证据）。改写为给实验 ID 和运行记录的版本。

失败不重跑到成功。让学生指出问题，再改写为受限版本。

- [ ] 工件状态追踪表与四次门检查结果一致，`stable` 满足两项独立证据或已降级
- [ ] 3 分钟陈述完成五段结构（问题→证据→工作流→AI 使用→边界）
- [ ] 复现抽查通过（教师指定实验 ID/引用/trace 可核验）
- [ ] 课程复盘含八阶段反思 + AI 使用边界（有效/误导/核验/不可自动化）+ 不能自动化的判断
- [ ] 同伴互查门条件检查记录（10 项逐项标注已满足/待补全/未满足）
- [ ] AI 使用记录包含本课论证收口、修改落实、复盘的用途、Context、输出用途和人工核验方式

本课产出是论证门材料初版。课后学生完成自查和补全后提交论证门材料与期末项目合并包，具体条件以 [assignments.md](../../course/assignments.md) Checkpoint 4 为准。

## 八、讲后复盘

教师课后记录：

- 学生是否仍把论文式短文写成分段汇报？
- 结果表/图是否真的追溯到实验 ID，还是只写数字？
- 威胁有效性是否写具体，还是只写套话？
- 同行评审修改是否真的落实为采纳/拒绝/理由，还是只标"已改"？
- `stable` 标记是否被滥用（单一证据就标稳定）？
- 陈述是否回答五个必答问题，还是只讲"我做了什么"？
- 复现抽查是否通过？哪个学生被抽查？抽查结果如何？
- 课程复盘是否具体（八阶段反思 + AI 使用边界），还是写成感想？
- 论证门 10 项条件中，哪一项学生最容易不满足？（经验上第 2 项结果追溯实验 ID、第 5 项结论绑定证据和判断、第 9 项工件状态一致性最易缺失）
- 全课收口：第 1 课"研究责任仍由人承担"在本课是否被学生真正理解和落实？
- 下一轮开课需要在哪一课加强论证链训练？（经验上第 14 课论文式写作需加强证据回写）
