# 第 16 课逐页脚本｜学生最终分享、论证门与期末项目

## 一、使用说明

### 本课唯一主目标

> 学生把第 14-15 课的论文式短文和同行评审预检收口为论证门可检查的最终项目——每个关键结论能从问题、证据、判断、实验反向追溯到结论，个人 Agent Workflow 的真实作用和失败被展示，AI 参与被如实披露，课程八阶段链路被复盘——并完成论证门与期末项目合并提交。

本课不追求在 90 分钟内完成全部 10 项门条件自查，也不要求课堂内提交。目标是让学生亲手完成一次"论证链收口 → 陈述 → 复现抽查 → 同行评审修改落实 → 工件状态一致性 → 课程复盘 → 门条件自查"的可复盘链路。本课产出是第 16 课论证门与期末项目合并提交的直接材料。本课是全课的最后一课，收口全课：呼应第 1 课"研究责任仍由人承担"。

### 适用条件

- 21-40 人；
- 连续 90 分钟；
- 中文授课，英文仅保留论文名、工具名和必要术语；
- 正式 PPTX 以本稿为现行内容源制作，并按 [ppt-quality-gates.md](../../course/ppt-quality-gates.md) 与 [ppt-design-criteria.md](../ppt-design-criteria.md) 完成检查；
- OpenCode、Git 和模型后端尽量在课前确认；
- 学生优先使用自己的项目材料（第 14-15 课产出）；没有者沿用贯穿案例；
- 本课为论证门+期末项目正式提交节点，课后提交合并包。

## P04｜论证不是"写完一篇短文"

### 屏显内容

**分段汇报（不合格）**：

> 问题段写背景，方法段写做了什么，结果段写数字，结论段写"方法有效"。

**可追溯论证（合格）**：

> 在 20 篇 ACL Anthology 2024-05 论文的小样本下（实验 ID exp-001..exp-010），阅读卡工作流组遗漏率均值 0.18±0.03，低于自由摘要 baseline 的 0.31±0.04（证据项 E3）；但时间投入替代假设（A2）未排除，结论标"支持（待验证）"非 stable。

分段汇报回答"我做了什么"；论证回答"每个结论来自哪里"。

> 论证门条件之五：每个关键结论至少绑定一项直接证据或实验结果及一个上游研究判断。

### 视觉结构

左右对照。左侧分段汇报（灰显并标红"不合格"），右侧可追溯论证（标绿"合格"）。底部论证门条件提示。

### 教师讲述备注

最常见的错误是把论文式短文写成分段汇报。分段汇报回答"我做了什么"，但论证门要的是"每个结论来自哪里、谁在什么条件下作出了什么决定、什么证据支持它、什么证据限制它"。注意右侧也写了"A2 未排除"和"非 stable"——结论的边界必须写入，不能只写"方法有效"。

### 互动／操作

让学生把自己的短文一个关键结论改写为可追溯论证单元（主张→证据→推理→边界）。如果写不出证据编号，说明还停留在分段汇报。

### 建议时间

5:09-6:51。

### 来源与事实边界

讲义 §二·1；Booth et al. *The Craft of Research*, 5th ed., Chapter 5 and 7（[reading-list.md](../../course/reading-list.md) 第 14 课核心阅读，本课重读）；[assignments.md](../../course/assignments.md) Checkpoint 4 条件之五。

## P05｜可追溯链路：问题→证据→判断→实验→结论

### 屏显内容

论证门的核心是可追溯性——结论能反向回到证据、实验、判断和问题。

| 链路节点 | 来自阶段 | 论证门检查 |
| --- | --- | --- |
| 问题 | 阶段 1（第 6 课问题门） | 具体可检验、有非例和可证伪命题 |
| 证据 | 阶段 4-5（第 3-5 课） | 区分主证据、补充、冲突、空白 |
| 判断 | 阶段 6（第 7-9 课） | 写明取舍理由、适用边界、待验证 |
| 实验 | 阶段 7（第 9-13 课） | 追溯到实验 ID 和工作流运行记录 |
| 结论 | 阶段 8（第 14-16 课） | 绑定证据和上游判断；stable 满足两项独立证据 |

> 这条链路不是新东西，是八阶段研究链路的收口。

### 视觉结构

上方五节点双向链路（正向箭头表示论证推进，反向箭头表示审查）。下方一句判断。

### 教师讲述备注

可追溯链路是全课的收口。第 1 课 §2.8 给出的基本论证单元"主张→证据→推理→边界"，本课要求每个主张都能回答："这个结论来自哪里？谁在什么条件下作出了什么决定？"反向检查是全课的方法论核心——第 1 课 §三已建立"追溯与核验：结论可反向检查，AI 输出不跳过核验"，本课是这条原则的最终验收。

### 互动／操作

让学生检查自己短文的一个关键结论：能反查到哪个问题、哪条证据、哪个判断、哪个实验 ID？

### 建议时间

6:51-8:34。

### 来源与事实边界

## P06｜结果表或图追溯到实验 ID

### 屏显内容

论证门条件之二：结果表或图能够追溯到具体证据项、实验 ID 或工作流运行记录。

**不合格**：

> 实验结果表明，阅读卡工作流降低了遗漏率。

**合格**：

> 阅读卡工作流组遗漏率均值 0.18±0.03（实验 ID exp-001..exp-010，证据项 E3，运行记录 run-2026-05-12-seed-100/200/300），低于自由摘要 baseline 的 0.31±0.04。

每张表、每张图、每个关键数字必须能被反查。

> 不能把工作流的自我报告当作实验结果——以实际文件变化、日志和 diff 为准。

### 视觉结构

左右对照。左侧不合格（灰显标红），右侧合格（标绿，实验 ID/证据项/运行记录高亮）。底部第 1 课 §五·4 提示。

### 教师讲述备注

结果段最常见的错误是只写"实验结果表明..."而不给实验 ID。第 1 课 §五·4 已建立"以实际文件变化为准，不只看 Agent 自述"——结果段的每个数字必须能反查到实验 ID。工作流的自我报告不能当作实验结果，必须以 diff、日志和运行记录为准。

### 互动／操作

让学生检查自己短文结果段的每张表/图/数字：能反查到哪个实验 ID？找不到的标注待补。

## P07｜威胁有效性或等价威胁分析

### 屏显内容

论证门条件之三：讨论内部、外部、构念和结论有效性，或给出适合本项目类型的等价威胁分析。

| 有效性 | 威胁示例 |
| --- | --- |
| 内部 | baseline 不公平、随机性未控制、评价协议漂移、工作流篡改指标 |
| 外部 | 样本小、领域单一、模型版本单一，不能外推 |
| 构念 | 指标没真正测量"目标动作改善"，只测了"能跑" |
| 结论 | 把相关性写成因果，把工作流参与写成方法效应 |

贯穿案例：内部盲评不彻底、外部 n=20 CS 单一、构念指标是否真测量改善、结论 A2 未排除。

> 用适合本项目的等价威胁分析，不强制四类齐全，但要写具体，不写"可能存在威胁"。

### 视觉结构

四行威胁表 + 贯穿案例对应。底部一句判断。

### 教师讲述备注

威胁有效性不是"可能存在威胁"的套话。每条要写具体：baseline 哪里可能不公平？样本为什么不能外推？构念有效性最容易被忽略——"遗漏率下降"是否等于"科研动作改善"，还是只等于"字段被填满"？第 13 课 §三·4 已展开，本课要求短文讨论段写至少两类具体威胁。文献型或系统型项目用等价威胁分析（来源覆盖度、检索偏差、标注一致性、复现可行性）。

### 互动／操作

让学生写出自己项目的至少两类具体威胁。

### 建议时间

10:17-12:00。

### 来源与事实边界

## P10｜最终 Agent Workflow 收口

### 屏显内容

论证门条件之七：最终 Agent Workflow 有运行说明、权限边界、评价结果和失败记录。

四项必备：

- 运行说明：最小命令、环境依赖、可重复执行动作
- 权限边界：只读/可写范围、禁止项、预算上限、停止条件、人工确认点
- 评价结果：至少一次可重复评价、baseline/前后对比、对原研究动作的实际影响

## P18｜本讲知识点总结

### 屏显内容

1. **完整闭环**：问题、判断、验证与论证四个门能追溯到对应工件。
