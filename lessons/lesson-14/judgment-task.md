# 第 14 课共同诊断｜证据支持多强的表达

## 先独立判断

**问题：哪种写法与当前证据相称？**

输入：L13 的实际评价、限制与决定。先记录判断和依据，再与同伴比较；课堂校准后可修订并写明改变原因。答案有分歧时回到具体记录。已有示例可作方法参考，不替代本人的初始判断。

## 原始材料与待比较选项

课堂构造数据：3 个公开构造文本、6 个保存输出；按条件加权遗漏率为 3/8 与 4/8；T03 方向相反；gold 已公开且用于开发；没有机制区分实验。

A：“阅读卡显著提高科研质量，证实结构化生成机制有效。”

B：“样本有限，所以没有任何可以报告的结果。”

C：“在这组公开构造输出中，阅读卡条件的限定条件遗漏率低 0.125；T03 方向相反。该描述用于评价流程审计，机制与真实论文效果仍需验证。”

**待决定：**逐句指出主张、证据、推理和范围；修订其中一项而不是只选 C。

把“初始判断—证据位置—仍缺什么—核验后决定”写在现有笔记中。允许回答“仍不能判断”，同时指出下一项能改变判断的证据。

## 迁移到本人项目

用本人真实比较写一个论证段，附一条结论追踪和实际 AI 披露；把已积累的问题、方法、评价、局限直接组织成短报告初稿。

**验证：**同伴从句子找到记录 ID 和评价定义；检查“显著”“证明”“消除”等词是否有证据。报告长度服务论证，不新建平行文档。

**保存位置与达标证据：**report.md 或主文档中的论证段、完整骨架与追踪条目。

**下课去向：**L15 以这份实际初稿进行同行评审。

## 完成标准

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

断网时保留同样的判断要求，使用包内文本、存档或本地工件。工程课纸面诊断仅作备用练习，最终仍须补本人实际执行、实质修改和对照评价。提前完成者可寻找一个使自己决定改变的反例；不增加课后任务。
