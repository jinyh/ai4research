# 第 14 课关键页设计规格

保留交大原生 master、layout、校徽、红标题带、页码和主题关系；标题实际 30–32 pt，正文 22–24 pt、默认常规字重，工件标注 18–20 pt。视觉主线是“一个结果→论证段→追踪记录→披露摘要→同伴核验”。以下要求与 v0.5.0 逐页稿同步。

| 关键页 | 页面任务 | 视觉下限 |
| --- | --- | --- |
| P05 | 固定虚构实验口径 | 20 篇→两条件→各 3 次→120 次输出→人工基准→主指标；虚构身份可见 |
| P06 | 区分结果与机制结论 | 原生可编辑柱图仅绘 0.18/0.31；± 未定义不画误差线；可写绿／越界红，H1 只到方向支持待验证 |
| P07 | 显示 H1/A1/A2/A3 | 主假设与三个替代解释同屏，未决状态不可隐藏 |
| P08 | 支撑个人论证实践 | 一个动作、输入／保存位置与四句完整虚构样例；不显示课堂计时 |
| P09 | 修复论证断裂 | 真正的可编辑文本 diff，红删绿增；记录位置与替代解释写入修改句 |
| P10 | 结论追踪 | 证据/运行记录、上游判断、缺失与三态可见 |
| P11-P12 | 日志与披露 | 取用讲义既有虚构披露示例；模型与调用日期不得冒充本次实际执行；显示具体人工纠错 |
| P13 | 同伴反向核验 | 三问和作者责任同屏，不要求机械拒绝 |

逐页 speaker notes 含闭合 `[Sources]`；虚构数字、案例和实验身份在屏显与 notes 中均明确。P14 独立知识总结，P15-P16 课后与交接。正式文件须经结构、实际字号、全尺寸逐页、contact sheet 与 PowerPoint 重开检查，记录与 LibreOffice 的字体差异。
