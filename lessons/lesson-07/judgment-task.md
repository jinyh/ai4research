# 第 7 课共同诊断｜竞争解释与区分实验

## 先独立判断

**问题：哪项最小验证能区分当前解释，什么结果仍不能区分？**

输入：L6 的命题与必要前提。先记录判断和依据，再与同伴比较；课堂校准后可修订并写明改变原因。答案有分歧时回到具体记录。已有示例可作方法参考，不替代本人的初始判断。

## 原始材料与待比较选项

教学构造观察：同一批输出，阅读卡遗漏率较低，但原评分者看得到格式和组别。

- H1：阅读卡确实更完整地保留限定条件。
- A2：格式和组别线索使评分者更容易认定阅读卡“保留了条件”。
- 当前只有原评分结果，没有盲标结果。

| 方案 | 保持/改变的条件 |
| --- | --- |
| X | 同一评分者沿原方法再评同一输出 |
| Y | 输出内容固定，隐藏组别与非语义格式，按同一准则重评 |
| Z | 同时换模型、文本和评分者，比较新均值 |

预算只允许一项。

**待决定：**选择 X/Y/Z 或一个更小的验证；为 H1 和 A2 分别预测结果，并指出混合解释。

把“初始判断—证据位置—仍缺什么—核验后决定”写在现有笔记中。允许回答“仍不能判断”，同时指出下一项能改变判断的证据。

## 迁移到本人项目

为主假设和一个替代解释写结果预测，选最小验证并说明什么结果会改变决定。默认工程题同时测坏记录拦截和正常记录保留。

**验证：**同伴寻找两假设给出同样预测的结果；如所有预测相同，重写假设或验证，不补形容词。

**保存位置与达标证据：**hypothesis-and-design.md 的预测表和实验选择理由。

**下课去向：**L8 以最薄弱的区分证据接受同伴质询。

## 完成标准

| 尺度 | 判断依据 |
| --- | --- |
| 需支持 | 完成操作，但理由、证据定位或验证仍有缺口。 |
| 达标 | 独立决定，证据可定位，完成相称验证，并更新本人项目。 |
| 优秀 | 识别替代解释或有效性威胁，以额外检查改变或加强判断。 |

课堂尺度对应课程的待改、达标、卓越；不新增每周成绩或提交。优秀依判断质量，不要求更多课外时长。

断网时保留同样的判断要求，使用包内文本、存档或本地工件。工程课纸面诊断仅作备用练习，最终仍须补本人实际执行、实质修改和对照评价。提前完成者可寻找一个使自己决定改变的反例；不增加课后任务。
