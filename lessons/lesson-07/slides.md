# 第 7 课逐页脚本｜机制假设、研究判断与实验设计

## 一、使用说明

### 本课唯一主目标

> 学生把第 6 课问题门收敛的可检验问题变成有依据、可区分、可停止的实验规格，并当场写下研究判断。

本课不追求在 90 分钟内完成完整实验设计，也不要求填满假设—指标—实验映射。目标是让学生亲手完成一次"问题门输出 → 多候选机制 → 替代假设 → 反证点 → 研究判断 → 假设—指标—实验映射 → AI 候选核验"的可复盘链路，并把 AI 生成的候选机制归位为"探索线索"。本课产出是第 8 课方案分享与第 9 课判断门的直接输入。

### 适用条件

- 21-40 人；
- 连续 90 分钟；
- 中文授课，英文仅保留论文名、工具名和必要术语；
- 正式 16 页 PPT 已按三门通过后的母稿制作，视觉规则见 [ppt-quality-gates.md](../../course/ppt-quality-gates.md) 与 [ppt-design-criteria.md](../ppt-design-criteria.md)；
- OpenCode、Git 和模型后端尽量在课前确认；
- 学生优先使用自己第 6 课问题门的可证伪命题；没有者沿用贯穿案例；
- 本课无正式提交，第 9 课判断门统一检查。

## P04｜结果预测说会发生什么，机制假设解释为什么

### 屏显内容

可证伪命题（第 6 课）：
> 在 20 篇计算机论文阅读任务中，使用结构化阅读卡相比自由摘要会降低 AI 生成摘要的限定条件遗漏率。

结果预测：
> 使用结构化阅读卡会降低遗漏率。

机制假设：
> 阅读卡的字段约束迫使生成时显式标注原文限定条件，使错读在核验阶段更易被发现；机制路径是"字段约束 → 生成时强制标注 → 错读更易暴露"，而不是"阅读卡让模型更聪明"。

| 要素 | 内容 |
| --- | --- |
| 自变量（干预） | 你将操作什么 |
| 因变量（结果） | 你将观察什么 |
| 机制路径 | 干预如何导致结果 |
| 反证点 | 什么观察使假设不成立 |

常见错误：
- 把"使用方法 X 会更好"当机制假设——只是结果预测
- 把"模型理解了原文"当机制——黑箱归因，不可观察

> 只写"会降低"不算机制假设——没有说"为什么"。

### 视觉结构

上方命题引文与三步机制路径（高亮中间过程），下方四要素表与两个错误样例（带删除线）。

### 教师讲述备注

区分两类表述。结果预测回答"是什么"，机制假设回答"为什么"。一个好的机制假设要指出中间过程、可观察现象、可被推翻，并能与替代解释区分。"模型理解了原文"不可观察，且无法与"记住了模式"区分——不算机制假设。四要素不是格式要求，是可验证的最低条件。缺反证点的假设任何结果都能解释，不算可证伪。

### 互动／操作

让学生指出：你之前写的"假设"更接近结果预测还是机制假设？用自己的命题填四要素。只听一个例子，不展开评价。

### 建议时间

10:00-13:00。

### 来源与事实边界

讲义 §二·1-2；第 1 课 §2.3 机制假设最小定义；[AGENTS.md](../../AGENTS.md) 证据标准。

## P05｜替代假设必须对同一结果给出可区分解释

### 屏显内容

主假设：字段约束 → 生成时强制标注 → 错读更易暴露

替代假设（同一结果的不同解释）：
- A1 任务转移：总错读率不变，只是从"限定条件"字段转到"作者主张"字段
- A2 标注假象：差异来自标注者提示，不是生成阶段真的少遗漏
- A3 选择效应：阅读卡只对特定结构论文有效，整体下降来自样本占比

多候选假设淘汰理由：
- 与第一性原理约束冲突
- 不可观察或不可测量
- 与证据地图主证据冲突且无法解释
- 课程周期内无法构造区分性实验
- 与替代假设不可区分

> 替代假设不是"另一个题目"，是对同一结果的不同解释。实验必须能产生不同结果来区分。

> Agent 建议只能生成候选项，最终机制判断由学生负责。

### 视觉结构

上方主假设一行与三个替代假设（各附预测差异：A1 总错读率不变 / A2 换标注者后差异消失 / A3 分层后效应集中），下方淘汰理由清单。

### 教师讲述备注

引用 Platt 的强推理：为主假设设计竞争解释和关键实验。替代假设必须可区分——如果实验无法在主假设和替代假设之间产生不同结果，这个实验不能"支持"主假设，只能"不反驳"它。A1/A2/A3 各自预测不同的可观察结果，这就是区分实验的逻辑。AI 给出的候选机制可能看起来合理，但如果不经过反证点和替代假设的区分检验，就只能算探索线索。候选越多不代表研究越好——淘汰理由比候选数量更重要。

### 互动／操作

让学生写一个替代假设。提示：它的结果必须和主假设不同。

### 建议时间

13:00-16:00。

### 来源与事实边界

## P06｜事实、假设、研究判断与待验证项必须分开落盘

### 屏显内容

| 类别 | 定义 | 在哪个工件 |
| --- | --- | --- |
| 事实 | 已被可核验来源支持、不在本课争议范围 | 证据地图主格 / 阅读卡 |
| 假设 | 当前未被直接证据支持、但可被实验检验 | 机制假设列表 |
| 研究判断 | 从证据和约束到行动的有理由取舍 | 研究判断记录 |
| 待验证项 | 需补证据或补实验才能升级 | 研究判断记录"待验证"字段 |

研究判断记录六字段（贯穿案例）：

| 字段 | 贯穿案例 |
| --- | --- |
| 判断内容 | 主要评价指标采用"限定条件遗漏率"，不用通用语言质量评分 |
| 取舍理由 | 研究可追溯性而非语言流畅度；通用评分无法区分"漏标"与"措辞差" |
| 适用边界 | 带引用的计算机论文摘要任务；外推需重验 |
| 依据 | 证据地图 E1 + 第一性原理"主张必须能定位原文" |
| 待验证状态 | 标注者间一致性未测；rubric 在 20 篇样本稳定性待跑 |
| 影响工件 | 实验规格的因变量定义、标注协议、停止条件 |

> "事实"不等于"绝对正确"，只意味着"当前不再争议"。

> 当场写，不课后补。

### 视觉结构

上方四类分类表（每行配工件图标），下方六字段表（贯穿案例）。右下角强调"当场写"。

### 教师讲述备注

这四类常被混在一起，导致事后无法复盘。证据地图里的 verified 条目在此意义上是事实；review 和 pending 是待验证项。把假设写成结论、把研究判断写成事实，都是常见错误。研究判断记录能防止一种常见现象：实验完成后，研究者根据结果反向改写"最初为什么这样设计"。保留当时的理由，才能诚实分析哪些判断正确、哪些需要修正。本课要求至少写一条完整六字段记录。

### 互动／操作

让学生指出：你第 6 课的哪些陈述是事实、哪些是假设、哪些是研究判断？你目前的设计中，哪个取舍最需要当场记录？

## P09｜公平 baseline 与停止条件共同决定实验可解释性

### 屏显内容

| 变量类别 | 贯穿案例 |
| --- | --- |
| 自变量 | 是否使用结构化阅读卡 |
| 因变量 | 限定条件遗漏率 |
| 控制变量 | 模型、解码参数、论文集、温度、最大长度 |
| 混杂变量 | 论文结构差异、标注者训练、任务记忆 |

实验规格至少写明：
1. 假设对应（每步验证哪条）
2. 样本与数据（数量、来源、是否预注册）
3. 步骤（谁执行、谁审核）
4. 度量标准（操作定义、标注协议、一致性指标）
5. 对照（baseline 与公平性）
6. 随机化与重复（种子如何记录）
7. 停止条件（运行次数、提前停规则）
8. 失败预案（不支持假设怎么办、baseline 跑不通怎么办）

> baseline 不是"任意一个对比组"，而是公平对照——控制变量须真正一致，混杂变量须被识别。

> 停止条件防止"跑到出现显著结果为止"的隐性 p-hacking。

### 视觉结构

上方变量表，下方八项实验规格清单。右侧"不公平 baseline"反例：模型不同、温度不同、论文集不同。

### 教师讲述备注

引用 Box et al. 与 NIST 手册：实验是模型—推论—数据—修正的迭代学习过程。比较、重复、随机化与区组是基本要素。baseline 不公平，"方法有效"的结论无法成立。常见错误：对照组换了一个模型、换了一个温度、换了一批论文——这都不是 baseline，是另一个实验。停止条件最容易被忽略。没有预先写明运行次数和停止规则，"跑完出现显著结果"就是隐性 p-hacking。预算和时间约束也要显式写。如果用 Agent 或自动化，还要写明只读/可写范围、人工确认点和失败日志保留（第 10-12 课系统展开，本课只标出哪些步骤拟用 Agent）。

### 互动／操作

让学生列出自己实验的控制变量清单，并写出停止条件。提示：跑多少次、何时停、什么条件下提前停。

### 建议时间

24:30-27:30。

### 来源与事实边界

讲义 §四·2-4；Box et al. *Statistics for Experimenters* §3.4；NIST/SEMATECH e-Handbook Experimental Design（[reading-list.md](../../course/reading-list.md) 第 7 课）；第 1 课 §2.7 原型验证实验规格要素。
