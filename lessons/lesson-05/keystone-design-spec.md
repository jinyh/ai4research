# 第 5 课关键页设计规格

依据 [正式课堂 PPT 设计准则](../ppt-design-criteria.md) v1.2.0。屏显文案、讲述、互动、时间和来源以 [slides.md](./slides.md) v1.0.0 为唯一现行母稿。

## 一、关键页集合

首轮关键页：`P01 / P02 / P04 / P07 / P09 / P10 / P13 / P14 / P15 / P18 / P20`。

| 风险类型 | 页面 | 选择理由 |
| --- | --- | --- |
| 开场与收束 | P01、P20 | 必须建立并回应“如何从阅读卡形成问题门可检查的证据结构” |
| 上游连接与失败模式 | P02、P04 | 阅读卡容易继续按论文堆叠，须显式转换为按问题组织 |
| 核心方法 | P07、P09、P10 | 候选文献角色与问题门四视图容易混写；候选题生成容易被限定在文献空白一条路径；空白容易被误写成领域结论 |
| 教师演示 | P13-P15 | 论文 A-E、检索字段和 AI 综述均为虚构教学样例，必须保持证据边界 |
| 课堂行动 | P18 | 27 分钟停留页必须支持窄矩阵、地图、空白检验、候选题记录和 AI 记录 |

## 二、关键页契约

### P01｜综述不是摘要堆叠，是按问题组织的证据结构

- **页面任务与主结论**：把本课从“多读几篇”转向“重组已核验材料”。
- **主视觉锚点及来源**：`阅读卡 → 按问题组织 → 证据结构` 单链；课程方法框架，非实证图。
- **与相邻页的叙事关系**：提出全课判断；P02 用第 4 课工件说明转换尚未完成。
- **最小成立内容**：课名、单链、阶段五与第 6 课问题门。

### P02｜阅读卡完成后，为什么仍不算综述

- **页面任务与主结论**：让学生识别“工件已有，但关系未建立”。
- **主视觉锚点及来源**：按论文排列与按子问题排列的对照；来源为第 4 课现行工件。
- **与相邻页的叙事关系**：承接 P01；为 P03 的最低产出建立必要性。
- **最小成立内容**：已有阅读卡、缺少跨文献关系、一次 2:30 短互动。

### P04｜摘要堆叠为什么不算综述

- **页面任务与主结论**：暴露逐篇复述无法支持冲突、边界和空白判断。
- **主视觉锚点及来源**：同一组材料的“论文顺序”与“问题结构”对照；课程构造示意。
- **与相邻页的叙事关系**：把目标转成失败模式；P05-P07 给出修复方法。
- **最小成立内容**：两个组织方式、至少三项缺失关系与不等号。

### P07｜从候选文献角色到问题门四视图

- **页面任务与主结论**：区分第 3 课角色标签和问题门证据地图视图。
- **主视觉锚点及来源**：左侧角色流向右侧直接/补充/冲突/空白四视图；来源为第 3 课材料与 `assignments.md` Checkpoint 1。
- **与相邻页的叙事关系**：承接 P06 的矩阵；为 P08-P11 的空白判断提供地图语法。
- **最小成立内容**：直接、补充、冲突、空白；“对比不自动等于冲突”；探索线索不入主格。

### P09｜候选题生成不止文献空白一条路径

- **页面任务与主结论**：阻止把"关键词→论文→空白"当作唯一问题来源；候选题池覆盖 ≥2 条生成路径、含 ≥1 个非文献空白路径候选。
- **主视觉锚点及来源**：六类生成路径表 + 候选题池约束卡（3/2/1）；据讲义 §四·1、§四·4 与 Qian 六种构思模式（课堂案例）。
- **与相邻页的叙事关系**：承接 P08 三类空白（文献路径）；P10 对所有路径的候选统一执行三步检验。
- **最小成立内容**：六条路径与检索的检验角色、候选题池 3/2/1 约束、"检索检验而非生成问题"判断句。

### P10｜空白候选必须经过真实性、重要性与可行性检验

- **页面任务与主结论**：阻止把“我没找到”升级为领域结论。
- **主视觉锚点及来源**：三步门槛与通过/回退分支；课程方法框架。
- **与相邻页的叙事关系**：承接 P08-P09 的空白与生成路径；P11 用非例限制误判。
- **最小成立内容**：三项检验、真实检索记录字段、回退含义、通过后进入候选题池。

### P13｜虚构阅读卡只训练从材料到矩阵的动作

- **页面任务与主结论**：演示 5 张材料如何按 3 个子问题进入矩阵。
- **主视觉锚点及来源**：阅读卡集合与窄矩阵；课程虚构教学样例。
- **与相邻页的叙事关系**：把 P05-P12 方法跑起来；P14 将矩阵转换为四视图地图。
- **最小成立内容**：3 个子问题、5 条不同角色、画面虚构标记。

### P14｜对比证据不自动形成冲突，空白也不预设命中为零

- **页面任务与主结论**：展示角色到视图的转换与诚实的空白状态。
- **主视觉锚点及来源**：E1-E4/G1 表格与三步检验字段；课程虚构教学样例。
- **与相邻页的叙事关系**：承接 P13 的矩阵；P15 只用已核验条目写四句草稿。
- **最小成立内容**：E3 不可比、E4 冲突、G1 待真实检索、通过后记入候选题池、虚构标记。

### P15｜四句 mini review 只使用已核验条目

- **页面任务与主结论**：把 AI 草稿从“共同支持”改写成可追溯的最小综合。
- **主视觉锚点及来源**：错误归纳、核验状态和四句骨架组成一条修订链；课程虚构教学样例。
- **与相邻页的叙事关系**：吸收 P14 地图；P16 收束失败路径与判断点。
- **最小成立内容**：一条不合格归纳、处理决定、四句骨架、虚构标记。

### P18｜27 分钟只要求跑通最小综述闭环

- **页面任务与主结论**：学生可不依赖教师口头提示完成窄矩阵、地图、空白首轮检验、候选题记录和四句草稿。
- **主视觉锚点及来源**：可抄写的四区工件模板；课程模板。
- **与相邻页的叙事关系**：P17 解释任务；P18 长时间停留；P19 用四问检查。
- **最小成立内容**：1 个子问题的窄矩阵、2 条证据主格、4 句 mini review、AI 记录字段、一行空白候选与一行候选题（表述 + 路径标签）与 27 分钟顺序。

### P20｜mini review 与证据地图共同进入问题门

- **页面任务与主结论**：收束本课并明确第 6 课只检查和收敛，不重做综述。
- **主视觉锚点及来源**：`四句 mini review + 证据地图 + 候选题池 → 问题门` 路径；课程项目链路。
- **与相邻页的叙事关系**：回应 P01；承接 P19 的个人反馈处理。
- **最小成立内容**：退出卡、三项输入、第 6 课路径和“不新增正式作业”。

## 三、模板与视觉边界

- 保留交大模板 master/layout、红色标题带、校徽、主题字体和页码；正文区只扩展矩阵、地图、检验门槛和工件模板。
- P13-P16 的论文 A-E、主张、检索字段与 AI 综述属于课程虚构教学样例，画面和 speaker notes 必须同时标注；不得仿造真实论文页面、DOI、产品界面或检索证据。
- P06、P07、P13-P15、P18 属于精读工件页，承担课堂阅读任务的文字不低于 18 pt；虚构标记同样不低于 18 pt。
- P18 是 27 分钟停留页，优先保证可抄写和后排可读；不得用装饰性卡片挤占模板空间。
- 标题必须单行；矩阵和表格只保留完成本页判断所需字段，其余进入 notes 或讲义。
