# 第 15 课关键页设计规格

保留交大原生 master、layout、校徽、红标题带、页码和主题关系；标题实际 30–32 pt，正文 22–24 pt 默认常规字重，工件标注 18–20 pt。视觉主线是“真实意见→处理决定→实际 diff→剩余边界”。以下要求与 v0.5.0 逐页稿同步。

| 关键页 | 页面任务 | 视觉下限 |
| --- | --- | --- |
| P04 | 校准故意含错分支 | 虚构身份、错误 stable 与正确降级并排 |
| P05 | 五维 rubric | 每维一个可检查问题，不做评分仪表盘 |
| P07 | 真实交叉评审 | 输入、轮转、写入位置与一条完成记录可见，不显示课堂计时 |
| P08 | 五类可选处理 | 动作与真实理由逐行对应，明确不凑类别；不画卡片墙 |
| P10 | 展示实际修改 | 前后 diff 只保留影响研究判断的变化 |
| P13 | 主要提交预检 | 已满足／部分满足／未覆盖三列标题与空选择框对齐，不代替学生勾选，不自造门条件 |

逐页 speaker notes 含闭合 `[Sources]`；普通失败与学术规范红线分开呈现。P14 独立总结后，P15 才交接第 16 课。正式文件须经结构、实际字号、全尺寸逐页、contact sheet 与 PowerPoint 重开检查；最终验收不沿用旧稿笼统“视觉通过”。
