## 一、总判断

**保留现行 16 课结构、四次研究门和个人项目制。正式授课前，先修“证据概念、假设逻辑、演示评价链”三个贯穿全课的问题，再处理单页密度与串词。**

课程想训练的能力是成立的：学生从一个真实科研问题出发，使用 AI 推进某个具体动作，并能解释依据、检查结果、修正判断、承担责任。五个教学模块与 25%／30%／25%／20% 四个评分维度基本对应。当前主要风险发生在这一目标被具体化的过程中：一些状态词代替了研究判断；一些不同层次的主张共用同一假设编号；演示用的简化工件与要评价的科研对象没有完全接上。

这次复审在[逐课审阅](./lesson-teaching-audit-20260915.md)基础上，重新对照课程定位、大纲、四次提交条件、评分、早期与完整模板，以及关键课次的现行讲义和教案。重点是整门课的学习依赖、概念一致性和研究推理。逐页清单及 P03 替换稿继续使用原报告；助教操作任务见[演示准备清单](./lesson-demo-assignment-20260915.md)。

## 二、应保留的设计，以及对上一轮判断的校正

1. **保留“文献先行、问题再收敛”的授课顺序。** 八阶段是研究动作地图；课堂从初步方向进入检索，再在 L06 收敛问题，逻辑成立。L01 讲义已经说明回退与迭代。教师需要把“初步问题→证据→修订问题”演出来，无须把课次机械排成阶段 1 到阶段 8。
2. **保留阅读卡贯穿案例与真实文献案例的分工。** 阅读卡方便跟踪同一问题的变化；Keshav 和 MI（机械可解释性）材料提供真正可查的原文与推断限制。MI 需要更好的术语入口和取舍，不能为追求全课同题而全部换成构造阅读卡数据。
3. **保留减负后的课堂最低产出。** L05 已明确完整空白检验和三候选题池在课后补齐，真正错位的是 L06 仍把完整检验描述成 L05 当堂完成。L14 已明确课后把一个论证段扩展为 `report.md` 初稿，L15 的入口并非完全没有交代。
4. **保留可复演的离线方案。** 课程允许可运行或可演示原型。无需每课都现场调用模型，更不必跑完整 AI Scientist 或 AutoResearch。演示必须有输入、步骤、可观察结果与记录；流程图、预期输出和实际复演要标明身份。
5. **保留失败与局限作为正常研究证据。** 现行权威考核已经区分普通失败与编造、隐瞒、越权。局部教案里的绝对说法应向权威口径修正。
6. **修正上一轮“统一到 L07 定义即可”的建议。** 统一编号仍有必要，但 L07 对主假设与 A1/A3 的逻辑关系也要重写，详见下面 R2。不能把上游定义整体当成正确答案复制到后课。

## 三、贯穿全课的八项发现

### R1｜证据、核验、成熟度和判断方向混在一起

**优先级：授课前必修。影响 L01–L07、L13–L16 和两个项目模板。**

证据位置：

- [L01 讲义 §一·2](../lessons/lesson-01/handout.md)及 P03，把“线索、草稿、候选证据、可提交结论”排成可升级身份。
- [早期模板 §4](../course/starter-template.md)和[完整模板工件状态表](../course/project-template.md)将 `stable` 简释为“可引用”。
- [L07 讲义 §三·1](../lessons/lesson-07/handout.md)把 `verified` 条目直接视为事实，并把 `review` 与 `pending` 放在同一组。
- [L13 讲义 §五第五步](../lessons/lesson-13/handout.md)用“评论性博客转载，不是同行评议论文”解释不能作为主证据，没有先交代具体待支持主张与原始来源。

**为什么影响教学：** 学生可能学成“正确来源格式→verified→事实→stable→可以写论文”的流水线。实际至少有四个不同问题：是否正确转述原文、材料支持哪个判断、结论支持到什么范围、这份项目材料经过了谁的审查。

**建议统一讲法：**

| 学生要判断什么 | 用什么表达 | 教师必须说清的边界 |
| --- | --- | --- |
| 这段拟用内容是否对得上来源？ | `pending / verified / verified-with-caveat / rejected` | 已核验转述，不等于原研究的结论已被独立证实 |
| 这项材料对当前主张有什么作用？ | 直接支持、补充、限制、冲突、检索线索等 | 先指定主张，再判断证据作用；同行评议身份不能代替这一步 |
| 现在怎样判断这个具体命题？ | 支持／反驳／仍不能判断＋依据和范围 | 判断必须绑定命题，不能只给整个文件贴一个方向词 |
| 项目材料经过了什么检查？ | `draft / review / approved / stable` | 沿用课程成熟度约定，避免把 `stable` 解释成引用资格 |

早期课堂先用中文问题训练判断，状态词在需要记录时出现。保留课程对 `stable` 的证据要求，同时说明：单一证据支持的有限结论、负结果和未决项都可以如实进入报告。

**复审验收题：** “一篇论文身份与转述已核验，但它只在一个数据集上得到结果。你能写什么，什么仍不能写？”学生应能同时说明来源核验已完成和外推依据不足，而不是只回答一个状态词。

### R2｜H1 同时承担效果、机制、可核验性和采用价值

**优先级：授课前必修。影响 L06–L09、L13–L16。**

证据位置：

- [L06 讲义 §三·1](../lessons/lesson-06/handout.md)的命题是“限定条件遗漏率更低”，却把“人工核验成本不可接受”也作为推翻条件。
- [L07 讲义 §二、§四](../lessons/lesson-07/handout.md)的 H1 同时包含“保留”和“核验”；A1 是其他错读增加，A2 是评价提示偏倚，A3 是论文结构下的异质性。
- [L13 评价样例](../lessons/lesson-13/evaluation-report-example.md)进一步改变了 A1/A2/A3 的具体含义；L14–L15 又使用“支持（待验证）”笼统承接 H1。

**核心逻辑问题：**

- 限定条件遗漏下降，同时其他错误增加，两件事可以同时发生。A1 直接挑战的是“整体阅读质量改善”，未必推翻“限定条件保留更多”。
- 只对某类论文有效，可能限定效应的适用范围。A3 不必与该范围内的机制相互排斥。
- 评价者因字段提示而给出不同评分，才直接涉及“观察到的差异是否来自测量”的竞争解释。
- 人工检查更容易、成本更低，需要相应过程或成本观察，不能仅从遗漏率推出来。

**建议用四个问题重新组织，编号可待主笔统一：**

| 层次 | 课堂问法 | 需要看什么 |
| --- | --- | --- |
| 结果 | 在明确的论文与任务范围内，限定条件遗漏是否减少？ | 对照输出、人工基准、差异及与主张相称的不确定性 |
| 机制 | 哪个中间过程造成了差异？有没有测量偏倚等另一解释？ | 能区分具体解释的过程观察或对照 |
| 整体价值与范围 | 其他错误、核验成本怎样变化？哪些论文适用？ | 分项质量、成本和分层结果，按项目目标选用 |
| 研究决定 | 现有结果下继续采用、修改还是暂缓？ | 上述证据，加课程周期与资源约束 |

先保留阅读卡任务，重写一条清楚的结果命题和一条机制候选；课堂选择一个真正可区分的替代解释完整演示。A1/A3 可放入质量代价和范围检查，不要求学生把所有风险都写成竞争机制。

L06 第一性原理示例还应把“相同材料与标准就能归因于结构”改成待检验设计前提。现有 §四已经承认推导要接受证据检验，示例中的确定性因果表述应与这条原则一致。

**复审验收题：** “遗漏变少、其他错误增加、只在文本论文上成立，你会分别改哪条主张？”能分别处理这三件事，才说明理解了机制、指标与范围。

### R3｜演示中的指标与研究主指标没有接成同一条可检查链

**优先级：授课前必修。影响 L09–L14，助教准备依赖最大。**

已核对的对象：

1. [L09 小工件](../lessons/lesson-09/assets/reproducibility-example/README.md)对四条合成记录统计 `condition_present` 的真假，并得到 0.5。它能教输入、配置、结果和日志的一致性。
2. [L10 小工件](../lessons/lesson-10/assets/agent-task-example/task-01.md)修复 `normalize_record()` 的缺字段处理。它能教任务、修改与测试的对应关系。
3. L11–L12 有小队列与原型的说明、伪代码和 trace 示意，课次目录中尚未发现完整独立运行包。
4. [L13 讲义 §五](../lessons/lesson-13/handout.md)评价的是人工基准中的限定条件是否被输出保留，并展示 20 篇×两条件×三次的构造汇总。

**问题在于教学接续：** “记录里的布尔值为假”“代码缺少 summary 字段”“摘要遗漏一个限定条件”是三个不同对象。都叫缺失或遗漏，会让学生误以为前两个程序已经实现了第三个科研指标。

**建议保留已有工程微例，同时补一条小规模但语义完整的主线：**

```text
一段明确标为教学构造的源文本
  → 人工列出应保留的限定条件
  → 两种方法的输出
  → 逐项判断保留／遗漏，并记录依据
  → 汇总差异
  → 写一条有限结论
```

这里的重点是让学生看见一次指标如何从文本得到。无需为此先运行完整 120 次输出。L09 的布尔小例与 L10 的函数修复明确标为工程校准，随后指出它们在主流程中承担哪一步。

主示例的助教说明至少说清：

- 论文样本、条件、重复运行分别如何编号；120 个输出与 20 个论文对象分列。
- 每篇应保留哪些限定条件，判断来自哪段源文本；遇到未能判定的项怎样记录。
- 分母、重复汇总、论文之间的汇总方式及失败输出的处理；按论文平均与汇总全部条件所回答的问题不同，主演选择一种并保持一致。
- 若展示 ±，解释它具体表示什么；没有统计定义时只展示明确标为示意的点值。
- 评价材料由谁持有，执行端是否能读取，评价者是否能识别条件。
- 图表论文负例、总体汇总和最终论证分别对应哪条记录。

**复审验收题：** 助教能从一条原文限定条件，一路指出输出中的保留或遗漏，再找到汇总表里对应的数值贡献。做不到这一步时，不进入大规模队列演示。

### R4｜从负结果直接命名“根因”，再缩小范围，容易误教事后修饰

**优先级：授课前必修。影响 L13–L15。**

[L13 讲义 §五第四步](../lessons/lesson-13/handout.md)先给出两篇图表论文效果更差，随即把“原文位置字段无法定位图表”定为根因，并建议排除图表论文或增加字段。教学构造可以设定已知原因，但当前页面没有展示使这个原因成立的诊断记录，学生容易把作者给出的解释当作从结果自动推出的结论。

建议完整演示三个动作：

1. **保留观察。** 原冻结样本中的两篇负例仍计入原结果，记录实际输出和失败位置。
2. **提出并检查原因。** 先写“疑似与图表位置解析有关”，展示定位记录或对照才能提高判断强度。
3. **形成下一版决定。** 修解析、增字段或限定新适用范围，写入新版本与评价计划；原版本结果继续可查。

这能把“失败记录”从一张合规表变成真正改变研究的材料。若教师提供的是原因已预设的构造案例，就把诊断依据一起给出。

**复审验收题：** “现在决定下一版只面向文本论文，上一版的两篇负例怎么办？”应保留原结果与范围变化记录，并分别报告版本。

### R5｜早期权限模板本身有冲突，声明与执行证据也需分层

**优先级：授课前必修。影响 L01–L02 和 L10–L12。**

[starter-template.md 的 AGENTS.md 最小模板](../course/starter-template.md)把 `problem-definition.md` 与 `notes/` 同时放在“只读”和“可写”范围里。[L02 讲义](../lessons/lesson-02/handout.md)又规定冲突时执行更窄授权。学生可能照模板严格执行而无法完成 L01 写回，也可能习惯忽略冲突。

建议在正式模板中明确一个一致的默认权限，并用本次任务授权说明“哪一段在什么确认后可写”。同一时刻的只读与可写集合应清楚；权限扩大要有记录。与 L01 现有第二轮单段写回一起同步。

课堂还需分清三层：

- **约定**：项目文件和任务契约声明允许什么。
- **控制**：执行环境实际怎样限制读写、执行和外部访问。
- **核查**：日志、diff 与拒绝记录证明本次发生了什么。

L12 若只回放构造拒绝记录，就按回放讲；若演示实际权限控制，就在明确配置的运行环境里触发一次拒绝。两种方式均可承担相应教学任务。

**复审验收题：** “把禁止访问写进文档后，什么材料能证明本次执行确实遵守了它？”学生应指向实际行为和记录，而非再指回声明本身。

### R6｜前半课方法讲解偏集中，短互动尚不足以检验理解

**优先级：试讲前完善。影响 L01–L07、L09–L13。**

按现行教案分段累计，L01–L07 与 L09–L13 这 12 课中，专门的持续个人实践起点在开课后 40–50 分钟。此前已经有投票、标记、短写或问答，不能把这些课描述成前半节完全没有学生动作；问题是一些问题只让学生表态，没有产生能供教师诊断的依据。

建议在原有方法／演示段中，让学生先完成一次小而真实的判断：圈出原文与转述的差别、选出不公平的条件、预测哪个测试会失败。教师根据理由接话，再介绍所需概念。无需把所有短互动都变成额外表格。

四个重点试讲位置：

| 位置 | 当前拥挤点 | 试讲时要确认什么 |
| --- | --- | --- |
| L01 开场与课程契约 | 10 分钟内六页开场，随后 5 分钟六页课程契约 | 学生记住的是一个研究判断，还是一串框架名称？ |
| L04–L05 MI 演示 | 原文核验动作与专业术语同时进入 | 不熟悉 MI 的学生能否说明正在检验哪句话？ |
| L08 开场 | 短时段中既解释规则又示范完整陈述、反馈 | 教师与助教能否完整演一轮，并及时把时间交给学生？ |
| L13 核心演示 | 5 分钟中要完成对照、局限、判断修订 | 输入是否已预置，现场是否只做这三项？ |

修订如改变分段、个人实践或中点点评时长，按现有备课流程重做 90 分钟教学门。总和为 90 不能代替这四处试讲。

### R7｜同一项目的研究结论与其中工作流的评价，关系需要提早交代

**优先级：试讲前完善。影响 L06–L13。**

权威[课程定位](../course/curriculum.md)要求工作流服务学生自己的科研动作。[完整模板 §6](../course/project-template.md)已有“工作流服务的科研动作”和评价计划；方向合理。但阅读卡案例恰好把“研究阅读卡是否有效”和“评价阅读卡工作流”高度重叠，可能使学生误以为所有人都要做一项关于 AI 工具效果的独立研究。

建议在 L06/L09 的既有项目中写清一条关系，而不是新增项目：

> 我的研究问题是什么 → 哪一个科研动作需要重复完成 → Agent Workflow 服务哪个动作 → 它的评价怎样影响原研究判断。

例如学生研究某种训练方法，可以把结果汇总与异常审计做成工作流。方法效果由实验比较判断，汇总工作流的正确性、遗漏和人工修订量由相应评价判断；两者共享项目记录，回答不同问题。

L10 把这个已选动作收窄成一次任务，L11 使它可重复，L12 封装交接，L13 评价它对原动作的影响。这样也能减少 L12 才临时另起项目的压力。

**复审验收题：** “你的工作流评价分数提高，是否就意味着你的论文假设成立？”学生须指出两者的具体关系和不同证据。

### R8｜借用样例完成课堂动作之后，回到个人项目的欠项要可见

**优先级：试讲前完善。影响 L03–L15 的备用路径与四次研究门。**

多课允许缺材料或环境故障时使用教师样例，这有助于课堂继续。L14–L15 已要求课后迁回个人项目，L12 也明确纸面流程图不能充当原型。这些安排应保留并统一执行。

建议利用既有离场卡或缺口栏区分：

- 今天已用什么材料完成了什么方法动作；
- 本人项目还缺什么输入或结果；
- 下次课前回写到哪里。

这三个事实无需新增评分或正式提交。L06/L09/L13/L16 研究门检查本人实际材料，教师构造样例仍保留为练习。避免“课堂练习已完成”被误登记为“个人项目相应门条件已满足”。

## 五、整门课的板书与串词应怎样组织

### 1. 统一一种板书结构，逐课更换内容

建议黑板保留三个区域，按课堂进程填写：

```text
左：当前问题与已知材料       中：这次观察／比较       右：判断如何改变
我还不知道什么             我实际看到了什么         接受、修改、暂缓及理由
哪些条件已经固定           哪里支持或不支持         下一步与回写位置
```

L01 写“减少／所有”，L04 写“AI 转述／原文”，L07 写“两个解释／区分观察”，L09 写“对照／结果来源”，L13 写“观察／机制／范围”，L15 写“评审位置／修改”。

板书保留判断变化，文件表格保留完整记录。这样学生能在一眼内看到本课为什么做这一步，也能在课后找到细节。

### 2. 六处关键转场，建议正式写入备注

| 接续 | 可试讲串词 |
| --- | --- |
| L01 P03→系统研究案例 | “一句话已经需要检查效果和范围。把规模放大到一整篇 AI 生成论文，我们继续用这两类问题看它的研究质量。” |
| L02→L03 | “现在材料可以在什么范围内使用已经清楚。接下来找证据，并检查它是否真的支持我们的问题。” |
| L05→L06 | “把这些材料放在一起后，哪一处仍然没有回答？下一步从几个候选中选一个值得在课程周期内检验的问题。” |
| L07→L09，经 L08 诊所 | “我们已经写出哪个观察能区分解释。同伴帮我们找出缺口，接下来把这个观察变成公平、可执行的比较。” |
| L12→L13 | “这条路径可以复演了。现在分别看：输出是否正确、科研动作有没有改善，以及它对原研究判断意味着什么。” |
| L13→L16 | “把观察、解释和范围写进报告；让同伴反查并实际修改；最后展示证据让你改变过的一个判断。” |

### 3. 每个核心提问必须有接话条件

教师备注中至少写明：预期回答、一个常见误答、怎样追问、什么回答足以进入下一步。例如 L07 学生说“遗漏下降，所以机制成立”，教师应追问“有没有另一种过程也会产生同样分数”，并让学生指出一个区分观察。单写“让学生讨论”或“只听回答不评价”不能承担概念讲评。
