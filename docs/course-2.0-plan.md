# 课程 2.0 改版计划：配图 × MI 贯穿案例 × 失败强化

> 本文件是 2.0 改版的提案与执行计划，不替代 `course/` 权威课程文件；执行时每课仍按 `prepare-course-lesson` skill 门控流程推进。

## Context（为什么改）

学生对 v1.0 备课材料（tag `lesson-prep-v1.0`）提出三条反馈：① 文字太多、缺配图；② 基本是理论框架、缺实际案例；③ 失败的记录讨论不足。用户选定一位博士生的真实课题 **Mechanistic Interpretability（MI）** 作为贯穿案例，启动 2.0 改版。

第二轮反馈与提问（已逐条侦察核实，落点见 §第二轮反馈回应）：① 建议加"包含课程节点的整体框架图"（核实：学生可见材料零图，真空白→G1）；② 缺少示例、但注意到 git 上有模板（核实：课级 8 类示例/模板未发布、链接被网站降级、2 份模板是孤儿，可见性问题→G2）；③ 学生问"如何训练找出对小领域有意义、有意思且可执行的选题"（核实：单线链路已有，缺多候选比较与四维标准卡→G3）；④ 学生问"agent 做科研失败如何归因——代码错 vs 不能推广 vs 基本假设错——如何持续修正"（核实：要素散在 6/9/10/11/13 课，无统一分层归因框架→G4）。

第三轮反馈（已逐条侦察核实，落点见 §第三轮反馈回应）：① 防御性文本（"不做XX/不是XX"）需审查必要性与可改直接指令（核实：16 课 handout + 模板约 590 处判断点，峰值 L2 4.8 处/千字；规则库已存在于 review-checklist §一，但 handout 被豁免边界排除→G5）；② 网页需检查不同系统/浏览器显示（核实：构建链健康，风险集中在 Google Fonts 大陆可达性、中文搜索分词、深色模式嵌图，且零浏览器测试手段→G6）；③ 模板需更明显链接、方便查找与提交作业（核实：三模板已发布但无 nav 条目、无索引页，assignments.md 无"提交到哪"→G7）。

v1.0 立项时侦察核实的结构性基线（历史状态，完成情况以“当前执行状态”表为准）：
- 当时 16 课 handout **零图片**，网站只发布纯文字 handout，图片管线尚未打通；批次 0-1 已完成 L3-L6 的图片与白名单管线，其余课次仍随批次 2-4 推进。
- PPT 密度规则全是防御性的（18pt 下限、删字不缩字），缺"用图替代文字"的正向规则。
- **第 1-8 课没有任何真实科研负结果**（"失败"全是 AI 幻觉/越权）；`course/starter-template.md`（第 1-6 课用）无失败字段；L13 失败分类无"假设被证伪/效应不存在"类；L14 负结果入文有规则无范文；L2 是唯一无失败演示段的教案；证据地图无负面证据落点。
- 问题门（Checkpoint 1）无任何失败条件；判断门（Checkpoint 2）只有前瞻预案。
- MI 在现有材料中零存在，纯增量；但与 L7 机制假设、L9 探针/消融 baseline 天然契合。

## 范式定义（试点产出、推平复用）

**assets/ 一图两用**：同一文件既嵌入 slides.pptx 又被 handout 以 `![](assets/xxx)` 引用，禁止两套副本；跨课复用用相对链接指回源课，不复制。命名：`<来源>-<年份>-<对象>-fig<n>.png`（原图）/`-redraw.svg`（重绘）/`<主题>-<对象>-structure.svg`（自绘）/`mi-trace-<步骤>.png`（工件截图）；每课 `assets/README.md` 逐图登记出处块（来源角色/出处/许可或虚构标记/脱敏状态）。

**图的四种来源角色**：论文原图仅 CC BY 或等价许可直接粘贴，否则一律作重绘依据（lesson-01 版权先例），证据框规则（题名/期刊/年份+图+本页结论同框，DOI/许可进 notes `[Sources]`）；忠实重绘 SVG 优先并标"据 X et al. 年份重绘"；结构图不得伪装实证；工件截图脱敏后使用。

**MI 身份管理**：案例边界框（每课使用处，声明真实课题+授权+学生练习仍用虚构案例）；公开素材标 DOI/arXiv/仓库链接；仓库/模型钉死版本（AutoResearch commit 先例）；`references/notes/mi-case-registry.md`（Git 跟踪、只存元数据）用统一素材 ID 串联各课身份；未发表内容标注只进 PPT notes 与教案，不进 handout 正文。

**每课失败增补最小模式**：失败对象（真实优先，虚构显式标注）→ 失败表现+预期对照 → 根因归类（用 L13 扩展骨架的轻量子集）→ 回写去向（failure-log/研究判断/证据地图冲突格）。

## 关键风险与缓解

- **版权**：重绘优先，仅 CC BY 用原图，逐篇许可进 registry（lesson-01 先例）。

- **门条件批准边界**：先提交说明获批再改；文案被否时仅阻塞 L6/L9，其余批次不受影响。
- **mkdocs 不收集软链目录**：试点实测，默认实现即逐文件软链。
- **虚构/真实混淆**：案例边界框双线声明 + 虚构与未发表各自屏显/notes 双标。
- **G5 误删红线表述**：审查前先建必要边界清单（学术红线/安全/证据/虚构标注），改写时逐条避开，验收时清单逐条复核。
