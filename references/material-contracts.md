# 单课材料契约

本文件规定 `prepare-course-lesson` 内容门、90 分钟教学门和逐页映射门的最低一致性要求。它不替代 `course/` 权威课程文件，也不新增作业或研究门条件。

## 一、材料角色

| 材料 | 唯一职责 | 不得替代 |
| --- | --- | --- |
| `handout.md` | 面向学生、可脱离课堂独立阅读的现行内容源 | 教师讲述提纲、试讲稿 |
| `teaching-plan.md` | 90 分钟教学执行、演示、活动、评价、备用路径与复盘 | 学生讲义 |
| `slides.md` | 正式 PPT 的逐页内容母稿：页面任务、屏显内容、讲述、互动、时间与来源 | 历史 PPT、视觉样张 |
| `keystone-design-spec.md` | 风险触发关键页的页面任务、视觉锚点、相邻页关系和最小成立内容 | 第二套屏显母稿 |
| `lesson-NN.pptx` | 依据上述现行材料制作并通过三重检查的课堂呈现文件 | 未审校内容的事实来源 |

每课只能有一套现行讲义、教案和逐页母稿。README 负责导航和记录门控状态，不得以 README 的 PASS 声明覆盖材料正文中的草稿、待审或口径冲突。

## 二、内容门

内容门通过前必须同时满足：

1. 课次目标、八阶段位置、上游输入、下游输出和正式提交节点与 `course/` 权威文件一致；
2. 三件套使用同一组核心概念、工件字段、案例边界、来源角色和验收条件；
3. 关键事实有可核验直接来源，虚构教学样例不冒充论文、真实项目或实验结果；
4. 学生讲义已完成教师复核，不再标“待教师复核”或“内容草稿”；
5. 不把推荐做法、特定 ML 案例或示例数值升级为课程普适硬门。

任一现行材料仍标“草稿，待教师复核”时，内容门不得登记为正式通过；可以登记为“草稿通过，待教师复核”，但不得据此宣称正式 PPT 已完成全部门控。

## 三、文献核验状态

全课程统一使用以下四态：

| 状态 | 含义 | 可进入候选文献表 | 可进入证据地图主格或综述草稿 |
| --- | --- | --- | --- |
| `pending` | 尚未回到正式来源或原文完成核验 | 是，必须显著标待核验 | 否，只能留在线索区 |
| `verified` | 书目信息、主张与原文一致 | 是 | 是 |
| `verified-with-caveat` | 核心主张与原文一致，但存在范围、方法、版本或措辞限定 | 是，必须携带 caveat | 是，必须保留限定；不得单独支撑 `stable` 结论 |
| `rejected` | 来源不存在、身份错误或主张与原文不符 | 否；保留在审计记录 | 否 |

来源核验、证据作用、结论方向与工件成熟度是不同维度。`verified` 表示拟用转述与原文一致，不表示原研究获得独立证实。`stable` 沿用课程的成熟度与证据要求，不是取得引用资格；有限结果与未决项可以如实写入报告。

不得把 `verified-with-caveat` 缩写成新的状态名 `caveat` 或 `with caveat`。候选表允许保留 `pending` 作为待查线索，但正式门检查、证据地图主格和综述草稿必须区分“已核验”与“待核验”。

## 四、90 分钟教学门

教案和逐页母稿必须明确：

- 连续课堂节奏：逐段只以整数时长呈现（如 5 分钟、10 分钟、15 分钟），各段合计恰好 90 分钟；合计是验证条件，不是呈现方式；不写绝对起止时间；
- 第一次学生动作及其距开课时长；
- 持续项目实践的可用时长与分段安排；
- 一组可在课堂时长内完成的最低产出；
- 设备、网络、模型或人数异常时仍能达到同一学习目标的备用路径；
- 课堂最低产出、课后补全和研究门完整条件三者的边界。

个人实践的分段与呈现约束：

- 单次连续个人实践段不超过 15 分钟；预计超出的，拆成两段并在中间插入教师中点共性卡点点评（教师主导，不计入练习时长）；
- 同伴互查、轮转分享等协作活动不视为个人实践段，不受上款限制；
- 时间数字只保留在教师材料内部（教案流程表、逐页母稿建议时间）；学生可见的屏显不出现任何课堂分钟数（含阅读与准备时长估算），讲义不出现课堂计时分钟数；课前阅读与准备时长估算可保留在讲义与课程阅读清单等文档中。

备用路径可以改变工具和载体，不能悄悄降低学习目标后仍宣称完成同一最低闭环。

## 五、逐页映射与正式 PPT

每页至少映射页面任务、讲义位置、证据角色和学生动作。PPT 屏显标题以现行 `slides.md` 为唯一来源；若制作中形成更好的标题，先回写母稿再更新 PPT。

虚构工件、风险状态、权限、研究门条件和学生行动属于教学信息，必须在最终渲染中可见并满足 18 pt 下限。真实证据页优先展示论文、原文、数据或脱敏研究工件；概念卡片不能替代学生需要观察、比较或核验的研究对象。

正式 PPT 完成后按 `course/ppt-quality-gates.md` 与 `lessons/ppt-design-criteria.md` 执行技术、教学和视觉三重检查。技术 PASS 不能替代内容门或视觉门。

## 研究判断与负荷验收（2026-10-12）

- 学生先独立作答再揭示教师依据；每课至少有一个必须核对原文、数据或 trace 才能决定的分歧。
- 检查决定、证据位置、验证与实际回写；有依据的“仍不能判断”可达标，记录下一项证据。
- 普通课默认按 5/10/10/10/5/15/5/15/10/5 分钟组织；L04按2026-10-21教学选目修订，将讨论与原文校准调整为5/10分钟，即5/10/10/5/10/15/5/15/10/5，总计90分钟，两段个人实践仍各15分钟。L8/L15/L16专用结构仍须90分钟，换场包含在内。
- 课外每课最多60分钟，包括阅读、排障、项目和提交；四门不叠加新必读。三卡在L4–L6课堂逐张形成。
- 实测填写：课次、准备/阅读/项目用时、提示次数、卡点、采用的备用路径、实际回写位置。未试做填写“待测”，不能用桌面推演冒充学生完成时间。
- 无 AI 错误、两条来源均通过、无改善、负结果、网络故障和同题独立判断均按真实证据验收；不设失败配额。
- 工程终稿须含本人实际执行、实质修改、同输入对照及 trace；保存输出回放和已公开参考判定保留其身份。
- 教师答案不进学生发布白名单/下载/搜索。内容复核、文件检查和现场教学验证分别登记，旧版通过不能继承。
